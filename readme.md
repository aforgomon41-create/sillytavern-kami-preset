# 卡密预设（Kami Preset）

一套运行在 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 1.18 以上版本与[酒馆助手](https://n0vi028.github.io/JS-Slash-Runner-Doc)（Tavern Helper / JS-Slash-Runner）4.11.2 以上版本上的 AI 角色扮演预设。

作者：kamisama ｜ 最新正式版：见 [Releases](https://github.com/aforgomon41-create/sillytavern-kami-preset/releases/latest)

## 安装

从 [Releases](https://github.com/aforgomon41-create/sillytavern-kami-preset/releases) 页面下载最新版本的预设 JSON 文件，在 SillyTavern 中导入即可。导入时请允许启用预设内嵌的脚本与正则。

## 功能

**预设本体**

- 条目式上下文工程，通过开关条目切换各项功能，条目支持层级与互斥分组。

**酒馆助手脚本**

- 🧩 运行库：其他面板共用的界面运行库（React 与 Radix 组件），必须保持开启并排在第一位。
- 🎛 脚本按钮：所有功能按钮的统一登记与派发中枢；更新后自动整理重复的脚本项。
- 🛡 反截断：通过工具调用让模型续写，避免回复被截断。
- 🎨 皮肤管理：统一管理各前端皮肤，支持预览与参数调整；未运行时各前端回退到自带样式。
- ✍️ 提示词发送修改：统管所有「对发送提示词的修改」。目前两件事：角色名包裹（切换角色名的包裹符号）、常驻附加指令。
- 📄 正文外壳：给 AI 输出的正文套上标题、字数、渲染与原文双视图和复制按钮。
- 💭 思维链：把显式思维链块搬进酒馆原生思维链块，并给原生块套上同一套前端；原生编辑、删除、复制入口保留。
- 🌟 预设设置：自动解析预设结构的图形化设置面板，支持模型切换、变量调整与查看条目注释。
- 🧭 引导：首次使用时自动弹出的全屏向导。
- 🧰 工具箱：集中提供「压缩」「网络搜索」「其他功能」三个页签。
  - 压缩：长上下文自动压缩（大总结 / 超限压缩）。
  - 网络搜索：支持模型原生搜索与外部搜索服务，自动搜索跟随剧情，手动搜索使用独立模型与提示词。两种搜索分别设置查询、来源、资料数和保存预算，手动搜索可查看进度或随时中断。配置方法与密钥入口见[搜索功能说明](docs/网络搜索功能方案.md)和[密钥获取说明](docs/搜索服务Key获取.md)。
  - 其他功能：自动标签处理（在正则处理前保护思维链中的标签引用）、常驻附加指令、导出纯净正文。
- 🔄 远程更新：启动时自动检查新版本并提示更新，可继承旧预设的设置。
- 📊 状态栏（制作中，默认关闭）：屏幕边缘一颗可拖动的预设吉祥物悬浮球。

**内嵌前端（由正则渲染）**

- 显式思维链：折叠展示思维链内容，支持 Markdown 渲染与一键复制。
- 行动选项：将模型输出的选项渲染为可交互按钮，可填入输入框或直接发送。
- 搜索资料：默认折叠，展开后是编号事实列表与来源表，来源显示网页标题；保存到上下文的内容采用精简格式。

**皮肤**

- 内置 21 套皮肤（含 GPT、Claude 与大肥鱼），支持明暗、密度和动效调整。大肥鱼提供鲸鱼娘挂件、虎鲸特色控件和海洋背景，可分别关闭。

## 开发

- 技术栈：酒馆助手脚本 + 正则内嵌前端；界面由 React 18 + Radix 无头组件实现，esbuild 打包成一份共享运行库；样式用 `.kami-*` 类名、`--kami-*` CSS 变量与 `@layer`。详见 [前端技术栈](docs/前端技术栈.md)。
- 装依赖：`npm ci`；构建：`node build/build.mjs`（会先跑全部测试与守卫），产物输出到 `dist/`（不进 git）。改了 `src/runtime/` 后先跑 `node build/build-runtime.mjs`。
- 分支：`main` 用于维护与发版；大改动在独立支线上做，支线产物名带支线后缀、不得发版。规则见 [交接](docs/交接.md) 第〇节。
- 文档索引见 [docs/README.md](docs/README.md)，新会话从 [docs/交接.md](docs/交接.md) 开始。
