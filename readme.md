# 卡密预设（Kami Preset）

一套运行在 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 1.18 以上版本与[酒馆助手](https://n0vi028.github.io/JS-Slash-Runner-Doc)（Tavern Helper / JS-Slash-Runner）4.11.2 以上版本上的 AI 角色扮演预设。

作者：kamisama ｜ 最新正式版：见 [Releases](https://github.com/aforgomon41-create/sillytavern-kami-preset/releases/latest)

## 安装

从 [Releases](https://github.com/aforgomon41-create/sillytavern-kami-preset/releases) 页面下载最新版本的预设 JSON 文件，在 SillyTavern 中导入即可。导入时请允许启用预设内嵌的脚本与正则。

第一次使用会弹出引导：先阅读并确认「免责声明与开源许可」，然后跟着引导把外观、模型、语言与数值等设好。

已经装过旧版的用户不用手动下载：「🔄 远程更新」会提示更新，合并时保留你改过的条目、开关、参数和自己加的东西，并先把原预设另存一份备份。

## 功能

**预设本体**

- 条目式上下文工程，通过开关条目切换各项功能，条目支持层级与互斥分组。

**酒馆助手脚本**（按钮都在输入框上方的按钮条里）

- 🧩 运行库：所有界面共用的运行库（React 18、Radix 无头组件、设计系统与皮肤引擎），必须保持开启并排在第一位。
- 💬 消息前端：每条回复的正文、思维链、搜索资料、行动选项由预设统一排版、跟着皮肤走；内容仍由酒馆渲染（Markdown、HTML 美化、其他插件插入的内容照常），公式会渲染出来。可以在「🎨 显示」里整个关掉，或只关其中某一块（正文 / 思维链 / 搜索资料 / 行动选项），交回酒馆原样显示。
- 🎨 显示：皮肤、配色、动效、密度、字号、特效与参数，以及消息前端开关、皮肤字体颜色、角色名样式、行动选项的默认行为。
- 🧭 引导：首次使用时弹出；必须先确认免责声明与开源许可，再逐页介绍预设的每一项功能，并按出厂默认设好。随时可以重看。
- 🎛 脚本按钮：所有功能按钮的统一登记与派发；更新后自动整理重复或已退役的脚本项。
- 🛡 反截断：通过工具调用让模型续写，避免回复被截断（默认关闭）。
- ✍️ 提示词发送修改：统管所有「对发送提示词的修改」：角色名包裹（切换角色名的包裹符号）、常驻附加指令。
- 💭 思维链：把显式思维链块搬进酒馆原生思维链块，原生编辑、删除、复制入口保留。
- 🌟 预设设置：从当前预设自动解析出来的图形化设置面板，支持模型切换、变量调整与查看条目注释。
- 🧰 工具箱：「压缩」「网络搜索」「其他功能」「更新」四个页签。
  - 压缩：长上下文自动压缩（滚动压缩 / 超限压缩）。
  - 网络搜索：支持模型原生搜索与 14 种外部搜索服务，自动搜索跟随剧情，手动搜索使用独立模型与提示词。两种搜索分别设置查询、来源、资料数和保存预算，手动搜索可查看进度或随时中断。配置方法与密钥入口见[搜索功能说明](docs/网络搜索功能方案.md)和[密钥获取说明](docs/搜索服务Key获取.md)。
  - 其他功能：自动标签处理、常驻附加指令、导出纯净正文。
  - 更新：版本信息、手动检查更新、继承旧预设的设置。
- 🔄 远程更新：启动时检查新版本并提示更新，三方合并保留你的设置。

**皮肤**

- 内置 31 套：默认「碎光」；「世界观」系列 13 款、「朋克」系列 9 款（赛博、蒸汽、柴油、真空管、原子、太阳、丝绸、生物、发条），每款有自己的配色、字体、装饰与招牌动效；「AI 娘」系列 8 款（DeepSeek、Claude、GPT、Gemini、GLM、Kimi、Grok、千问），带立绘、看板娘、表情与道具。
- 都支持明暗、密度、字号与动效调整，特效可以逐项关闭。

> 小提示：酒馆每次打开都会把预设文件夹里的所有预设一起载入。不用的旧版预设建议删掉，手机上会明显快一些。

## 开发

- 技术栈：酒馆助手脚本 + 新前端（`src/frontend/`，TypeScript、React 18 + Radix，原生 CSS 变量与 `@layer`，Shadow DOM 隔离）；皮肤包在 `src/skins-next/`。协议见[前端契约](docs/前端契约.md)，加新东西前先查[功能复用](docs/功能复用.md)。
- 装依赖：`npm ci`；构建：`node build/build.mjs`（会先打新运行库与皮肤包，再跑全部离线测试与守卫），产物输出到 `dist/`（不进 git）。
- 验证只在真实酒馆里做：本机测试酒馆 + 假模型 + `test/st/*.mjs`，见 [test/st/README.md](test/st/README.md)。
- 分支：`main` 用于维护与发版；大改动在独立支线上做，支线产物名带支线后缀、不得发版。规则见 [交接](docs/交接.md) 第〇节。
- 文档索引见 [docs/README.md](docs/README.md)，新会话从 [docs/交接.md](docs/交接.md) 开始。
