# 卡密预设（Kami Preset）

一套运行在 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 1.18 以上版本与[酒馆助手](https://n0vi028.github.io/JS-Slash-Runner-Doc)（Tavern Helper / JS-Slash-Runner）4.9.5 以上版本上的 AI 角色扮演预设。

作者：kamisama ｜ 当前版本：v0.9（开发中）

## 安装

从 [Releases](../../releases) 页面下载最新版本的预设 JSON 文件，在 SillyTavern 中导入即可。

## 功能

**预设本体**

- 条目式上下文工程，通过开关条目切换各项功能，条目支持层级与互斥分组。

**酒馆助手脚本**

- 🎛 脚本按钮：所有功能按钮的统一登记与派发中枢。
- 🛡 反截断：通过工具调用让模型续写，避免回复被截断。
- 🎨 皮肤管理：统一管理各前端皮肤，支持预览与参数调整；未运行时各前端回退到自带样式。
- 🌟 预设设置：自动解析预设结构的图形化设置面板，支持模型切换、变量调整与查看条目注释。
- 🧭 引导：首次使用时自动弹出的全屏向导。
- 📜 压缩：长上下文自动压缩。
- 🔄 远程更新：启动时自动检查新版本并提示更新。

**内嵌前端（由正则渲染）**

- 显式思维链：折叠展示思维链内容，支持 Markdown 渲染与一键复制。
- 行动选项：将模型输出的选项渲染为可交互按钮，可填入输入框或直接发送。

**皮肤**

- 内置多套皮肤（grokbot / memo / nixie / rain / trpg），移动端与 PC 端均已适配。
