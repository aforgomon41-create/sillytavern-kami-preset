# 卡密预设（Kami Preset）

一套运行在 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 1.18 以上版本与[酒馆助手](https://n0vi028.github.io/JS-Slash-Runner-Doc)（Tavern Helper / JS-Slash-Runner）4.11.2 以上版本上的 AI 角色扮演预设。

作者：kamisama ｜ 当前版本：v0.91

## 安装

从 [Releases](../../releases) 页面下载最新版本的预设 JSON 文件，在 SillyTavern 中导入即可。

## 功能

**预设本体**

- 条目式上下文工程，通过开关条目切换各项功能，条目支持层级与互斥分组。

**酒馆助手脚本**

- 🎛 脚本按钮：所有功能按钮的统一登记与派发中枢。
- 🛡 反截断：通过工具调用让模型续写，避免回复被截断。
- 🎨 皮肤管理：统一管理各前端皮肤，支持预览与参数调整；未运行时各前端回退到自带样式。
- 🌟 预设设置：自动解析预设结构的图形化设置面板，支持模型切换、变量调整与查看条目注释；另有「🧰 其他功能」页，放那些不常改的功能，卡片默认折叠。目前两件：自动标签处理（AI 回复里没写闭合的标签自动补全或删除，开启覆盖模式除网页自带标签外全管，可手动处理当前楼层）、常驻附加指令（把一段自定义指令接在每条消息末尾一起发出去，只进提示词）。
- ✍️ 提示词发送修改：统管所有「对发送提示词的修改」。目前两件事：角色名包裹（切换角色名的包裹符号）、常驻附加指令（与上面那张卡配合）。
- 🧭 引导：首次使用时自动弹出的全屏向导。
- 📜 压缩：长上下文自动压缩。
- 📊 状态栏（实验，默认关闭）：屏幕边缘一颗可拖动的预设吉祥物悬浮球。
- 🔄 远程更新：启动时自动检查新版本并提示更新。

**内嵌前端（由正则渲染）**

- 显式思维链：折叠展示思维链内容，支持 Markdown 渲染与一键复制。
- 行动选项：将模型输出的选项渲染为可交互按钮，可填入输入框或直接发送。

**皮肤**

- 内置 15 套皮肤（grokbot / crt80s / civdawn / empire / isekai / manga / memo / mileng / nixie / rain / senren / terminal / trpg / wod / xianyun），移动端与 PC 端均已适配。
