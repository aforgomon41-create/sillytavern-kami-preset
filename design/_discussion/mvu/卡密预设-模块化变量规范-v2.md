# 卡密预设 · 模块化变量数据体系规范 (v2.0 精简受控版)

> **设计宗旨**：架构大满贯，模块严控复杂度。  
> **核心机制**：复杂度主要通过「开关模块」控制；每个模块内部严格限制字段与深度，兼顾模型可读性、Token 经济性与代码防御。

## 一、体系总览与开关拓扑

整套数据划分为 **6 个独立功能模块**。除第一模块为底层必开外，其余模块皆可按场景独立启闭。

```
┌─────────────────────────────────────────────────────────────┐
│  1. 当前状态模块 (时空、地点、天气特效、同屏在场) [必开]            │
├─────────────────────────────────────────────────────────────┤
│  2. 角色模块 [各子模块独立开关：基础(必开)/属性/资产/社交/NSFW]    │
├─────────────────────────────────────────────────────────────┤
│  3. 地图模块 [开关：纯节点拓扑模式  XOR  微观网格战术模式]          │
├─────────────────────────────────────────────────────────────┤
│  4. 势力模块 [开关：控制阵营动向、声望关系与大局走势]              │
├─────────────────────────────────────────────────────────────┤
│  5. 剧情模块 [开关：主支线推进阶段、线索备忘与核心目标]            │
├─────────────────────────────────────────────────────────────┤
│  6. 活世界模块 [开关：独立时钟事件、坊间传闻与世界环境动态]          │
└─────────────────────────────────────────────────────────────┘
```

## 二、模块一：当前状态模块 (必开常驻)

为整个故事锚定叙事镜头。天气的枚举类型直接与卡密预设的皮肤特效通道（如雨滴、扫描线、光晕）联动。

```yaml
当前状态:
  时间: "第3天 14:30"             # 故事内时间，短字符串
  地点: "迷雾森林·石碑入口"        # 当前场景名，与地图当前点呼应
  天气: "浓雾"                    # 严格限定枚举，直接触发前端 CSS 氛围特效
                                  # 可选枚举：[晴天, 阴天, 雨天, 暴雨, 浓雾, 暴雪, 雷暴, 扬尘, 虚空异象]
  在场人员: ["雷恩", "艾莉亚"]     # 当前同一物理空间内的人员名单，用于驱动状态栏人员卡
```

## 三、模块二：角色模块 (核心子模块分治)

以角色名为键（支持模型剧情中动态长出新 NPC）。子模块按需加载。

```yaml
角色:
  [角色名]:
    # ── 2.1 基础子模块 (必开) ──
    基础:
      是否主角: boolean           # true 为玩家角色，其余为 NPC
      身份头衔: string            # 如："精灵族游侠"
      当前外貌: string            # 30 字以内高浓度特征，提炼发型、瞳色、体态与神情
      衣装状态:
        外层: string              # 如："墨绿色防风短斗篷"
        主体: string              # 如："深绿色游侠皮甲 (完好)"
        贴身: string              # 如："素色衬衣"

    # ── 2.2 属性子模块 (开关) ──
    属性:
      数值能力:                   # 经典六维或其他主属性，单项直接记数字
        力量: 12
        敏捷: 18
        体质: 14
        智力: 13
        感知: 16
        魅力: 14
      特殊属性:                   # 针对剧本设定的定制能量槽或状态值
        魔力储备: "75%"
        理智值: 88
      特质与被动:                 # 固有天赋或状态词条，名称对应短说明
        森林之子: "林地移动不受地形惩罚"
      掌握技能:                   # 主动技能及其熟练度/等阶
        连珠箭: "Lv.2 (可双发附魔)"

    # ── 2.3 资产子模块 (开关) ──
    资产:
      佩戴装备:                   # 部位对应装备名称与简明词条
        武器: "精灵长弓 (射程加成)"
        护具: "硬化皮甲 (轻量防刺)"
      随身物品:                   # 物品名对应数量，不记复杂长文
        箭矢: 20
        止血草药: 2
      财富储备:                   # 资金统计
        金币: 15
        银币: 40

    # ── 2.4 社交模块 (开关) ──
    社交:
      好感数值: 0                 # 范围：-100 到 100，玩家自身默认 100
      关系阶段: "陌生防备"        # 限定枚举：[死敌, 厌恶, 疏离, 陌生防备, 点头熟人, 值得信赖, 亲密挚友, 暧昧恋慕, 生死契约]
      内心印象: "这人类有古怪魔力，绝不可掉以轻心" # 当前对主角的真实心声
      重要羁绊:                   # 与其他特定角色的关系单行记录
        引导精灵: "昔日盟友 (已离去)"

    # ── 2.5 NSFW 模块 (开关) ──
    NSFW:
      情欲状态: "平静无波"        # 当前性冲动与唤起程度
      心防程度: "完全封闭"        # 限定枚举：[完全封闭, 略有动摇, 羞怯顺从, 沉沦依附]
      衣着完整度: "整齐"          # 限定枚举：[整齐, 凌乱, 半解, 破损暴露, 赤裸]
      敏感部位:                   # 关键性感带状态
        耳尖: { 敏感度: "特异弱点", 状态: "微红警戒" }
        胸口: { 敏感度: "普通", 状态: "紧绷于皮甲内" }
```

## 四、模块三：地图模块 (受控双互斥模式)

为保证模型理解力，杜绝旧版死板庞大的全图数据，采用「**视野局部化**」原则控制数据体积。双模式互斥二选一：

### 模式 A：局部节点拓扑模式 (宏观叙事与旅行)
不存全球大百科。只存当前节点与相邻可到达的 2–4 个岔路点。

```yaml
地图_节点:
  当前大区: "迷雾森林"
  当前节点: "森林入口石碑"
  节点环境: "风化严重的古老石碑，被湿润的青苔覆盖"
  可前往路径:                     # 仅列出相邻连通的路线
    - 目标节点: "起始镇·北门"
      耗时: "步行 30分钟"
      限制条件: "无"
      状态: "畅通"
    - 目标节点: "遗迹核心祭坛"
      耗时: "穿行 2小时"
      限制条件: "需要驱雾火把或向导"
      状态: "有迷雾阻隔"
```

### 模式 B：微观网格战术模式 (地牢探险与近身战)
限定固定尺寸（如 8×8 或 10×10）。采用**稀疏矩阵记录法**，普通平地不写，只记录带有掩体/障碍的特殊坐标点与实体实时位置。

```yaml
地图_网格:
  空间名称: "遗迹大厅"
  网格尺寸: [8, 8]                # 8宽 x 8高
  特殊地块:                       # 稀疏记录特殊格子
    "[2,3]": { 类型: "石柱掩体", 可穿行: false }
    "[4,4]": { 类型: "积水洼地", 可穿行: true, 阻碍: "消耗双倍移动力" }
    "[7,7]": { 类型: "下层阶梯", 可穿行: true, 事件: "前往地下一层" }
  单位坐标:                       # 角色当前格子位置
    雷恩: [1, 2]
    艾莉亚: [2, 2]
    守卫魔像: [5, 5]
```

## 五、模块四：势力模块

追踪当前世界主要组织的博弈态势与对主角的看法，避免复杂的百科介绍，专注动态与声望。

```yaml
势力:
  [势力名]:
    阵营特质: "中立守序·自然守卫" # 简单阵营或行为宗旨
    主角声望: 0                  # 范围：-100 (血仇) 到 +100 (领袖崇拜)
    外交态度: "中立戒备"          # 态度概括
    近期动向: "封锁迷雾森林外围通道，搜寻失踪的巡逻队员" # 一句话描述当前行为
```

## 六、模块五：剧情模块

管理当前正在推进的任务主线与重要线索，避免流水账历史记录。

```yaml
剧情:
  主要任务:
    [任务名]:
      分类: "主线使命"            # [主线使命, 伙伴支线, 突发机缘]
      阶段目标: "穿过迷雾大门"     # 当前这一步要干什么
      完成进度: 30                # 0 到 100 数值
      当前难点: "需要取得艾莉亚的通行许可"
  已知关键线索:                   # 记录悬念、伏笔与重要情报
    古代结晶的来历: "表面刻有失落纪元的封印印记，可能源自深层祭坛"
```

## 七、模块六：活世界模块

体现「世界不在围着主角转，其它角落也在运转」的动态沉浸感。

```yaml
活世界:
  时钟事件:                       # 带倒计时、不依玩家意愿自主推进的大事
    魔兽集结:
      剩余倒计时: "90分钟"
      局势描述: "荒原上的魔物群正在聚合，警报烽火已燃起"
      超时后果: "城镇将遭到第一波潮汐冲击"
  坊间传闻:                       # 随时间刷新的外部动态
    - "商会刚刚提高了对纯净结晶的收购价"
  环境变迁:                       # 世界发生过的不可逆物理改变
    - "北门吊桥已在早先的战斗中损坏，暂时无法通行马车"
```

## 八、Zod Schema 校验与修补实现草案

在前端与脚本层，通过 Zod 4 实现各字段的防御性保障。

```typescript
import { registerMvuSchema } from 'https://testingcf.jsdelivr.net/gh/StageDog/tavern_resource/dist/util/mvu_zod.js';

// 1. 天气与特效联动枚举
export const WeatherEnum = z.enum([
  '晴天', '阴天', '雨天', '暴雨', '浓雾', '暴雪', '雷暴', '扬尘', '虚空异象'
]).prefault('晴天');

// 2. 关系阶段枚举
export const RelationshipEnum = z.enum([
  '死敌', '厌恶', '疏离', '陌生防备', '点头熟人', '值得信赖', '亲密挚友', '暧昧恋慕', '生死契约'
]).prefault('陌生防备');

// 3. 好感度范围钳位 (-100 到 100)
export const AffectionSchema = z.coerce.number()
  .transform(v => _.clamp(v, -100, 100))
  .prefault(0);

// 4. 当前状态模块 Schema
export const StateModuleSchema = z.object({
  时间: z.string().prefault('第1天 12:00'),
  地点: z.string().prefault('未知区域'),
  天气: WeatherEnum,
  在场人员: z.array(z.string()).prefault([]),
}).prefault({});

// 5. 动态角色子模块骨架 (全面部署 prefault 防止子字段缺失)
export const CharacterEntitySchema = z.object({
  基础: z.object({
    是否主角: z.boolean().prefault(false),
    身份头衔: z.string().prefault('旅行者'),
    当前外貌: z.string().prefault('体态普通，暂无特殊描写'),
    衣装状态: z.object({
      外层: z.string().prefault('无'),
      主体: z.string().prefault('普通布衣'),
      贴身: z.string().prefault('贴身内衬'),
    }).prefault({}),
  }).prefault({}),

  属性: z.object({
    数值能力: z.record(z.string(), z.coerce.number()).prefault({}),
    特殊属性: z.record(z.string(), z.any()).prefault({}),
    特质与被动: z.record(z.string(), z.string()).prefault({}),
    掌握技能: z.record(z.string(), z.string()).prefault({}),
  }).prefault({}),

  资产: z.object({
    佩戴装备: z.record(z.string(), z.string()).prefault({}),
    随身物品: z.record(z.string(), z.coerce.number()).prefault({}),
    财富储备: z.record(z.string(), z.coerce.number()).prefault({}),
  }).prefault({}),

  社交: z.object({
    好感数值: AffectionSchema,
    关系阶段: RelationshipEnum,
    内心印象: z.string().prefault('并无特殊看法'),
    重要羁绊: z.record(z.string(), z.string()).prefault({}),
  }).prefault({}),

  NSFW: z.object({
    情欲状态: z.string().prefault('平静无波'),
    心防程度: z.enum(['完全封闭', '略有动摇', '羞怯顺从', '沉沦依附']).prefault('完全封闭'),
    衣着完整度: z.enum(['整齐', '凌乱', '半解', '破损暴露', '赤裸']).prefault('整齐'),
    敏感部位: z.record(z.string(), z.object({
      敏感度: z.string().prefault('普通'),
      状态: z.string().prefault('平静'),
    }).prefault({})).prefault({}),
  }).prefault({}),
}).prefault({});

// 6. 模块级根 Schema (按设置动态聚合已开启的模块)
export const MasterSchema = z.object({
  当前状态: StateModuleSchema,
  角色: z.record(z.string(), CharacterEntitySchema).prefault({}),
  // 其余模块（地图/势力/剧情/活世界）按开关动态挂载
}).prefault({});
```
