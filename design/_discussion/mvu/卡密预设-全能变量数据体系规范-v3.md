## 一、模块开关与架构拓扑

整套体系由 **6 个独立功能模块** 组成。除核心底座为必选外，其余模块均通过配置开关自由启闭。

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 当前状态模块 (时空历法、地点两级、天气特效、在场人员) [必开常驻] │
├─────────────────────────────────────────────────────────────────┤
│  2. 角色模块 (主键为唯一角色ID，支持随时改名)                     │
│     ├─ 2.1 基础子模块 (位阶、即时状态、健康精力、分层着装) [必开]  │
│     ├─ 2.2 属性子模块 [开关：DnD模式  XOR  WoD模式]              │
│     ├─ 2.3 资产子模块 [开关：装备/消耗品/背包/世界观货币]        │
│     ├─ 2.4 社交子模块 [开关：好感/身份关系/约定/隐瞒/回忆]       │
│     └─ 2.5 NSFW子模块 [开关：性设定/情欲心防状态机/部位开发]      │
├─────────────────────────────────────────────────────────────────┤
│  3. 地图模块 [开关：图谱节点模式  XOR  世界大网格模式]            │
├─────────────────────────────────────────────────────────────────┤
│  4. 势力模块 [开关：组织特性、掌控资源、全景外交]                 │
├─────────────────────────────────────────────────────────────────┤
│  5. 剧情模块 [开关：宏观焦点、多剧情线阶段目标]                   │
├─────────────────────────────────────────────────────────────────┤
│  6. 活世界模块 [开关：场外动态、传闻八卦、公共变迁]                │
└─────────────────────────────────────────────────────────────────┘
```

## 二、模块一：当前状态模块 (必开常驻)

用于锚定全剧当前镜头。时间严格规范，天气枚举直接联动皮肤背景特效。

```yaml
当前状态:
  轮次: 12                        # 整数，客观交互计数器，判断时序的唯一刚性标尺
  时间: "第四纪元-2023年-11月-15日-15:00" # 严格固定格式：[纪元]-[年]-[月]-[日]-[时间]
  地点:
    大区: "迷雾森林"              # 第一级宏观地理划分
    地点: "石碑入口"              # 第二级具体场景点
    坐标: null                    # 纯节点模式为 null；网格模式下填 [X, Y]
  天气: "浓雾"                    # 13种限定枚举之一：
                                  # [晴天, 阴天, 雨天, 降雪, 风暴, 暴雨, 雷暴, 暴雪, 沙暴, 浓雾, 瘴气, 室内, 特殊]
  在场人员: ["char_player", "npc_01"] # 记录同屏角色的唯一角色ID
```

## 三、模块二：角色模块 (5大子模块分治)

以唯一 `角色ID`（如 `char_player`、`npc_01`）为主键，隔离改名带来的数据冲突。

### 2.1 基础子模块 (必开常驻)
```yaml
角色:
  [角色ID]:
    基础:
      姓名: "艾莉亚"              # 可读姓名，初始可填“兜帽少女”，得知真名后直接修改
      是否主角: false             # true 为玩家操作的主角，其余为 NPC
      身份头衔: "精灵族巡逻游侠"   # 阵营与社会地位概括
      位阶: "白银阶中段"          # 世界观下的战力/境界梯队定位
      所在地点: "迷雾森林·石碑入口" # 大区·具体位置，不在场的角色亦可准确定位
      当前状态: "警戒潜行中"       # 即时战术姿态或行为状态
      健康: "轻度疲惫，无明显外伤" # 自然语言描述生理伤病
      精力: "充沛"                # 自然语言描述精神与体能状态
      当前外貌: "银发碧眼，身形修长，神情警惕冷淡" # 30字以内浓缩外貌特征
      当前目标: "核查可疑人类的来历，确保结界完好" # 行动动机
      心声: "这人类手里的结晶很眼熟，绝不能让他靠近祭坛" # 内心真实想法
      着装状态:
        外穿: "墨绿色防风斗篷"
        主体: "贴身硬化皮甲"
        贴身: "麻布内衬"
        足部: "猎手软皮靴"
        装饰: "风行者护符、细银耳坠"
        其他: "防毒面纱(挂在脖颈处)"
```

### 2.4 社交模块 (开关·扁平人际网络)
社交层直接挂目标角色 ID，消除多余层级，支持群像多向关系。
```yaml
    社交: # [开关控制]
      [目标角色ID]:               # 目标对象，可以是主角也可以是其他 NPC
        好感: 30                  # 数值范围：-100 到 100
        关系: "昔日并肩作战的同僚" # 自然语言身份性质：如青梅竹马/死敌/师徒/同僚

        关键回忆: "三年前在凛冬要塞一起死里逃生的风雪夜" # 维系关系的重大经历
```

## 四、模块三：地图模块 (双互斥模式)

两套模式互斥二选一，第一级大区与地点结构保持统一。

### 3.1 模式 A：图谱节点模式 (宏观叙事)
大区包含地点，地点包含属性与视听配置，连接关系独立维护。
```yaml

    大区: "迷雾森林"
    地点: "石碑入口"

    迷雾森林:
      描述: "古老原始森林，终年笼罩魔力浓雾"
      地点:
        石碑入口:
          描述: "森林边缘的一块风化断碑，被湿润的青苔覆盖，立于岔路口。"
          文生图tags: "misty forest, entrance, stone monument, moss, volumetric lighting, masterpiece"
          可见性: "已探索"        # 枚举：已探索 / 已知未至 / 未发现
          $背景图: "https://.../forest_gate.jpg" # 隐藏字段：有则直接覆盖 AI 生图
          $BGM: "https://.../forest_ambient.mp3"  # 隐藏字段：进入地点自动播放
          特殊:                   # AI 自由扩展
            环境威胁: "低等毒瘴"

        核心祭坛:
          描述: "深处被古木环绕的圆形祭坛，散发着淡紫色的魔法光辉。"
          文生图tags: "ancient magic altar, purple glow, giant ancient trees, fantasy, masterpiece"
          可见性: "已知未至"
          $背景图: ""
          $BGM: ""
          特殊:
            结界状态: "运转中"

  连接关系:                       # 图谱边清单，格式明确直观
    - "迷雾森林·石碑入口 <-> 迷雾森林·核心祭坛" # 双向通行
```

## 七、模块六：活世界模块 (开关·纯事件账本)

## 八、Zod 4 落地校验与修补实现代码

以下脚本作为预设的内置角色脚本载入，全面配置 `prefault` 保底默认值，杜绝因大模型少填字段导致对象丢失：

```typescript
import { registerMvuSchema } from 'https://testingcf.jsdelivr.net/gh/StageDog/tavern_resource/dist/util/mvu_zod.js';

// ── 1. 枚举与数值约束 ──
const WeatherEnum = z.enum([
  '晴天', '阴天', '雨天', '降雪', '风暴', '暴雨', '雷暴', '暴雪', '沙暴', '浓雾', '瘴气', '室内', '特殊'
]).prefault('晴天');

const VisibilityEnum = z.enum(['已探索', '已知未至', '未发现']).prefault('未发现');

const AffectionSchema = z.coerce.number()
  .transform(v => _.clamp(v, -100, 100))
  .prefault(0);

// ── 2. 模块一：当前状态 Schema ──
const StateModuleSchema = z.object({
  轮次: z.coerce.number().prefault(1),
  时间: z.string().prefault('第一纪元-1年-1月-1日-12:00'),
  地点: z.object({
    大区: z.string().prefault('未知区域'),
    地点: z.string().prefault('入口'),
    坐标: z.array(z.coerce.number()).nullable().prefault(null),
  }).prefault({}),
  天气: WeatherEnum,
  在场人员: z.array(z.string()).prefault([]),
}).prefault({});

// ── 3. 模块二：角色各子模块 Schema ──
const CharacterBaseSchema = z.object({
  姓名: z.string().prefault('无名者'),
  是否主角: z.boolean().prefault(false),
  身份头衔: z.string().prefault('平民'),
  位阶: z.string().prefault('凡人'),
  所在地点: z.string().prefault('未知'),
  当前状态: z.string().prefault('正常'),
  健康: z.string().prefault('健康完好'),
  精力: z.string().prefault('充沛'),
  当前外貌: z.string().prefault('相貌寻常'),
  当前目标: z.string().prefault('暂无明确目标'),
  心声: z.string().prefault('心中平静'),
  着装状态: z.object({
    外穿: z.string().prefault('无'),
    主体: z.string().prefault('普通便服'),
    贴身: z.string().prefault('贴身内衬'),
    足部: z.string().prefault('布鞋'),
    装饰: z.string().prefault('无'),
    其他: z.string().prefault('无'),
  }).prefault({}),
}).prefault({});

const CharacterAttributesSchema = z.object({
  数值属性_DnD: z.record(z.string(), z.coerce.number()).prefault({}),
  数值属性_WoD: z.record(z.string(), z.coerce.number()).prefault({}),
  特殊属性: z.record(z.string(), z.any()).prefault({}),
  特质与被动: z.record(z.string(), z.string()).prefault({}),
  能力与技能: z.record(z.string(), z.string()).prefault({}),
}).prefault({});

const ItemEntrySchema = z.object({ 描述: z.string().prefault('') }).prefault({});
const ConsumableEntrySchema = z.object({ 数量: z.coerce.number().prefault(1), 描述: z.string().prefault('') }).prefault({});

const CharacterAssetsSchema = z.object({
  装备: z.object({
    武器: z.record(z.string(), ItemEntrySchema).prefault({}),
    防具: z.record(z.string(), ItemEntrySchema).prefault({}),
    饰品: z.record(z.string(), ItemEntrySchema).prefault({}),
    道具: z.record(z.string(), ItemEntrySchema).prefault({}),
    载具与坐骑: z.record(z.string(), ItemEntrySchema).prefault({}),
  }).prefault({}),
  消耗品: z.record(z.string(), ConsumableEntrySchema).prefault({}),
  背包: z.record(z.string(), ItemEntrySchema).prefault({}),
  资金财富: z.record(z.string(), z.coerce.number()).prefault({}),
}).prefault({});

const CharacterSocialSchema = z.record(
  z.string(),
  z.object({
    好感: AffectionSchema,
    关系: z.string().prefault('相识'),
    印象: z.string().prefault('寻常相处'),
    约定: z.string().prefault('无'),
    隐瞒: z.string().prefault('无'),
    关键回忆: z.string().prefault('无特殊经历'),
  }).prefault({})
).prefault({});

const CharacterNSFWSchema = z.object({
  性设定: z.object({
    性欲倾向: z.string().prefault('普通'),
    性经验: z.string().prefault('不详'),
    性癖与偏好: z.string().prefault('无特殊偏好'),
  }).prefault({}),
  性状态: z.object({
    情欲唤起: z.string().prefault('平静无波'),
    心防程度: z.string().prefault('严防死守'),
    体液与痕迹: z.string().prefault('干爽'),
    衣物破损: z.string().prefault('完好'),
  }).prefault({}),
  敏感部位: z.record(
    z.string(),
    z.object({
      敏感度: z.string().prefault('普通'),
      当前状态: z.string().prefault('平静'),
      刺激反馈: z.string().prefault('无特殊感应'),
    }).prefault({})
  ).prefault({}),
}).prefault({});

const CharacterEntitySchema = z.object({
  基础: CharacterBaseSchema,
  属性: CharacterAttributesSchema,
  资产: CharacterAssetsSchema,
  社交: CharacterSocialSchema,
  NSFW: CharacterNSFWSchema,
}).prefault({});

// ── 4. 模块四至六 Schema ──
const FactionEntitySchema = z.object({
  基础: z.object({
    名称: z.string().prefault('未知组织'),
    组织类型: z.string().prefault('自发组织'),
    规模层级: z.string().prefault('微型'),
    根据地: z.string().prefault('未知'),
    核心代表: z.string().prefault(''),
    当前诉求: z.string().prefault('生存与发展'),
    内部氛围: z.string().prefault('稳定'),
  }).prefault({}),
  组织特性: z.record(z.string(), z.string()).prefault({}),
  掌控资源: z.object({
    资金账目: z.string().prefault('收支平衡'),
    控制场所: z.array(z.string()).prefault([]),
    关键资产: z.record(z.string(), z.string()).prefault({}),
  }).prefault({}),
  对外关系: z.record(
    z.string(),
    z.object({
      好感声望: AffectionSchema,
      关系性质: z.string().prefault('中立'),
      明面态度: z.string().prefault('例行公事'),
      暗地动作: z.string().prefault('无'),
    }).prefault({})
  ).prefault({}),
}).prefault({});

const QuestEntitySchema = z.object({
  名称: z.string().prefault('事件推进'),
  类型: z.string().prefault('探索'),
  状态: z.string().prefault('推进中'),
  当前阶段: z.string().prefault('起步'),
  阶段进度: z.coerce.number().transform(v => _.clamp(v, 0, 100)).prefault(0),
  阶段目标: z.string().prefault('观察环境'),
}).prefault({});

const StoryModuleSchema = z.object({
  宏观焦点: z.string().prefault('继续当前的探索'),
  剧情线: z.record(z.string(), QuestEntitySchema).prefault({}),
}).prefault({});

const LivingWorldSchema = z.object({
  场外动态: z.record(
    z.string(),
    z.object({
      涉及范围: z.string().prefault('周围区域'),
      当前情况: z.string().prefault('日常运转'),
      潜在影响: z.string().prefault('暂无显著波及'),
    }).prefault({})
  ).prefault({}),
  传闻与八卦: z.array(z.string()).prefault([]),
  公共现状变动: z.array(z.string()).prefault([]),
}).prefault({});

// ── 5. 全局总 Schema 注册 ──
export const Schema = z.object({
  当前状态: StateModuleSchema,
  角色: z.record(z.string(), CharacterEntitySchema).prefault({}),
  势力: z.record(z.string(), FactionEntitySchema).prefault({}),
  剧情: StoryModuleSchema,
  活世界: LivingWorldSchema,
  // 地图模块根据设置二选一挂载对应子树
}).prefault({});

$(() => {
  registerMvuSchema(Schema);
});
```
