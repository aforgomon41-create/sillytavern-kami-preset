# 你的任务：设计并实现「奈亚子的TRPG」—— 重做版（全新的默认皮肤）

> 上一版「DM 帷幕」被用户否决（原话：丑到没边了），整个目录已经删除，你也看不到它。
> 不要参考任何旧实现，这是从零开始的一套。

## 用户的原话（直接照做，不要自由发挥成别的方向）

1. 左上角有一个大的 3D 骰子装饰（可转动），要高性能实现；
2. 仅限显式思维链标题的样式：折叠时是一个立起来的三折式硬板纸帷幕（要有立体感，形状像「反斜杠—横—正斜杠」，折角朝向观察者）；
   展开后翻过来（形状像「正斜杠—横—反斜杠」，折角朝外或朝下）；
3. 大面板看起来像撕下来的草稿纸，上面有很多关于跑团的涂鸦；
4. 卡片看起来像桌游的硬纸卡牌；
5. 整体看起来比较清新、有手工感。

## 关于 3D 骰子：高性能怎么做（我的建议，你可以提出更好的方案）

- 皮肤是纯 CSS（不能有 JS、不能引用外部资源），所以 3D 只能是 CSS 3D：
  一个 transform-style: preserve-3d 的骰子容器 + 6 个面，转动只改 transform（走合成层，GPU）即可。
- 禁止 WebGL / canvas / 位图序列帧 —— 这套 CSS 会在每一个聊天楼层各跑一份，按楼层线性付费。
- 一个骰子 = 1 个容器 + 6 个面；整个皮肤里只允许这一个常驻的 3D 层，并且只给容器加 will-change: transform。
- 转动怎么触发由你决定（常驻慢转 / 悬停加速 / 展开时转一下…），但必须能被 data-kami-motion 的 off 档与 prefers-reduced-motion 彻底停住。
- 骰面建议用纯 CSS 的骰点（radial-gradient）或盾徽之类，要求在 40–56px 这种小尺寸下也一眼认得出是骰子。
- 位置：显式思维链组件的左上角 —— 如果你有更好的理解，在汇报里说明。

## 关于三折帷幕（只用在显式思维链标题上，别扩散到其它组件）

- 折叠态：三块硬纸板立着，折角朝向观察者（像「反斜杠—横—正斜杠」），要能看出纸板厚度、折痕与哑光质地；
- 展开态：翻过来（像「正斜杠—横—反斜杠」），折角朝外或朝下，露出内侧；
- 全部用 CSS（clip-path / 渐变 / 伪元素 / transform），不许位图；
- 硬要求：375px 下标题栏必须是一行（上一套「记事本」就是因为标题栏换行被用户挑出来过）。

## 关于「撕下来的草稿纸」大面板

- 边缘要有撕纸的毛边（clip-path 锯齿或 mask 做），不要圆角矩形；
- 纸面要有跑团涂鸦：随手画的骰子、箭头、框选、下划线、圈注、页码、咖啡渍之类，
  用低对比度的背景层，绝不能干扰正文可读性；
- 但它会出现在每一个楼层，涂鸦层数要克制（别为了一张纸付一整个楼层的重绘）。

## 关于「桌游硬纸卡牌」卡片（行动选项）

- 卡牌感：纸板厚度（底边一道硬影）、小圆角、边角轻微磨损、角落有类型标签（用现有语义色），
  悬停或选中时有「被拿起来」的反馈。
