# 你的任务：设计并实现一套**全新的默认皮肤** —— 「DM 帷幕」（现实跑团的挡板）

## 定位

- 皮肤 id 用 `trpg`（原先占这个 id 的那套已改名为 `memo`「记事本」，与你无关，别去碰它）。
- 皮肤管理脚本的默认皮肤就是 trpg —— **你这套会成为用户开箱看到的第一套皮肤**。
- 用户原话：「风格要求突出跑团，trpg。比如说显式思维链折叠起来的时候应该看起来像是 dm 的帷幕，
  然后展开后看起来就像是把帷幕翻过来或者向上移开露出后面 dm 正在准备的剧本以及模组文稿。其他细节设计也是。」

## 关于 DM 帷幕的实物形态（我替你查过了，别凭想象画错）

它是现实桌面跑团里 GM/DM 用的**可折叠多面板挡板**（通常 3–4 块，像屏风一样立在桌上），
作用是把 DM 的骰子、笔记、模组藏起来不让玩家看见。实物特征：

- **面向玩家的一面**是装饰面：整幅插画（常见暗色奇幻或恐怖题材），有的带标题横幅与纹章，边缘有铆钉、铰链、折痕；
- **面向 DM 的一面（内侧）**是功能面：规则速查表、状态表、NPC 名录、随机表，常有卡槽（能插纸）、夹板、便签；
- 材质多为厚卡纸 / 仿皮 / 木，立起来时是**锯齿状折板**，折缝与厚度都看得见；
- 高度约 25–30cm，单块面板约 22cm 宽（横向 A4 上下）。
- 参考：https://www.acaeum.com/indexes/miscellaneous/dmscreen.html 与 https://geekifyinc.com/product/custom-dungeon-master-gaming-screen
  （想更准可以在网上搜 DM screen / GM screen 的实物图再看一遍。）

## 核心交互概念（必须落到具体 CSS 上，不能只是气氛）

- **思维链收起 = 挡板立着**：不透明、有厚度、有折痕与铰链，面向玩家那一面（插画感的纹样或铭牌）。
  它在语义上就是「挡住，你看不到」。
- **思维链展开 = 把挡板翻开或上移**，露出**后面 DM 正在准备的剧本与模组文稿**：纸面、页边批注、
  手写体编号、段落框、便利贴、卡槽。展开后的正文应该看起来像「一页模组文稿」，而不是普通卡片正文。
- 必须在**结构 + CSS** 上做出来，不许用位图贴图（皮肤不允许外部资源，也不允许 JS）。
- 面板、行动选项、参数页、特效都要共用同一套语汇（例如行动选项做成「模组里递给玩家的选项卡」、
  参数滑杆做成仪器旋钮或标记尺），随你决定，但要成体系。
