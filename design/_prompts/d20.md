# 任务：为卡密预设做一个「真 3D 可交互 d20 骰子」装饰组件

## 背景（你没有上下文，这是你需要的全部信息）

工作区：D:\SillyTavern\卡密预设0.9
这是一个 SillyTavern（酒馆）AI 角色扮演预设项目，运行在**酒馆助手 4.9.5** 上。
先读这三份文档再动手：`docs/皮肤契约.md`（接口规范）、`docs/真机验证备忘.md`（部署与踩坑）、`docs/交接.md`（项目全貌）。

关键机制：
- 预设里有「正则内嵌前端」：酒馆把消息里的代码块渲染成**同源 iframe**，前端是完整 HTML 文档（`src/regex/frontend-think.html`、`frontend-options.html`）。
- 预设里还有「酒馆助手脚本」：`src/scripts/30-皮肤管理.js` 是**皮肤管理**脚本，它会把当前皮肤的 CSS 与 `data-kami-*` 属性**注入到酒馆页面 + 每一个消息 iframe**（同源，直接操作 `contentDocument`）。
- 皮肤是**纯 CSS 包**（`src/skins/<id>/skin.css` + `skin.json`），**不含 JS、不引外部资源**。
- 前端里已经埋好了空槽：`<span class="kami-deco" data-kami-deco="d20" aria-hidden="true"></span>`，位置有三处：思维链标题栏、行动选项标题栏、皮肤管理面板标题栏。

## 你要做的东西

一个**真 3D（CSS 3D 二十面体）、二十个面、每面有数字、点击会滚动并停在随机一面**的 d20 装饰。

### 架构（用户已经拍板，照做即可）

1. **只有 TRPG 这套皮肤有骰子** —— 所以由**皮肤声明、皮肤管理脚本注入**，不是写在前端里：
   - `src/skins/trpg/skin.json` 里加一个声明（形如 `"decor": ["d20"]`）；
   - `30-皮肤管理.js` 在「当前皮肤声明了 d20」时，把骰子模块**注入**到酒馆页面与每个消息 iframe；
   - 切到别的皮肤或脚本被关闭时，**必须完整销毁**（移除注入的 script、还原槽位、解绑事件）——这个项目对「注销无残留」有硬要求。
   - **其它三套皮肤（memo / nixie / rain）不受任何影响、一分钱不付。**
2. 前端**不需要改**（空槽已经在了）。

### 技术路线（用户已认可，别改成 WebGL）

- **CSS 3D 二十面体**：JS 只在初始化时算一次 20 个面的精确 transform（二十面体 12 顶点 → 枚举 20 个三角面 → 面法线 → 用 `rotateY(ry) rotateX(rx) translateZ(R)` 把面摆到位）。
- **每个面**是一个 div，用 `clip-path` 裁成三角形，面里放数字文字。
- **滚动**：随机选一面 → 算出「把它转到正对镜头」的目标旋转（容器 `transform: rotateZ(a) rotateX(-rx) rotateY(-ry)`）→ 多转两圈 → 用 CSS `transition` 缓动停住。**闲置时开销为零**（没有任何逐帧 JS；只有容器一个 `transform` 在动）。
- **禁止 WebGL / three.js / canvas 逐帧绘制**：浏览器对同时存在的 WebGL 上下文有硬上限，而骰子会在每个聊天楼层出现，会直接爆掉。
- 尺寸自适应：调用方（宿主）通过 CSS 变量或容器尺寸决定大小，模块要能**同时服务于 28–32px 的小骰子与 72–96px 的大骰子**。
- `data-kami-motion` 的 off/calm 档与 `prefers-reduced-motion` 下：**不做滚动动画**（可以直接跳到结果），但骰子本身仍要看得见。

### DOM 与类名契约（**请按这个来，皮肤作者要靠它配色**）

    已有空槽：span.kami-deco[data-kami-deco=d20]
    模块把它升级为：
      span.kami-d20                          （最外层，承担点击与键盘）
        span.kami-d20-stage                  （perspective 容器）
          span.kami-d20-body                 （preserve-3d，转动的就是它）
            span.kami-d20-face  × 20         （每个面，clip-path 三角形）
              i                                （面里的数字）

    状态：body 上用 data-kami-d20-rolling 表示正在滚动；body 上写 style.transform 承载旋转。
    无障碍：最外层 role=button、tabindex=0、aria-label（例如「掷骰」），滚动结束时把结果写进 aria-label 或一个 visually-hidden 的元素。

### 验证要求（必须给证据）

1. `node build/build.mjs` 通过（它会自动跑前端语义验证）；`node build/lint-skins.mjs` 四套皮肤全 PASS；
