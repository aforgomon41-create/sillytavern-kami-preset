# 皮肤设计简报：月之暗面（`moonside`）· 第二版

> 状态：**待用户拍板**（2026-10-01）。第一版已作废，见 §零。
> 气质示意：`.audit/mock-moonside-v2.png`（左＝现有色块皮肤，右＝本方案）；可重跑示意页 `.audit/mock-moonside-v2.html`。

## 零、第一版为什么被否（留档，别再走回去）

用户原话：**「感觉没有和色块皮肤做出区别，主题也没有突出」**。
内部审计（`skin-auditor`，2026-10-01）逐条比对后确认：第一版只换了表皮，**组件骨架仍是色块皮肤那一套**——
四角大圆角（14/16/22px）、每个设置项装在圆角浮卡里、控件是胶囊与圆形开关、选中态整面反相、层级靠三档背景色套娃。
光谱只是绕着这些既有组件描了一圈边，没有产生任何结构或交互上的差别。

## 一、设计语言一句话

**整套面板是一张摊开的唱片封套：题头只发生一次「棱镜事件」，其余全篇是曲目表。**
一道白光从左射入，被三棱镜劈成六色向右散开——**这一次性的事件就是全部彩色**；
下面的每一项设置都是一条**曲目**：编号在左、名称在中、状态在右，底下一条发丝线。

## 二、身份符号（只留一个）

**一次棱镜事件**：`.kami-card-head::after` 或面板头部，白光（1px 实线）→ 三角（clip-path）→ 六色硬边色带（无渐变过渡）。
全篇其余部分**一律单色**，这是与第一版最根本的区别。

**第二识别物是结构性的，比装饰更难撞**：`.kami-font-mono` 的**曲目编号**（01 / 02 / 03）与每行底部的**发丝线**。
它出现在每一个列表里，用户一眼就知道这是「月之暗面」，而不需要看见彩虹。

## 三、与色块皮肤的结构差异（这才是这一版的重点）

| 维度 | 色块（grokbot） | 月之暗面 v2 |
|---|---|---|
| 几何 | 四角大圆角 8/12/16/22/24px | **直角化** 2/3/4/6px；外壳一个角 45° 切边（`clip-path`） |
| 卡片 | 圆角浮卡 + 1px 四边描边 | **不是卡**：透明底、无外框，只有底部发丝线 + 左侧悬挂编号 →「曲目行」 |
| 卡内卡 | 再套一层更小圆角的色块 | **不换底**：缩进 + 左侧 1px 竖线（唱片内页的 sub-track） |
| 卡头 | 卡里嵌的小圆角标题条 | 横跨版面的排版轴：左 mono 编号/大写标签，右直角小方框 chip |
| 按钮 | 白色胶囊 | **运输控制**：白色直角块 + 字距拉宽；次按钮是文字 + 短下划线 |
| 选中态 | 整面反相 + 加粗 | 编号变白 + 下划线拉长 + 标题位移 1px（满足契约「不只靠颜色」） |
| 开关 | 胶囊轨道 + 圆形滑块 | 直角轨道 + 方形滑块 + mono `ON` 字样 |
| 纹理 | 纯平面，可选噪点 | 黑胶刻槽只在**外壳**（偏心同心圆，圆心在版面外），不在每张卡 |
| 排版 | 系统无衬线 + 粗体小标题 | **三元字体栈**（见 §五）：标题衬线、编号 mono、正文无衬线 |
| 动效 | 缩放弹出、整面呼吸 | 下划线延伸 / 横向擦露；`is-done` 时编号推进一格 |
| 光谱 | 到处描边 | **只出现一次**（题头事件） |

## 四、配色

| 用途 | 暗档（月之暗面 · 默认） | 明档（内页纸 · 月之亮面） |
|---|---|---|
| 底 / 外壳 | `#08090c` / `#0a0b10` | `#efece5` / `#f6f4ee` |
| 曲目行底 | 透明（靠发丝线分行） | 透明 |
| 正文块 | `#12141a` | `#ffffff` |
| 主文字 | `#f4f6fa` | `#14161b` |
| 次要 / 最弱 | `#a7aebc` / `#6c7382` | `#4a5160` / `#7b8290` |
| 强调（主按钮底） | `#ffffff` + 黑字 `#0a0b10` | `#14161b` + 白字 |
| 发丝线 | `rgba(255,255,255,.09)` | `rgba(0,0,0,.12)` |
| 品牌蓝（焦点 / 当前） | `#4c8dff` | `#2f6fd0` |
| 六色光谱 | `#ff4d4d #ff9a3c #ffe14d #4dd97a #4c8dff #a86bff` | 同一条 |

- **六色而不是七彩**：色带用硬边（`linear-gradient` 的 0 16.6%… 断点），不用平滑彩虹渐变——平滑渐变就是第一版糊成泥的原因。
- 语义色七色照契约给，从光谱里各取一段并压低饱和度，保证 ≥4.5:1。
- 对比度目标与 base.css 同口径：正文 ≥12:1、次要 ≥7:1、最弱 ≥4.5:1。

## 五、字体：借用官方的「三元」结构，但只能用系统栈

[Kimi 官方品牌手册](https://www.kimi.ai/resources/kimi-brand) 规定了三元字体 **Inter / Geist Mono / Sentient**，
但契约明令**不得引入外部字体文件**，所以只借结构、不借字体：

- 标题 → `--kami-font-title`：系统衬线栈（`Georgia, "Songti SC", "Source Han Serif SC", serif`）＝手册里「Sentient 的文学温度」
- 编号 / 计数 / 元数据 → `--kami-font-mono`：等宽栈 ＝「Geist Mono 的开发者精度」
- 正文 → `--kami-font`：系统无衬线栈 ＝「Inter 的功能效率」

## 六、特效与参数

| effects id | 名称 | 做什么 | 默认 |
|---|---|---|---|
| `prism` | 棱镜事件 | 题头一次白光 → 三棱镜 → 六色带 | 开 |
| `vinyl` | 黑胶刻槽 | 外壳偏心同心圆纹理 | 开 |
| `pulse` | 心跳线 | 状态区一条心电波形（`clip-path` 裁出 2px 细带，纯 CSS） | 开 |
| `ghost` | 失焦拖影 | 面板题头文字轻微拖影，取官方站首页的失焦字气质 | 关 |

params（皮肤私有令牌 `--kami-moon-*`）：光谱带宽 0–100、刻槽浓度 0–100、波形振幅 0–12px、辉光半径 0–12px。

## 七、已核实的官方依据（我自己 fetch 过原文，不是二手解读）

- [Kimi 官方品牌手册](https://www.kimi.ai/resources/kimi-brand)：三元字体（Inter / Geist Mono / Sentient）、
  基底网格 + 表现网格、「Organic Digital Textures」（自然纹理转为数字像素阵列，做安静的画布底）、
  以及「以品牌蓝为中心的完整色彩架构」——**原文说的是 signature brand blue，不是我上一轮写的「电光蓝」**。
- [MoMA 馆藏记录](https://www.moma.org/collection/works/185416)：1973 年封面插画为石版画作品（版权归口明确）。
- [Pentagram 50 周年全案](https://www.pentagram.com/work/the-dark-side-of-the-moon)：原案出自 Hipgnosis 的 Storm Thorgerson，
  插画 George Hardie。
- [V&A 图形身份特稿](https://www.vam.ac.uk/articles/the-graphic-identity-of-pink-floyd)：Richard Wright 当时的要求是
  「不要再做超现实拼贴，要像 Black Magic 巧克力盒那样简单高级」；灵感来自物理教科书里光线穿过玻璃镇纸的插图。
- 官方站实拍读数（2026-10-01）：Moonshot 首页底色 `#000000`、主文字 `rgba(255,255,255,.56)`、按钮圆角 8px；
  Kimi 主站底色 `rgb(24,24,23)`、文字 `rgba(255,255,255,.84)`。**官方按钮是 8px 小圆角，不是胶囊** —— 这一条直接支持本版把圆角压小。

## 八、版权边界

不复制、不描摹：原版棱镜石版画的几何路径、Pink Floyd 商标与乐队标准字、厂牌图标、官方封套扫描图，
以及 Kimi 的 logo 与品牌图形。只借：**入射—分光—再汇聚**的物理机制、深空底与极简对比、六色硬边色带、心跳波形。
不引入任何外部字体、图片、`url()` 或 `@import`（契约硬规则）。
