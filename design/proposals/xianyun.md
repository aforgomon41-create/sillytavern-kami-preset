# 皮肤设计简报：闲云野鹤（`xianyun`）

> 本文是皮肤 `xianyun`（中文名「闲云野鹤」）的设计简报与决策备忘，供后续迭代与审查查阅。

---

## 一、概念与设计语言

**设计语言一句话**：
> **水墨修仙：大片宣纸留白、层叠水墨晕染、浓淡干湿有致，点缀一抹古雅朱砂印。**

核心基调：
- **黑白为主**：大面积温润生宣米白（#f7f5f0 / #fdfcf9），搭配沉稳浓墨黑（#1a1a1c）与淡墨黛灰（#464649 / #737378）。
- **水墨晕染**：通过 CSS 多层 `radial-gradient` 与柔和淡墨阴影，模拟水墨在宣纸上自然渗透、干湿浓淡相生的质感。
- **大片留白**：通过大内边距与通透的卡片间距，传达仙风道骨、闲云自适的悠远意境。
- **朱砂点睛**：纯正朱砂红（#b82424）仅占界面总面积 ≤5%，作为核心强调色与印章点缀，绝不大面积泼洒。
- **本地书法字体栈**（契约 §2 硬约束）：
  - 标题栈 `--kami-font-title`: `"KaiTi", "STKaiti", "楷体", "Kaiti SC", "KaiTi_GB2312", "LiSu", "隶书", "STSong", "宋体", "Songti SC", serif;`
  - 正文栈 `--kami-font`: `"Songti SC", "STSong", "宋体", "Noto Serif CJK SC", "Source Han Serif SC", serif;`
  - 代码栈 `--kami-font-mono`: `ui-monospace, SFMono-Regular, "Cascadia Mono", Consolas, "Courier New", monospace;`

## 二、身份符号（单一视觉焦点）

**唯一身份符号**：**朱砂方印（钤印角章）**。
- **表现形式**：在选中状态（`.is-on`）、关键标题或操作按钮上，以古雅朱砂方框印章或朱砂印泥反白呈现（红底纯白字，带微细方印边框）。
- **约束**：不做复杂或喧宾夺主的装饰，避免堆砌太极、仙鹤图形；依靠纯正的水墨留白与朱砂印章形成极高辨识度。

## 三、配色关系与对比度设计

### 1. 面积分配
- **宣纸白 / 留白底色**（`--kami-bg`, `--kami-card`）：约 75%
- **水墨黑 / 焦墨灰**（`--kami-fg`, `--kami-fg-dim`, `--kami-line`）：约 20%
- **朱砂红**（`--kami-accent`, `--kami-accent-line` 等）：≤ 5%

### 2. 核心色板与对比度计算（WCAG 2.1）
- **默认亮色（素宣闲云）**：
  - 容器底色 `--kami-bg`: `#f7f5f0`（熟宣米白）
  - 卡片底色 `--kami-card`: `#ffffff`（净白宣纸卡）
  - 主正文字 `--kami-fg`: `#1a1a1c`（浓墨黑）→ 对 `#ffffff` 对比度 **16.6:1**，对 `#f7f5f0` **15.2:1**（远超 4.5:1）
  - 次要文字 `--kami-fg-dim`: `#464649`（焦墨灰）→ 对 `#ffffff` 对比度 **9.1:1**，对 `#f7f5f0` **8.4:1**
  - 最弱文字 `--kami-fg-mute`: `#737378`（淡墨灰）→ 对 `#ffffff` 对比度 **4.8:1**，对 `#f7f5f0` **4.5:1**
  - 朱砂强调色 `--kami-accent`: `#b82424`（朱砂红）→ 纯白字在其上对比度 **5.6:1**
  - 描边强档 `--kami-line-strong`: `rgba(28, 28, 30, 0.45)`（墨线，对纸白底 ≥ 3.3:1）
- **暗色方案（墨夜寒潭，`data-kami-scheme="dark"`）**：
  - 容器底色 `--kami-bg`: `#121417`（夜墨深潭）
  - 卡片底色 `--kami-card`: `#1c1f24`（古砚墨石）
  - 主正文字 `--kami-fg`: `#ede8df`（纸白白字）→ 对 `#1c1f24` 对比度 **13.5:1**
  - 次要文字 `--kami-fg-dim`: `#b5b0a7`（淡墨宣白）→ 对 `#1c1f24` 对比度 **7.8:1**
  - 朱砂强调色 `--kami-accent`: `#d94141`（夜色朱砂）→ 墨黑字在其上对比度 **6.8:1**

### 3. 语义色（`--kami-kind-*` 七色）
在水墨黑白基底上采用传统国画天然矿物与植物颜料色相，互相区分清晰且均满足可读性：
- `--kami-kind-action`: `#225577`（石青 / 靛蓝，7.3:1）
- `--kami-kind-persona`: `#8c2d52`（胭脂 / 绛红，6.8:1）
- `--kami-kind-plot`: `#286b45`（松柏绿 / 竹青，6.2:1）
- `--kami-kind-info`: `#246a78`（浅黛 / 苍蓝，5.8:1）
- `--kami-kind-fun`: `#915e12`（雄黄 / 琥珀，5.2:1）
- `--kami-kind-nsfw`: `#b82424`（朱砂 / 赤红，5.6:1）
- `--kami-kind-other`: `#555861`（水墨黛灰，6.1:1）

## 四、参考与边界

1. **零外部资源**：严禁 `@import`、`@font-face`、网络图片 URL。字体完全使用操作系统自带的高品质楷/宋书法字体。
2. **纯 CSS 渲染**：宣纸纹理、墨晕效果、云气与印章边框全部使用纯 CSS（线性/径向渐变、box-shadow、border、filter: blur 等），无外部素材依赖。
3. **性能边界**：墨晕效果限制在静态伪元素与容器边缘，避免在每一帧动画上计算复杂 blur 或 backdrop-filter。
4. **反转翻转纪律**：在 `.is-on` 激活或朱砂底状态下，严格将 `--kami-fg` / `--kami-fg-dim` / `--kami-fg-mute` / `--kami-line` 成对翻转为 `--kami-accent-fg`（纯白反字），坚决杜绝 1.00:1 黑底黑字或红底红字事故。
5. **对比度四件套**：`.kami-number` / `.kami-text` / `.kami-textarea` / `.kami-select` 的 `background-color` + `color` + `color-scheme` 均带 `!important` 严格封锁宿主与用户自定义深色 CSS 污染。
6. **锁死条目友好反馈**：对带 `[disabled]` 的条目卡与按钮给出明确的锁死状态（降低不透明度至 `.42`，字体置灰为淡墨色，鼠标指针设为 `default`，消除 `:hover` 伪元素动画与位移）。
7. **窄屏自适应适配**：针对 `@media (max-width: 560px)` 与 `@media (max-width: 380px)` 分别将网格最小列宽调为 `152px`（两列）与 `108px`（紧凑两列），行高提升至 `44px`，确保移动端触控命中率。
