# crt80s · 扫描显示 — 设计简报

## 一、设计语言一句话
一台上世纪八十年代的荧光单色终端机被接进了聊天流：方角深色机身、等宽字、磷光余晖，
文字像是从玻璃后面亮起来的。

## 二、身份符号（只留一个）
**整屏扫描线 + 玻璃弧面反光**（默认开启的 `scan` 特效 + 常驻的顶部弧面高光纹理）。
- 扫描线用 `repeating-linear-gradient` 平铺静态暗线（间距可调，低透明度，不逐帧动画、不用大面积 blur）。
- 玻璃弧面反光走常驻 `--kami-texture`：顶部一道横向高光弧 + 极淡的磷光晕影，任何特效开关下都在。
- 网格地平线**不做身份符号**，只作为可选装饰特效（`grid`，静态透视渐变，默认关）。

## 三、配色关系
- **主调（约 85% 面积）**：近黑的深绿底 `#0a120c` 一族（机身、卡、正文块全是同一族不同明度），
  文字全部是荧光绿一族的明度阶梯（正文 `#8affa9` ≈ 11:1，次要 10.6:1，最弱 5.9:1）。
- **强调色（约 10%）**：亮荧光绿 `#3dff7c`，只出现在状态点、选中描边、主按钮、tab 下划线。
- **语义色（约 5%）**：七种 `--kami-kind-*` 是「同一台显示器上的彩色磷光」——统一高明度、
  低饱和差异，只靠色相区分，且都压深底 ≥4.5:1。
- **明暗两档 = 两种单色**：暗档是荧光绿终端，亮档是琥珀终端（米黄纸底 `#f2ead2` + 深琥珀字），
  契合「单色显示器只有一种荧光」的历史设定；`amber` 特效再把暗档整体换成琥珀荧光（仅暗档，避免亮底上亮琥珀字不可读）。
- **语义色区分**：暗档用亮色相（天蓝/桃粉/草绿/青/金黄/玫红/灰绿），亮档用深色相，同族明度。

## 四、参考与边界
- 参考：80 年代单色 CRT 终端（VT 系列琥珀屏、绿屏）、早期 Mac/terminal 界面的方角与等宽排版、
  复古未来主义插画里的网格地平线。**只借语言（扫描线、磷光辉光、方角机身、等宽字），不抄任何素材**——
  所有纹理与网格都是原生 CSS 渐变，无外链、无 SVG 素材、无位图。
- 边界：不用逐帧 blur/backdrop-filter 动画；扫描线是静态暗线（透明度 ≤0.16），不压灰正文；
  辉光只用 text-shadow/box-shadow 且幅度受参数控制；闪烁特效默认关、reduced-motion 下一律静止。

## 五、实测读数（回填区）
- lint：`node build/lint-skins.mjs crt80s` → `PASS  crt80s  (49595B, 81 令牌)`。
- 暗档正文对比度（#8affa9 on #0c130d 合成）：≈15.4:1；最弱 #4f8f66 ≈4.9:1；强调字 14.3:1。
- 亮档正文对比度（#33260e on #f2ead2）：≈12.3:1；最弱 #7a6636 ≈4.6:1；强调字 5.3:1。
- 预览台实测（端口 8801，tab 式逐格过）：
  - #diag 文案令牌生效：think-title=终端记录 / think-title-open=终端记录·展开 / options-title=指令选项；标题栏溢出=0。
  - 渗漏探针：消息 iframe 里 root/grid 令牌均为 232px（面板的 104px 紧凑档没有渗进楼层）。
  - 🌟 预设设置（桌面 420px 面板）：351px 网格 → 3 列，卡 112px；带 ⓘ 注释卡与同行等高（83/83/83）；
    锁定条目禁用正常；面板内/页面溢出均为 0。
  - 🌟 窄屏（377px 视口）：面板变成覆盖 78% 高度的贴底抽屉，tab 轨完整。
  - 💭 think：收起 48px / 展开约 400px，渲染与原文切换正常。
  - 🎯 options：6 卡 3 列，语义徽章分色可辨。
  - 📜 压缩：数字框 / 下拉 / 多行提示词全部荧光绿字压暗底，可读。
  - 亮色 scheme 切换实测：琥珀纸底 + 深琥珀字，对比可读。
- 浏览器工位被并行 skin agent 多次抢占（tab 被切走、会话被清），以下几条只有代码级核对、未实测：
  「琥珀荧光 / 网格地平线」两个特效打开后的画面、动效 calm/off 档位、320px 极窄。
- skin.json 的浓度参数 `unit` 必须是空串（`55` 裸数字供 calc 用）；初版误写 `%`，预览台下发出 `55%`
  会让 alpha 计算失真，已改为空串后复测正常。
