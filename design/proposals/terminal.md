# 皮肤设计简报：终端（`terminal`）

> 本文是**动手写 CSS 之前**定的四件事，以及实现后的实测读数。
> 后来改这套皮肤的人，先看 §三「踩过的坑」，再看 §四「实测」。

## 一、设计语言一句话

**一块深色终端窗口：等宽字体、零圆角方框、双线外框、方括号标签，加一个一直在闪的方块光标。**

四个语言要素与它们各自的位置：

| 要素 | 落在哪 |
|---|---|
| 等宽字体 | 正文字体、标题字体、等宽字体三份令牌**全是同一套 monospace 系统栈**（不引外部字体） |
| ASCII 边框 | `1px 外框 + 内缩 3px 的 1px 内细线`＝双线框（伪元素画，见 §二） |
| 光标闪烁 | `.kami-dot` 开态 = 实心方块 + `steps(1)` 硬闪；空态末尾也有一枚 |
| 方括号标签 | `.kami-chip` / `.kami-badge`（消息楼层）/ `.kami-tab` 的 `::before{content:"["}` + `::after{content:"]"}` |

## 二、身份符号（只留一个）

**「方括号标签 `[ ]` ＋ 闪烁方块光标 `▌`」算一套**——它们是同一条命令行标记语言的两个字，不是两个 competing 的记号。

- `.kami-dot` 关态 = **空心方框**（只有 1px 描边、内部透明）；开态 = **实心方块并闪烁**。
  「关＝空框、开＝实心块」本身就不是只靠颜色（形状占了一样）。
- `.kami-empty` 前面一枚 `$ ` 提示符、后面一枚闪烁方块：同一个符号延伸到空态。
- markdown 引用块 `blockquote::before{content:"> "}`：终端里"引用别人的输出"就长这样。

**明确不做的两件事**（写在这里，省得后来的人再试一遍）：

1. **不用盒画字符（`┌ ─ ┐ │ └ ┘`）拼四角。** 两条理由：① `─`/`│` 的字体回退与四角对齐在真机上不稳——等宽栈里 CJK 回退字体一换，半格错位立刻看得见；② 它会跟方括号标签抢"谁是记号"。
   ASCII 边框最终落成**双线框**：元素自身 1px 外框 ＋ `::before` 在内缩 3px 处再画一道 1px 细线。看起来是 TUI 的双线外框，但全是普通边框，没有任何字形依赖。
2. **不做 CRT 扫描线做主纹。** 扫描线只作为可选特效 `scanline` 挂在 `.kami-surface::after` 上，默认关（见 §五）。主纹是极淡的暗角渐变，静态、零动画。

## 三、配色关系

- **面积**：暗档下主调（近黑绿灰 `#0c110d` 一族）占约 85%；中性前景 `--kami-fg` 承担**全部**正文；强调色只做"点"——状态光标、选中描边、主按钮底、行内 code。**主调只有两种颜色：一层中性前景 + 一层亮绿强调**，第三色（琥珀）只出现在 `--kami-kind-fun` 与警示上，不参与主调。
- **两套都写全**（`data-kami-scheme="dark"` 默认 / `"light"` 纸白墨绿），不存在"只推算不实测"的那一档。
- **七个语义色**各给一个色相、同一档明度与饱和度；暗档提亮、亮档压深，实测在两档的卡底与正文块底上都 ≥ 4.5:1（读数见 §四）。
- **对比度是硬线不是风格**：终端感容易滑向"绿字压黑底看不清"，所以 `--kami-fg` 用**中性**浅灰绿（不是荧光绿），荧光绿只给强调色。暗档实测正文最差 12.81:1，亮档最差 13.69:1。

## 四、参考与边界

- **参考**：经典 TUI 的状态栏与分栏（vim / tmux / htop 的等宽栅格、方括号标签、实心选中块），以及老终端的"亮字压深底"。
- **只借语言，不抄素材**：没有图片、没有字体文件、没有 SVG 路径数据；纹理全部是 `repeating-linear-gradient` 与 `radial-gradient`。
- **边界**：辉光只在强调色上做小半径 `text-shadow` / `box-shadow`（参数可调、可关）；不做大面积 `backdrop-filter`（契约 §2.8 的性能纪律，皮肤 CSS 会进每一个聊天楼层）。

### 实现中改过的一处

选中态原本写 `border-width: 2px`，引导页实测选中卡比同行卡**高 3px**（`195x45[选中]` vs `195x42`）——
点一下卡片就跳高。改成「1px 边 + `inset 0 0 0 1px` 内环 + 加粗 + 淡染底」，
形状/边线/字重三样都还在，但不再改变盒子高度。

## 七、给后来的人的坑

1. **等宽字体下 `--kami-items-min` 要按 rem 给**：面板网格密集判据必须写 `.kami-grid:has(> .kami-item, > .kami-item-note)`（漏了 `.kami-item-note` 就静默退回单列）。
2. **`--kami-r-pill: 0px`**：零圆角是这套皮肤的骨架，别为了"好看"把某一档调回圆角。
3. **`.kami-shell` 与 `.kami-surface` 常是同一个元素**：`.kami-shell` 上只写 `background-color` / `background-image` 长写属性，别写 `background` 简写（会把 `.kami-surface` 的纹理重置掉）。
4. **选中换底 → 字必须翻**：`.kami-btn.is-on` / `.kami-item.is-on` 用强调底时，卡作用域里的 `--kami-fg` / `-dim` / `-mute` / `--kami-line` / `--kami-line-strong` 一族整体翻成 `--kami-accent-fg`（这条历史上翻过三次车）。
5. **`.kami-dot` 被引导向导的进度点复用**（`.kami-dots .kami-dot`）：方块光标规则必须把进度点排除掉，否则一页五个点一起闪。
