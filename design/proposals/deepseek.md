# 大肥鱼 / DeepSeek

用户于 2026-10-17 要求丰富装饰、允许扩展契约和管理脚本，并审阅第二版后回复“可以动手吧”。完整记录见 [前端设计](../../docs/frontend-design.md)。

- 语言：蓝白、圆角、虎鲸边饰与指定的鲸鱼娘；动物形态按用户纠正采用虎鲸。
- 布局：装饰分布在标题、选项、卡片标题、主按钮、开关、滑杆、数字输入、空态、消息页脚和边缘背景。各处复用平台已有组件，不加入业务分支。
- 三组特效：鲸鱼娘挂件 / 海洋背景 / 特色控件，均可关闭并沿用平台记忆；额外可调背景浓度与标题挂件大小。
- 资源：5 张静态 WebP，共 189684 字节，元数据 assets 声明并通过共享图片池供消息、宿主和皮肤卡使用；无外链图片、常驻扫描或循环动画。
- 配色：明档白与浅蓝，暗档深蓝灰；强调蓝只用于操作和状态，文本保持足够对比。
- 来源：[DeepSeek 官网](https://www.deepseek.com/)，鲸鱼娘原角色 [上善无形](https://space.bilibili.com/4456176)，女仆版二创设定参考 [ZipZipPipe](https://space.bilibili.com/4168597)。本包使用经用户授权生成的新图，不含创作者参考原图。完整记录见 [素材说明](../assets/deepseek/README.md)。
