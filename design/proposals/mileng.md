# 皮肤设计简报：军事工程（`mileng`）

> 动手写 CSS 之前定的四件事。实现后的实测读数在文末回写。

## 一、设计语言一句话

**一张军用装备的面板标识板：军绿压仓底、沙色喷字标题（全大写、字距拉开的模板喷字）、编号刻度带做骨架记号，警示斜纹只许出现在边条与提示上。**

要素落点：

| 要素 | 落在哪 |
|---|---|
| 模板喷字 | `--kami-title-transform: uppercase` + `--kami-ls-title` 拉大；标题/徽记/数字一律小面积、不描边（不用 `-webkit-text-stroke`，小字会糊） |
| 编号刻度带 | 头部条 `.kami-head` 底部一道刻度线（特效 `ticks`）；网格条目的卡头编号 `NO.01` 式计数器 |
| 军绿沙色 | 底色三层明度阶梯（仓底 / 卡底 / 正文块底），前景是沙色系而非草色 |
| 警示斜纹 | `repeating-linear-gradient(45deg…)`，只出现在脚条上缘、警示提示与主按钮边缘（特效 `hazard`），永不铺满组件 |

## 二、身份符号（只留一个）

**模板喷字的编号刻度**：全大写拉字距的标题 ＋ 头部刻度尺 ＋ 条目卡头的 `01 / 02 …` 编号。
三处是同一个记号系统的三件套，不与斜纹、颗粒抢地位。斜纹（`hazard`）与颗粒（`grain`）只是可关特效，默认斜纹关。

## 三、配色关系

- **面积**：军绿压仓底约 85%，沙色前景一族承担全部正文；沙黄强调色只做「点」——状态灯、选中环、主按钮、编号。第三色只为语义色服务。
- **军绿是低饱和色，明度差必须拉**：暗档正文用沙白 `#e9e1c8` 压深军绿底，明度差大（实测见下），绝不写「深绿字压军绿底」。
- **对比度硬线（WCAG 2.1 逐对实算）**：
  - 暗档：fg/bg ≈ 14.2、fg/card ≈ 12.7、fg/card-2 ≈ 15.9、fg-dim/card-2 ≈ 8.6 —— 均 ≥ 4.5。
  - 亮档：沙纸底 `#ece5d1` 一族，墨绿字 `#262b15`，各对 ≥ 10。强调底（沙黄 `#d8a93c`）上压近黑字 ≥ 7。
  - 强描边（line-strong 用沙黄 45%）：对卡底 ≈ 3.2，≥ 3。
- **七个语义色靠「色相 + 明度」双区分**（同档明度、各自饱和）：行动=钢蓝、性格=沙玫瑰、推进=灰绿、信息=青灰、搞笑=布黄、nsfw=锈红、other=装备灰；亮档整体压深。

## 四、参考与边界

- **参考**：军械库的装备标牌（编号钢印、警示黄黑斜纹）、milspec 技术文档的栏头刻度；只借这套视觉语言。
- **不抄素材**：无图片、无字体文件、无 SVG 路径数据；纹理全部是 CSS 渐变。
- **边界**：`--kami-blur: 0px`（工业面板不做玻璃，省每层 backdrop-filter）；循环动画只有信号灯一档且在 calm/off/reduce 下直接停；45° 斜纹只画边条，单层面积小。
