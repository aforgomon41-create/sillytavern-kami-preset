# 皮肤设计简报：文明启蒙（`civdawn`）

> 本文是**动手写 CSS 之前**定的四件事，以及实现后的实测读数。
> 后来改这套皮肤的人，先看 §三「踩过的坑」，再看 §四「实测」。

## 一、设计语言一句话

**文明早期蒙昧时代：赭石土黄、洞穴壁画刻痕、陶纹石板与原始岩彩。**

四个语言要素与它们各自的位置：

| 要素 | 落在哪 |
|---|---|
| 原始岩壁与陶土基底 | 背景与卡片使用低饱和土黄/赭褐/泥灰层次，微细岩石土粒（双层极淡渐变）模拟岩壁陶板 |
| 陶纹石板凿刻线 | 卡片与容器边框微错位双线或凿刻凹线，卡头与分隔条采用平行刻线与陶纹回形折角 |
| 凹刻字与阴影 | 标题与关键文字使用 `text-shadow`（下暗上亮 1px）营造石壁阴刻感，内阴影营造凿刻凹陷 |
| 洞窟岩彩语义色 | 七种语义色取自天然矿物与原始岩彩（靛蓝、朱砂、苔绿、松石、黄赭、红褐、燧灰） |

## 二、身份符号（只留一个）

**「陶纹刻痕与岩壁凿痕」**算核心身份符号 —— 它贯穿边框、卡头、分隔条与状态点。

- `.kami-dot` 关态 = **凹刻环形陶印**（1px 泥色凹刻线）；开态 = **赭红燧石火种**并带有呼吸式微光。
- 卡片与面板外壳：带有原始手工石板的微小各角圆角差异（`border-radius: 4px 6px 3px 5px`），避免工业化完美倒角。
- 卡头与分隔条：带有陶纹平行刻痕装饰（通过双线或伪元素刻线点缀）。
- `.kami-empty` 空态呈现如荒原石板般的刻痕占位。

**明确不做的两件事**：

1. **不用大面积复杂 filter/backdrop-filter 滤镜。** 避免每一帧动画重绘滤镜导致性能开销，岩壁质感与刻痕全走静态渐变与 text-shadow / box-shadow 凹刻。
2. **不堆砌多种不同时期的符号。** 严格收敛于新石器早期与洞穴壁画的纯粹刻痕与天然矿物色彩，不混入青铜器饕餮纹或后期符咒。

## 三、配色关系

- **面积**：暗档下深岩主调（`#231c16` / `#352a22`）占约 85%；中性骨白 `--kami-fg`（`#f0e8d5`）承担**全部**正文，次要文字用赭黄泥色（`#c4b196`）；强调色采用洞穴壁画与燧石火光的**赭红橙**（`#d9653b`），强调底上的字使用深岩褐（`#1c120c`，对比度 > 7:1）。
- **两套都写全**：
  - 暗色（默认）：深岩赭褐底 + 骨白字 + 赭红燧石火光强调。
  - 亮色（日晒陶板）：浅黄陶泥底（`#ece2ce` / `#fbf5e8`） + 焦黑深褐字（`#261a12`） + 浓赭红朱砂强调（`#b54826`）。
- **七个语义色**：
  - 行动 (action): 靛青矿物 `#7aa5cc` (暗) / `#29557d` (亮)
  - 性格 (persona): 赭红朱砂 `#e27866` (暗) / `#a63a28` (亮)
  - 推进 (plot): 苔藓草绿 `#8db570` (暗) / `#3d6926` (亮)
  - 信息 (info): 绿松石青 `#6db5ac` (暗) / `#26665f` (亮)
  - 搞笑 (fun): 暖土黄赭 `#dfa74d` (暗) / `#885c10` (亮)
  - nsfw (nsfw): 陶土红褐 `#d97184` (暗) / `#923648` (亮)
  - 其他 (other): 燧石冷灰 `#9fa39e` (暗) / `#545753` (亮)
- **对比度**：严格遵循 WCAG 2.1 AA 标准（≥ 4.5:1），暗色正文对比度实测最低 11.43:1，亮色次要文字对比度最低 6.08:1。

## 四、参考与边界

- **参考**：阿尔塔米拉与拉斯科洞穴岩画、仰韶早期彩陶几何刻划符号、原始打制与磨制石器刻痕。
- **只借语言，不抄素材**：无外部图片、无外部字体、无外部网络请求。纹理均由 CSS `repeating-linear-gradient` 与 `radial-gradient` 生成。
- **边界**：刻痕只在边条、卡头和分隔线上使用，绝不干扰正文文字的可读性。
