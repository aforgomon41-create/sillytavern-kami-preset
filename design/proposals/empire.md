# 帝国与征服 · 皮肤「统御」（empire）设计简报

> 交付物：`src/skins/empire/skin.json` + `src/skins/empire/skin.css`。本文是动 CSS 之前定的稿。

## 一、设计语言（一句话）

**「一道深紫天鹅绒上的敕令」** —— 深紫做底、金只做敕令的描边与印记、暗红只做禁与危，
标题一律庄严衬线，圆角收小到 2–8px，整张界面像一块盖了金边框的帝国诏版。

## 二、身份符号（只留一个）

**一枚纯 CSS 自绘的纹章盾徽**（`clip-path` 六边形盾 + 金色渐变盾缘 + 内置等臂十字），
出现在两处：消息楼层（思维链 / 行动选项）标题左侧、面板标题栏的标题左侧。
除此之外**不再做第二个记号**：没有双线外框、没有角花、没有单独的火漆印。

- 盾形：`polygon(50% 0%, 100% 14%, 100% 52%, 50% 100%, 0 52%, 0 14%)`
- 盾缘：外层伪元素铺金色渐变（`--kami-accent` → 暗金），内层伪元素缩到 78% 铺深紫底 + 十字
- 十字：内层上再叠两条 `linear-gradient`（一竖一横），只用现有令牌，零外链、零 SVG 路径数据
- 骨架不靠它：材质（深紫天鹅绒 + 织纹）、衬线、小圆角、明度阶梯四件单独也立得住，
  纹章被否掉也不至于整套散架

## 三、配色关系（三色分工 + 七种语义色）

| 角色 | 取值 | 面积 / 用途 |
|---|---|---|
| 暗紫（底） | `#16101f` / `#1d1529` / `#221833` / `#191223` | 占 80% 以上，容器 / 次级容器 / 卡片 / 卡内正文四档明度阶梯 |
| 金（强调） | `#d8b45f`（暗档）/ `#7a5c10`（亮档） | ≤10%：标题字、选中描边、主按钮底、ⓘ 记号、纹章、tab 底线 |
| 暗红（危险） | `--kami-warn: #e8604a`（暗档）/ `#b3261e`（亮档） | 只做「发送失败 / is-bad」一类语义，不进主调 |

**金只做点不做面**：金从不做大面积底色，唯一例外是 `.kami-btn--primary` 与 toast（小块），
其上文字用 `--kami-accent-fg`（暗档深紫 `#1b1226`，9.14:1；亮档 `#fdf8ec`，5.89:1）。

## 四、对比度（WCAG 2.1 相对亮度实算，脚本核算过）

- 暗档：正文 15.33:1（对 `--kami-bg`）/ 13.87:1（对 `--kami-card`）/ 15.01:1（对 `--kami-card-2`）；
  次要 9.38:1；最弱 5.59:1；金当文字 8.51–9.41:1；强调底上的字 9.14:1
- 亮档：正文 14.53 / 16.59 / 13.49:1；次要 7.59:1；最弱 5.88:1；金当文字 5.07–6.24:1；强调底上的字 5.89:1
- 控件边线档（`--kami-line-strong`）对卡片底：暗档 3.49:1、亮档 3.78:1，均 ≥ 3:1
- 七种语义色对卡底最低 5.45:1（暗档 `nsfw`）、对 `--kami-card-2` 最低 4.44:1（亮档 `fun`，仅作徽章小字）

## 五、参考与边界（只借语言，不抄素材）

- 参考 `src/skins/terminal/`（结构厚度、锁死态与手机档的写法）与 `src/skins/wod/`（暗色 + 衬线的配色分工）。
- **不抄**任何皮肤已有的 SVG 路径数据：纹章完全由 `clip-path` + 渐变 + 伪元素拼出。
- 字体只用系统衬线栈（`Times New Roman` / `Songti SC` / `STSong` / 宋体 / Georgia），**不许在线字体**。
- 三色分工是硬边界：金不上大面积、暗红不进主调、语义色不落紫区。破了这条就不是「统御」。

## 六、动效（三条，对应入场 / 强调 / 循环）

1. `kami-emp-in` —— 入场：折叠体、toast、卡片列表项 `opacity + translateY`（位移量走 `--kami-enter-y`）。
2. `kami-emp-sheen` —— 强调：纹章盾面上扫过一道金箔高光（`background-position` 动画），挂在 `crest` 特效上。
3. `kami-emp-beat` —— 循环：状态点「王城心跳」缓慢明暗，间隔走参数 `--kami-emp-pulse`。

`data-kami-motion="off"` / `calm` 与 `prefers-reduced-motion: reduce` 下，循环动画直接 `animation:none`
（不是压到 1ms），时长全部 1ms、位移归零。

## 七、参数与特效

| 特效 id | 文案 | 默认 | 做什么 |
|---|---|---|---|
| `crest` | 纹章亮徽 | 开 | 盾徽扫一道金箔高光并描一层金边光 |
| `glow` | 金箔辉光 | 开 | 标题 / 主按钮 / 选中卡描边带一层小半径金光 |
| `weave` | 紫绒暗纹 | 关 | 表面覆一层极淡的斜向织纹（静态，不上动画） |
| `beat` | 王城心跳 | 开 | 状态点缓慢明暗循环 |

| 参数 id | 文案 | 组 | 令牌 | 单位 | 区间 |
|---|---|---|---|---|---|
| `glow` | 辉光半径 | 光效 | `--kami-emp-glow` | px | 0–20，默认 6 |
| `weave` | 暗纹浓度 | 材质 | `--kami-emp-weave` | % | 0–100，默认 40 |
| `beat` | 心跳间隔 | 动效 | `--kami-emp-beat` | s | 0.8–3，默认 2 |

（`unit` 一律合法 CSS 单位，绝不写 `×` / `°`；`value` 都在区间内。）

**取舍**

- 纹章只出现在「消息楼层标题」与「面板标题」两处，不做满屏水印 —— 面积 ≤1%，够辨识不抢内容
- 金只在 `--kami-accent` 一处定义，暗档提亮到 `#d8b45f`（当文字用 8.51:1）、亮档压深到 `#7a5c10`
  （当文字用 5.07:1），两个档位都不靠低亮度金做正文
- 织纹（`weave`）默认关闭：它是唯一会改变整面底图的特效，默认开会让「金只做点」的纪律失真
