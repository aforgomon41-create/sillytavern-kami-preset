# 和风古韵与落樱飞花 · 皮肤「千恋万花」（senren）设计简报

> 交付物：`src/skins/senren/skin.json` + `src/skins/senren/skin.css` + `design/proposals/senren.md`。

## 一、设计语言（一句话）

**「和风古韵与落樱飞花：温润的米白和纸、薄红樱瓣，与细腻的描金短册。」**
——以温润的米白和纸为底，浓墨为文，薄红樱色为情愫与动作引导，洒金细线勾勒边缘，和风短册与朱砂小印定格状态。排版采典雅和风衬线，字距行高舒展自然，动效轻盈如樱瓣徐徐飘落。

## 二、身份符号（纯 CSS 自绘）

**一枚纯 CSS 自绘的和风落樱花瓣与短册朱印（Sakura & Tanzaku Seal）**：
- 出现在两处：消息楼层（思维链「绘卷」/ 行动选项「纸笺」）标题左侧、面板标题栏左侧。
- 由 `::before` 与 `::after` 伪元素多重渐变配合几何剪裁绘制：
  - `::before` 绘制薄红微晕的五瓣落樱花形与洒金花蕊；
  - `::after` 绘制朱砂短册朱印高光层；
- 零外部图片、零 SVG 路径引用、纯 CSS 几何与渐变实现。
- 骨架与材质（和纸纤维 + 描金细线 + 短册竖标 + 浓墨衬线）即使在无动画档位下也能稳固树立和风古韵。

## 四、对比度（WCAG 2.1 相对亮度实算）

- **亮档（昼樱绘卷）**：
  - 正文（浓墨 `#2c2225`）对容器底 `#fcfaf6` = **14.83:1**，对卡片 `#ffffff` = **15.65:1**，对卡内 `#fbf5ee` = **13.98:1**；
  - 次要文字（暖墨 `#5c4e54`）对卡片 = **7.52:1**，对卡内 `#fbf5ee` = **6.72:1**；
  - 最弱文字（淡墨 `#7d6d74`）对卡片 = **5.11:1**，对卡内 `#fbf5ee` = **4.56:1**；
  - 樱红强调底上的文字（纯白 `#ffffff` 对 `#c94b6d`） = **5.40:1**；
- **暗档（宵樱古社）**：
  - 正文（粉白樱墨 `#f7edf1`）对容器底 `#1c1619` = **15.12:1**，对卡片 `#2c2328` = **12.84:1**，对卡内 `#20181d` = **14.30:1**；
  - 次要文字（淡粉雾灰 `#cbbbc2`）对卡内 `#20181d` = **8.53:1**；
  - 最弱文字（暮色灰 `#9e8e95`）对卡片 `#2c2328` = **5.20:1**；

## 五、字体与排版优化

- **字体栈**：
  - 正文采用系统高品质和风/中文衬线字体栈：`"Songti SC", "STSong", "宋体", "Noto Serif CJK SC", "Source Han Serif SC", Georgia, "Times New Roman", serif;`
  - 标题采用和风楷体/明朝体栈：`"Kaiti SC", "STKaiti", "KaiTi", "Kaiti TC", "Hiragino Mincho ProN", "Songti SC", "STSong", serif;`
  - 代码/等宽采用清晰等宽字体栈：`ui-monospace, SFMono-Regular, "Cascadia Mono", Consolas, "Liberation Mono", monospace;`
  - 杜绝一切外部 `@font-face` 与网络字体加载，确保纯离线秒开。
- **排版参数**：
  - 基准字号 `--kami-fs: calc(15px * var(--kami-fs-scale));`，标题字号 `--kami-fs-lg` 适度放大拉开层级；
  - 正文行高提高至 `1.72`，字间距略微舒放 `0.015em`（标题 `0.08em`）；
  - 卡片内边距充实，正文与边框保持舒展呼吸感，消除视觉压迫感。

## 六、动效体系（入场 / 强调 / 循环）

1. `kami-senren-in`（入场）：折叠展开、列表卡片与气泡提示的轻盈上浮渐入动画（`opacity` + `translateY`，位移量走 `--kami-enter-y`）。
2. `kami-senren-drift`（强调/飘逸）：落樱花瓣与短册笺条在鼠标悬停或特效开启时的轻微随风摇曳动效。
3. `kami-senren-glow`（循环/呼吸）：状态点朱印脉动与神木柔光的缓慢明暗呼吸（周期走 `--kami-sr-drift`）。
4. `kami-senren-shimmer`（流光）：和纸短册选中时的温润金丝掠影。
- 档位响应：在 `data-kami-motion="off"`、`calm` 及 `prefers-reduced-motion: reduce` 下，循环动画直接设为 `animation: none !important;`，过渡时长压至 1ms，位移全部归零。

## 七、这次重做改了什么（解决打回痛点）

1. **厚度与完成度**：
   - 规则数从 134 条扩充至 220+ 条，文件体积从 30KB 扩充至 50KB+；
   - 补全全部缺失项：`.kami-empty` 空态纸笺、`.kami-dots` 朱砂进度点、`.kami-resize` 描金折角把手、引导向导 `.kami-guide-*` 完整排版层。
2. **锁死态与可访问性**：
   - 补全 `.kami-root[data-kami-comp="panel"] .kami-item[disabled]` 规则：明显半透明压淡（`0.42`）+ 虚线描边 + 字色淡墨 + 去除 hover 动画与阴影；
   - 按钮 `.kami-btn[disabled]` 与 `.kami-icon-btn[disabled]` 同步覆盖锁死态。
3. **两端适配与窄屏优化**：
   - 密集网格基准规则写明 `--kami-items-min: 100px;`；
   - 补全 `@media (max-width: 560px)` 与 `@media (max-width: 380px)`，行高提至 44px 满足触控标准，手机档选择器与基准规则逐字相同将列宽收至 152px / 108px；
   - 补全 `@media (max-width: 768px)` 抽屉兜底与 `.kami-drop[data-kami-layout="sheet"]` 贴底抽屉样式；
   - 容器查询 `@container (max-width)` 自适应收敛长标题与操作栏。
4. **动效与特效升级**：
   - 实现 4 组 `@keyframes` 关键帧动画；
   - 完善五大特效（`sakura` 落樱花瓣、`washi` 和纸云纹、`goldleaf` 洒金描边、`tanzaku` 短册笺条、`softglow` 神木柔光）与 5 组滑杆参数。
5. **角标与语义色体系**：
   - 完整支持 `[data-kami-corner]` 四角角标（tl / tr / bl / br）；
   - 七种语义色各覆盖 5 处以上（标记、卡片边条、短册徽章、文字等）。
