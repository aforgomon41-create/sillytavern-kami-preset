# SOLVE 默认曲库 v1

47 首公有领域古典录音，供 SOLVE 状态栏按场景情绪播放背景音乐。清单见 `library.json`（每首的标题、作曲家、标签、时长）。

- 来源：Musopen Kickstarter Recordings（https://archive.org/details/MusopenKickstarterRecordings ，CC0 1.0）与 Musopen – The Complete Chopin Collection（https://archive.org/details/musopen-chopin ，CC0 1.0）。
- 处理：从原始 MP3 解码后重新编码为 128 kbps 立体声 MP3，内容未剪辑。
- 许可：沿用原录音的 CC0 / 公有领域，可自由使用。
- 这个目录发布后不再修改；更新曲库会发到 v2 等新目录。
