1. **这一页目前只有一张卡片**：`renderToolboxTab()` 里手搓的「自动标签处理」。

### 2.2 参数页折叠 —— **最贴近的现成实现，可直接照抄**

`src\scripts\30-皮肤管理.js:1149-1178`（完整逐字）：

````js
    order.forEach(function (g) {
      var isFolded = folded[g] !== false ? true : false;
      /* 契约 §4.3 的折叠写法：外层 .kami-collapse + data-kami-open="0|1"，
         头是 .kami-head.kami-collapse-head（六套皮肤的箭头旋转规则都写成

         （.kami-head 提供 flex + gap + cursor 来自 .kami-collapse-head）。 */
      var wrap = mk('div', 'kami-card kami-collapse');
      wrap.setAttribute('data-kami-open', isFolded ? '0' : '1');
      var head = mk('div', 'kami-head kami-collapse-head');
      head.appendChild(mk('span', 'kami-chev', '▸'));

      var bodyBox = mk('div', 'kami-card-body kami-collapse-body');
      groups[g].forEach(function (p) { bodyBox.appendChild(paramRow(p)); });
````

## 3. 折叠状态怎么表达最省事

**结论：用契约已登记的 `.kami-collapse` + `data-kami-open="0|1"`。**
**不要用 `<details>/<summary>`，不要自造 `.is-open` / `.is-folded`。**

理由（全部有据）：

1. **已在契约里**：`docs\皮肤契约.md:393-394`（类名表）、`:449-464`（DOM 形状）、`:476`（状态钩子）。
   而契约 `docs\皮肤契约.md:314-315` 明文：「组件一律使用下列类名，**不得新增未登记的类名**（新增必须回到本文件登记）」。
2. **`<details>/<summary>` 全项目零使用**：在 `src\skins` 里 grep `details|summary` = **0 匹配**。
   引入它意味着：浏览器默认外观要额外重置（违反契约 §0「前端不写外观」）；
   `open` 属性不在 `data-kami-open` 这套钩子里，15 套皮肤**全部要重写**；
   并且业务里本来就有 `<details>` 语义冲突（`build\verify-tags-pure.mjs:70` 把 `details` 登记成 HTML 卡片区的排除标签）。
3. **15 套皮肤已经全部写过折叠规则**（见 §4.2 表），换机制 = 15 份 CSS 白写。
4. **显隐已经有人管**：皮肤管理脚本注入的 `STRUCT_CSS`（30:195-196）就是干这个的，
   前端**一行 display 都不用写**（契约 §0：前端只负责 DOM 结构、类名、状态属性、事件）。

### 5.2 与「参数页折叠」的现状对比

参数页折叠**故意不持久化**：`src\scripts\30-皮肤管理.js:1129` 的 `var folded = {};`

### 5.3 建议（含取舍）

**建议：第一版「不持久化」，语义跟参数页完全一致（每次打开面板都折着）。**

理由：
- 用户原话是「**默认折叠**」——「默认」指的正是「初始态」，参数页（既有先例）就是这么理解的；
- 改动面最小：**不碰 `readVars` / `saveVars`**（40:2875-2924），少 2 处改动、少 1 个新键；
- 「记住状态」有反直觉副作用：用户上次收着，下次打开**什么都看不到**，会以为面板坏了 ——
  而这页恰恰是「不知道塞哪儿的功能入口」，本来就该自报家门。

**若用户明确要「记住」（例如把标签处理当高频工具，希望一打开就是展开的）：** 成本约 4 行：

1. 加常量（挨着 40:1989-1990）：`var FOLD_VAR = 'foldBox';`
2. 加模块级状态（挨着 40:2035 一带）：`var foldBox = null;`（null = 还没读过）
3. `readVars()` 里加一行（照 :2894 结构）：
   `if (typeof saved[FOLD_VAR] === 'boolean') { foldBox = saved[FOLD_VAR]; }`
4. `saveVars()` 的 `all[VARS_KEY] = {…}` 里加一行：`foldBox: foldBox,`
5. `renderToolboxTab()` 里用 `foldBox === false` 决定初始 `data-kami-open`；
   点击时 `foldBox = (data-kami-open === '1')` 并调 `saveVars()`

⚠️ **不要用 `localStorage`**：7 个脚本一律走脚本变量通道，且 `localStorage`
不跟预设走（换预设/换设备会串味）。**没查到**任何一处用 `localStorage` 存面板状态的先例。

⚠️ **键名建议**：若将来这一页要放多张卡，别用 `foldBox` 这种单值，
用对象（`{ tagfix: false, … }`）。理由见 §6.6。
