# 官方视觉资料核对

日期：2026-10-17。用途：GPT / Claude 皮肤修订与大肥鱼装饰预览。只读公开资料，未使用品牌站登录、未下载或再分发专有字体。

## GPT / OpenAI

- [Design Guidelines](https://openai.com/brand/) 是公开官方设计指南，覆盖名称、字标、Blossom、留白、用色与 OpenAI Sans 的特点。它是品牌呈现资料，不是完整组件库。
- [ChatGPT UI guidelines](https://developers.openai.com/plugins/concepts/ui-guidelines) 是更适合本项目的界面参考，讲系统字体、单色线框图标、清晰的间距、少量颜色与可访问性。旧 apps-sdk 地址目前跳转到 plugins 地址。
- [Apps SDK UI](https://openai.github.io/apps-sdk-ui/) 是官方组件演示入口；本轮未引入新框架或依赖。
- `brand.openai.com` 的完整品牌站跳转到认证页。未把登录后的内容、字体包或规范冒充为已读取资料。
- 本项目适配：保持灰阶、系统无衬线、克制的组件层次；不用生图重造商标，不靠大面积渐变或拟物纹样来“像 GPT”。

## Claude / Anthropic

- [官方品牌示例文档](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md) 确实存在。色板包含近黑 `#141413`、米白 `#faf9f5`、灰 `#b0aea5`、浅灰 `#e8e6dc`、陶土橙 `#d97757`，字体示例是 Poppins 与 Lora。
- 这份示例不能直接当成 Claude 产品全部视觉规范。实读 [Claude 官网](https://claude.com/) 的 HTML/CSS 和浏览器截图后，当前页面字体体系名为 `anthropicSans` / `anthropicSerif` / `anthropicMono`；基础样式还给出连续暖灰阶、陶土色及悬停色、灰阶主按钮、衬线大标题与细线分区。
- 样式证据：官网 `/_next/static/chunks/e5def80c1c13272b.css`，本轮读取可用；另一块非必要 CSS 请求失败，未据此猜测其内容。官网截图 `.audit/claude-official-website.png` 为独立 Chrome 的真实访问，先前沙箱阻止访问的截图已被成功访问结果替换。
- 本项目适配：第二版预览减少独立卡片堆叠，突出连续纸面、阅读型标题、暖灰表面和灰阶主按钮，以陶土色作点缀。系统字体回退只作近似，不称为官方字体；不复制官网标志 SVG 路径。

## 大肥鱼

用户指定 ZipZipPipe 版本鲸鱼娘，并明确授权生成图标、角色和丰富装饰。新增探头挂件、思考头像、虎鲸图标与海洋边饰，角色/背景/特色控件可独立关闭。用户随后纠正鲸形方向，因此最终背景和小图标按虎鲸形态处理；这是一项用户确认的视觉方向，不把未查到的生物学分类当作官方声明。

静态资源统一走可选 assets 字段与共享资源池。图片均在本地，浏览器测试不请求模型接口；五张预览 WebP 总计 189,684 字节。生成输入、角色归属与工程导出记录在 `design/assets/deepseek/README.md`。

## 本轮验证

资源流程 26 项（共享、清理、格式、路径与目录链接、文件/整体预算、像素、动画拒绝）、真实浏览器回归 30 项、既有异步回归 85 项、18 套皮肤 lint 与 dry 构建通过。五张最终预览 WebP 单独通过正式打包器检查。第二版在隔离 Chrome 的 1440px 明档和 320px 暗档截图均已查看；三个装饰分组、原生开关鼠标/键盘、滑杆和选项切换通过，无横向溢出。此为基础能力和布局预览验收，尚未代替用户对布局的明确审阅，也未发布下一版。

用户随后明确回复“可以动手吧”，正式三套皮肤及 d10 镜头已实现，21 套皮肤 lint、品牌浏览器集成 107 项和完整构建通过。本地产物 -32，未发布新 Release；正式验证详见 `docs/frontend-design.md`。
