## 一、问题 1：列表符号没出来

### 1.1 真机扫描结果（谁在重置）

把真机酒馆（`http://localhost:11451`，SillyTavern 1.18.0）页面引的 14 份样式表全部抓下来搜 `list-style`：

| 文件 | 命中的规则 | 是否全局 |
|---|---|---|
| `style.css` | `.mes_reasoning_details .mes_reasoning_summary`、`.autoComplete,.autoComplete-details`、`.alternate_greeting summary`、`.paginationjs-pages ul`（共 4 条，全部 `none`） | ❌ 限自家组件 |
| `css/macros.css` | `.macro-details .macro-args-list / .macro-example-list / .macro-alias-list` | ❌ |
| `css/select2.min.css` / `css/jquery-ui.min.css` / `css/fontawesome.min.css` | 组件内部规则（`.select2-*`、`.ui-*`、`.fa-ul`） | ❌ |
| 其余 9 份（st-tailwind / rm-groups / group-avatars / toggle-dependent / world-info / extensions-panel / select2-overrides / mobile-styles / user.css / bright 等） | 0 命中 | — |

**结论：酒馆自身的样式表里没有一条全局 list-style 重置；`data/default-user` 的 settings.json（custom_css 为空）与全部主题 json 也都没有。** 能对消息 iframe 起作用的、不在酒馆仓库里的注入样式（用户主题自定义 CSS，真机页面上那一大段 `id="custom-style"`，作者 KAKAA；以及本机浏览器插件注入的 Tailwind）在仓库/磁盘上都找不到文件，无法离线复证其内容。
**因此在预览台用最坏情况重置模拟**：`ul,ol{list-style:none;margin:0;padding:0}`（预先注入到皮肤 CSS 之前）——无论真机上是谁重置、以何种方式重置，修完后 9 套皮肤在这条规则之下都必须自己把符号画出来。

### 1.2 修复前读数（list-probe，reset=1，375px 档）

9 套全部同一病情：`ul[0] list-style-type=none`、`ul ul=none`、`ol=none`、`ol ol=none`；`.kami-md ul>li::before content=none`（无自定义字形兜底）。::marker 有颜色（各主题 accent / 嵌套压暗），但 **list-style-type=none 导致符号本体根本不生成** —— 这就是「上色了却没有点」的直接原因：9 套都没声明 `list-style`，符号完全依赖浏览器默认继承，外层一重置就消失。

### 1.3 修法（每套 skin.css 都加了同构的一块）

- `ul` → `disc`，`ul ul` → `circle`，`ul ul ul` → `square`；
- `ol` → `decimal`，`ol ol` → `lower-alpha`，`ol ol ol` → `lower-roman`；
- 原本没有 `::marker` 颜色的 4 套（crt80s / mileng / terminal / trpg）补上 `li::marker = --kami-accent`、嵌套 `li li::marker = --kami-fg-mute`；其余 5 套沿用已有的主题化 marker 色（xianyun 保留其 ul 朱砂 / ol 淡墨 的分色设计，未加通用色）；
- 已有 `padding-left: 1.3~1.5em` 保证符号与文字对齐良好（探针实测 16.4px–22.5px，位置 outside）。

## 二、问题 2：特效说明在手机上只能显示一行

总根源在结构层 `src/skin/base.css:227` 的 `.kami-sub { white-space: nowrap }`（该文件不归本批修改）。特效页说明（`renderFxPane()` 的 `.kami-field > .kami-field-label > .kami-sub`）就是被它抓成一行，溢出后被裁。

### 2.1 修法（每套 skin.css 各加一条，只放开"字段说明"一处）

```css
... .kami-root[data-kami-comp="panel"] .kami-field .kami-field-label .kami-sub {
  white-space: normal;
  overflow: visible;
  text-overflow: clip;
  min-width: 0;
}
```

标题栏 / 页脚那类 `.kami-sub`（计数、提示）不受影响，仍然单行——选择器精确限定在"字段标签里的说明"这一支上。
