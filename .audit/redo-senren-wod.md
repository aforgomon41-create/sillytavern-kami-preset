# 重做简报：senren（千恋万花）与 wod（黑暗世界）

> 用户 2026-09-23 裁定：「黑暗世界和千恋万花做的太差了，我要求打回重做」。
> 排期（用户当场选定）：**先把 8 套新皮肤做完，最后回头重做这两套**。
> 这份文件是派活方的证据存档 + 重做 agent 的简报底稿。量测工具：`.audit/coverage.mjs`（覆盖面矩阵）、`.audit/check-skin.mjs`（严查）。

## 一、用户点名的四类问题（原话拆解）

1. **太素**：「组件和细节只写了一半，看着像半成品」。
2. **字体、字号、排版不舒服**。
3. **动效和特效太少太弱**。
4. **「还有很多运行操作 bug，很多界面也没有用户友好性和两端适配性」** —— 用户补充原话。
   （第 4 条同时指向：交互行为缺陷、锁死/禁用态没有反馈、PC 与手机两端表现不一致。）

## 二、客观量出来的差距（2026-09-23 实测）

规则条数 / 体积（`.audit/coverage.mjs` 实测）：

覆盖率缺口（`—` = 一条规则都没有）：

- **两套共同**：
  - `.kami-empty` 空态 —— 没有
  - **锁死态 `[disabled]` —— 0 条规则**（预设面板里固定有 16 个「非当前模型」条目是原生 disabled；兜底皮肤 `src/skin/base.css:900` 的同类规则被 `html:not([data-kami-skin])` 限定，**真实皮肤生效时一条都不匹配**）→ 用户点锁死条目「没反应也没提示」。
  - **手机档 `@media (max-width)` —— 0 条**；`@container` 也是 0 → 只在 PC 上成立（其余七套皮肤都有手机档）。
  - 语义色七种几乎没区分：每种只出现 2 处，grokbot 是 6 处。
  - 注释角标 `[data-kami-corner]`：1 处 vs grokbot 12 处。
  - 可点区域偏小：senren `--kami-row-h: 38px`、wod `40px`；grokbot 基准 42px、**手机档 44px**，且注释写着「可点区域 ≥ 40px」。
- **senren 额外缺**：`.kami-dots` 进度点、`.kami-resize` 缩放把手、**`@keyframes` 一个都没有（等于零动效）**。
- **wod 额外缺**：`.kami-list`、`.kami-item-main`、`.kami-grid` 只 1 处、`:has()` 结构判据一处都没有。

## 三、重做时照抄的验收线（派活方会逐条机械复核）

1. `node build/lint-skins.mjs <id>` PASS —— 这只是入场券。
2. `.audit/check-skin.mjs <id>` **全过**（含锁死态 ≥2 条、手机档 @media ≥1、对比度四件套三项 `!important`、正文对比度数值 ≥4.5:1）。
3. `.audit/coverage.mjs` 里**深度不得低于 trpg**：规则条数 ≥ 200、体积 ≥ 45KB；除平台专属装饰（d20）外，矩阵里不许再有 `—`。
4. 语义色七种每种 ≥4 处；`@keyframes` ≥3（入场 / 强调 / 循环各一，循环动画在 `data-kami-motion="off"` 与 `prefers-reduced-motion` 下必须**停**，不是压到 1ms）。
5. 手机档把 `--kami-row-h` 提到 ≥44px，并按 560px / 380px 两档收 `--kami-items-min`。
6. 预览台六格读数（宽屏 + 手机宽度各一遍）：面板内溢出 0、页面横向溢出 0、网格列数合理、标题栏溢出 0。

## 四、「运行操作 bug」还缺用户的点名清单

用户只说了「还有很多运行操作 bug」，没有列出具体操作。派活前需要向用户确认：是面板按钮点了没反应、tab 切不动、滑杆拖不动、还是某个前端在手机上错位？
在拿到清单之前，重做 agent 先自查这几类通病：

- 触屏上只有 `:hover` 才有反馈、没有等价的可点提示（senren 已用 `@media (hover: hover)` 包住 hover，做法是对的，但要确认可点区域够大）。
- 可点区域 < 44px（手机档），或图标按钮只有 24–32px。
- 锁死/禁用条目没有视觉差别（见上）。
- 点了没反应的死区：`pointer-events` 被上层元素吃掉、或 `z-index` 被面板盖住。
- 长文本溢出、卡片内元素换行成竖排单字（历史真机 bug）。
- 面板窄屏没变贴底抽屉（`data-kami-layout="sheet"` 规则缺失或写错）。

## 五、重做时不许踩的老坑（摘自上位文档）

- 选择器必须以 `html[data-kami-skin="<id>"] ` 原样开头；面板组件规则**一律不许挂面板 id**（几何骨架例外）。
- 并列选择器里 `[data-kami-comp="panel"]` 与 `.kami-card` 之间**必须有空格**（少一个空格 = 86 处静默失效那次事故）。
- 「选中换底」必须把 `--kami-fg` 一族**成对翻**（同型事故三次）。
- `.kami-shell` 与 `.kami-surface` 常是同一元素：写 `background` 简写会把纹理重置掉。
- `params[].unit` 必须是合法 CSS 单位或空串（`×` / `°` 会让整条声明失效）。
- 改完**不要跑 `node build/build.mjs`**（会写 dist 并自增产物号），除非派活方明确要求。
