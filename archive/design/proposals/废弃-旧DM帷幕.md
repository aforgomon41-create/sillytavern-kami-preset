# DM 帷幕 · 皮肤设计方案（皮肤 id：`trpg`，按钮短名：帷幕）

> 阶段：设计 + 实现（本文件与 `src/skins/trpg/skin.css`、`skin.json` 同步交付）。
> 依据：`docs/皮肤契约.md`（§7 前缀规则已遵守：225 条选择器全部以 `html[data-kami-skin="trpg"] ` 开头，
> 特效写成 `html[data-kami-skin="trpg"][data-kami-effects~="fx"] `；`node build/lint-skins.mjs trpg` PASS）。
> 建议方案：`scheme: 'dark'`（明暗两套都实现，暗色是正典）。
> 一句话：**收起时它是一块挡板——挡住你看不到；展开时它是被翻开的那块板，后面平铺着 DM 的模组。**

---

## 1. 核心概念

**现实桌面跑团的挡板（DM screen）是唯一一个「语义上就在遮挡」的物件。**

它不是氛围道具，它是一件**功能性家具**：四块硬卡纸/仿皮板用铰链连成锯齿状立在桌上，玩家那一面印着整幅插画、
标题横幅与纹章，DM 那一面是速查表、状态表、NPC 名录与卡槽。它的两块面**朝外和朝内完全是两种东西**，
而它的立/倒就是「藏起来 / 亮出来」的物理动作。

所以这套皮肤的第一性规则不是配色，而是一条**两态律**：

> **挡板立着 = 不透明、有厚度、有折缝与铰链、面朝玩家；挡板翻开 = 看见内侧功能面，以及后面那一页模组文稿。**

由这条律推出四条硬规则，全套 CSS 都在执行它们：

1. **折板永远是四块，而且不随宽度变形。** 板面的明暗交替、折缝、铰链、铆钉全部用**百分比周期的
   `repeating-linear-gradient` + 固定像素宽的折缝**画出来 —— 所以 320px 的手机和 900px 的桌面看到的
   都是同样比例的四折板，而不是「一根木条」或「一堆竖线」。
2. **它有厚度，而且落在桌面上。** 板下沿有 5px 的切边（可调），切边下面压着一道**锯齿状的投影** ——
   四块板各自倾斜，所以桌面上的影子下缘是折线而不是直线。这一笔是整套皮肤的锚：你一眼就知道它是「立着的」。
3. **展开不是一个淡入，是板绕上沿转走。** 外插画面（`::before`）用 `rotateX(-96deg)` 绕板的上沿翻过去，
   露出元素自身的背景 = **内侧功能面**（黄铜压条 + 卡槽 + 速查表）。不需要交叉淡入：物理上就是「翻过来看见里面」。
4. **展开后你读到的不是「卡片正文」，是一页模组。** 页边批注线（红笔）、自动编号的章节、贴上去的 boxed text、
   红笔划的重点、裁切线、速查表式的原文 —— 展开态的阅读容器是一份**文稿**，不是一块面板。

一句话记住它：**合上是一堵墙，翻开是一叠稿纸。**

## 2. 用户体验路径

**第一次遇到（0–3 秒）。**
聊天楼层里出现的是一条**深绛红的四折挡板**，横在最上面：板面一块亮一块暗，折缝处有暗槽和一道接光，
下沿一排铆钉，折缝上有铰链，外沿裱着两道黄铜细线。左边压着一条横幅，上面是「奈亚子的DM帷幕」与一枚斜分的盾徽；
右边是「138 字」和一个折角箭头。它**不透明、厚、立着**——用户不需要读任何说明就明白：这里有东西被挡住了。

**理解（3–10 秒）。**
点一下横幅（整条头部都是热区）——**挡板绕上沿翻走**，露出里面的皮革面（黄铜压条 + 两只卡槽），
同时后面的稿纸从板下被抽出来：一页带页边批注线的模组，章节还带着手写编号 `01` `02`。
用户立刻学会两条规则：**挡板 = 藏，翻开 = 看**；而「渲染 / 原文」是稿纸页眉上的两只索引标签，
「复制」是同一行右端的动作 —— 全部**只在展开后出现**（契约 §5.1 的新骨架）。

**使用（持续）。**
往下翻，每一条行动选项是**模组里递到玩家面前的一张选项卡**：顶部凸出一张彩色标签（行动 / 性格 / 推进 / 信息 /
搞笑 / NSFW），左侧页边一个红笔写的 `01`…`06`，右下角折起来一角，下沿有厚度。手指按下去，卡片被推进卡槽（下沉 +
边缘起光）。参数面板里那把滑杆是**一把标尺**：刻度、黄铜滑座、走过的部分留一条黄铜线；开关是**卡槽里的一枚卡扣**。

**记住。**
两个记忆点：① 翻开挡板那一下（板转走，露出功能面，稿纸从后面被抽出来）；② 那张**挡板立在桌上的影子**——
它的下缘是折线，因为它由四块各自倾斜的板组成。第三个记忆点是安静的：长思维链落在**压暗的羊皮纸**上，
配页边批注线和印刷体章节标题，两千字读下来不累，而且它看起来像「在读一份文稿」，不像「在读一块 UI」。

**日常与降级。**
关掉动效它仍然是**一块立着的板 + 一页纸**：状态从来不只靠动画表达 —— 收起是「不透明 + 有厚度 + 有折缝」，
展开是「看得见内侧卡槽 + 看得见页边编号」。这两组几何在任何一档动效下都不变。

## 3. 视觉语言

### 3.1 色彩体系：绛红皮革 + 黄铜五金 + 羊皮纸 + 红笔

四层明度，各司其职：

| 层 | dark（正典） | light | 职责 |
|---|---|---|---|
| 板（外侧插画面） | `#3a1d18` → `#190a08` | 同左（**不随明暗变**） | 挡板面向玩家的那一面：深绛红皮革 |
| 板（内侧功能面） | `#221310` / `#150a08` | `#ded4be` / `#c9bda2` | 展开后露出来的那一面：夜里是深皮革，白天是浅色书写面 |
| 纸（模组文稿） | `#2f2718` | `#f7f0dd` | 正文：暗色是灯下的羊皮纸，亮色是真的米白模组纸 |
| 卡片（选项卡） | `#201914` | `#fdf9ee` | 行动选项、皮肤卡 |

**为什么暗色方案的纸不是白的。** 长思维链有两三千字，在暗色聊天里塞一整块高亮白纸，读三屏就会累；
所以暗色方案走「台灯下的羊皮纸」：纸是暖的、比板亮、比底色亮，但**不是白的**（纸/板对比 1.3:1，
靠上沿接光、下沿厚度影与纸纤维把它从板上分出来）。亮色方案才是字面意义上的「一页模组」：米白纸 + 蓝黑墨 + 红笔。
两套方案共享**同一个**挡板外观 —— 挡板是物件，物件不随环境灯变。

**黄铜是唯一的强调色**（`--kami-accent`）：横幅边框、压条、滑座、卡扣、焦点环、选中的标签。它只出现在
**五金件与「被选中」** 上，从不用来大面积填充。**红笔是第二支笔**（`--kami-ink-red`）：只用在
「DM 亲手写上去的东西」上 —— 页边章节编号、卡片编号、boxed text 的边、列表的方点。**红笔不是强调色，
是另一个人的手**，所以它和强调色从不混用。

### 3.2 字体栈与理由

- 正文 `--kami-font`：系统无衬线（手机上最快、中文最稳）。
- **标题与文稿 `--kami-font-title`：衬线**（Iowan Old Style / Palatino / 宋体 / Noto Serif Fallback）。
  这条是「印刷品 / 模组」与「UI」的分界：章节标题、卡片标题、面板标题、以及页边上那些编号都是衬线，
  读起来像印出来的，而不是渲染出来的。
- `--kami-font-mono`：打字机等宽 —— 只给三样东西：字数读数、速查表（原文）、参数数字。
- `--kami-title-transform`：`none`（中文不做大小写变换）。

### 3.3 材质与图形语言（全部是渐变，零位图、零滤镜）

| 实物特征 | 实现 |
|---|---|
| 四折板的明暗交替 | `repeating-linear-gradient(90deg, rgba(255,226,170,.045) 0 25%, rgba(0,0,0,.13) 25% 50%)` |
| 折缝（暗槽 + 一道接光） | 同一条 repeating 渐变里的两段：`--kami-seam-hi` 1px → `--kami-seam` 到 `--kami-fold-w`（默认 8px） |
| 下沿铆钉 | `radial-gradient(circle …, 2px)` 平铺 `background-size: 26px 100%` + `repeat-x` |
| 折缝上的铰链 | 两条 25% 宽的**单点**径向渐变贴片错开 25%：合起来正好落在 0/25/50/75/100% 五条线上 |
| 板厚切边 | `.kami-head::after`：`--kami-thick`（默认 5px）实色 + 1px 接光 |
| 挡板落在桌上的投影 | 同一个 `::after` 的 `clip-path: polygon(…)`：下缘是**锯齿**（四块板各自倾斜） |
| 裱在插画面上的双线框 | `box-shadow: inset 0 0 0 1px/3px/4px/9px/10px` 五层内嵌环 |
| 皮革/织物纹 | 两条 45°/−45° 的 1px 细渐变（`.kami-shell::before`） |
| 纸纤维 | `repeating-linear-gradient(0deg, 1px 亮 / 2px 暗)`，3px 一周期，透明度 ≤ .022 |
| 胶带 | boxed text 左上角一截旋转 −2.4° 的半透明浅色条 |
| 裁切线 / 撕口 | `hr` = 1px 高、7px 亮 8px 空的 repeating 渐变 |
| 折角 | 卡片右下角 14px 的 `clip-path` 三角，斜向渐变出一暗一亮两个面 |

**没有任何一张图、没有 SVG、没有 emoji、没有滤镜**（全文件只有一处 `filter`：主按钮悬停时的
`brightness(1.07)`，不是动画）。所有「物」都是渐变在正确的几何上。

### 3.4 留白与节奏

- 板的四折把一条横条切成四段，所以**头部信息被刻意靠左**（横幅压在左起第一块板上），右侧留出读数与折角箭头；
  中间两块板是空的 —— 那是插画的位置，不该放控件。
- 稿纸的页边是**结构留白**：`--kami-margin-w` 34px（窄屏 24px），红笔编号落在页边里，正文从页边右边开始。
- 卡片之间的行距比列距大 7px：桌面上的卡片是「摊开的」，不是「网格」。

## 4. 组件设计

### 4.1 挡板头部 `.kami-head`（本套皮肤的招牌）
元素自身的背景 = **内侧功能面**（黄铜压条 + 右侧卡槽 + 一条 17px 周期的速查表竖格）。
`::before` = **外插画面**（四折板 + 折缝 + 铆钉 + 铰链 + 双线画框 + 上方冷光），收起时盖住内侧。
`::after` = **板厚 + 桌上锯齿影**。`perspective: 760px` 让 `::before` 的 `rotateX` 有行程。
收起：`rotateX(0)`；展开：`rotateX(-96deg)`（`transform-origin: 50% 0%`）—— 板的底边向上收拢，
内侧从下往上露出来，**投影同时变软、下移**（`opacity .9 → .38`）。

### 4.2 状态点 `.kami-dot` = 一颗 d20
六边形 `clip-path` + 内嵌一个倒三角 `::after`（黄铜壳 + 深色面）。`[data-kami-on="1"]` 时壳变亮、内面转成绛红。
这是全界面**唯一一处「骰子」**，而且它是一个纯几何形状，不是贴图。

### 4.3 标题与副信息
- 收起态：`.kami-title` 是**印在横幅上的** —— 两端切角的缎带（`clip-path` 六边形），
  左端一枚 11×13px 的斜分盾徽（`::before`），字体用衬线 + 字距。`max-width: 68%`（窄屏 58%/52%）+ 省略号。
- 展开态：横幅消失，标题变成 **DM 自己贴上去的一条标签带**（黄铜底、−0.5° 倾斜、衬线小字）。
- `.kami-sub`（字数）永远是等宽 + `138 字` 的读数样式，落在板右侧。

### 4.4 `.kami-bar`（契约 §5.1 新增的正文头部操作行）
一条**压在裁切线上的操作行**：底部是一条 6px 亮 / 8px 空的 repeating 渐变（撕口线），左端夹一只
13×17px 的黄铜夹（`::before`，`clip-path` 切出夹口）。左端是「渲染 / 原文」两只**索引标签**，
选中那张更高一档、底色与稿纸连成一片（`margin-bottom: -1px`），右端是「复制」（`.kami-btn--ghost`），
成功时多出一枚勾（`.is-done::after`，也是 `clip-path` 画的形状）。
**收起态这一整行不存在** —— 挡板立着的时候你看不到纸，自然也没有纸上的工具行。

### 4.5 按钮 `.kami-btn` / `.kami-icon-btn`
硬卡纸/金属牌：1px 深边 + 2px 实底投影（悬停不浮起，只换底与边色），`.kami-btn--primary` 是黄铜牌
（`inset 0 1px 0` 顶光 + 2px 底厚），`.is-done` 变黄铜底并出现勾。

### 4.6 分段切换 `.kami-seg`
两只插在卡槽里的索引标签（顶圆角、无底边）。在**稿纸上**（`.kami-bar` 里）用「抽出更亮、与纸连成一片」；
在**板内侧**（行动选项头部）换成黄铜描边的槽位，选中那只是黄铜底 —— 同一控件在两种材质上有两种正确解。

### 4.7 卡片 `.kami-item.kami-card` = 递给玩家的选项卡
- 顶部**凸出 10px** 的彩色标签（`.kami-badge` 绝对定位 `top: -10px`，颜色来自 `data-kami-kind`，7 种色）。
- 左侧页边一个 `counter(kami-card, decimal-leading-zero)` 编号，红笔、衬线、斜体、−2° 倾斜。
- 右下角折角；下沿 2px 实底投影 = 卡纸厚度。
- 悬停：整张被「拿起来」（`translateY(-2px) rotate(-.35deg)` + 更深的落影）。
- 按下 / `.is-done`：被「推进卡槽」（`translateY(2px)` + 内阴影 + 黄铜边）。
- `.kami-item-side`（那个 ↵）做成一枚盖在卡片右上角的**小方戳**（黄铜细边 + 等宽字）。

### 4.8 稿纸 `.kami-md` = 模组文稿
- 页边：34px 的页边带（比纸略亮的色调）+ **红笔批注线**（宽 `--kami-rule-w`，默认 3px）+ 一条 3px 外的细线。
- 章节：`counter-reset: kami-sec` + `h1/h2/h3 { counter-increment }`，`::before` 在页边里输出
  `decimal-leading-zero`（01、02…），衬线斜体 + 红笔色 + −2.4° 倾斜 —— **编号是 CSS 计数器自动给的**，
  不依赖模型写对层级。
- `blockquote` = **boxed text**：双线框（`inset 0 0 0 3px 纸色, 0 0 0 4px 线色`）+ 左上角一截胶带 + 略微不同的纸色。
- `strong` = 红笔/记号笔划过的一道（`linear-gradient` 下 2/5 高亮）。
- `ul > li::before` = 5px 红方点；`hr` = 裁切线；`table` = 属性块（表头深底 + 等宽数字列）。
- `pre` = 贴上去的一张小纸（自己一层纸色 + 2px 底厚）。

### 4.9 `.kami-raw` = 挡板内侧那张速查表
等宽字 + **横格纸**：`repeating-linear-gradient` 用 `1.62em` 的周期，配 `background-origin: content-box`
把横格与行高严格对齐（`line-height: 1.62`），左边一条红笔竖线。它和 `.kami-md` 是两种不同的「纸」：
一个是排版稿，一个是抄下来的表。

### 4.10 表单
- `.kami-range` = **标尺**：轨道 20px 高，底部 6px 一排刻度（8px 周期），走过的部分由前端写入的
  `--kami-value` 画成一条黄铜线；滑块是 9×18px 的黄铜滑座（顶光 + 2px 底厚）。
- `.kami-switch` = **卡槽里的卡扣**：槽是内凹的暗槽，卡扣是黄铜小方块，选中时槽底转黄铜底、卡扣滑到右端。
- `.kami-number` = 表格里的一格（等宽 + 右对齐 + `tabular-nums`）。
- `.kami-field` 行之间是**虚线**（纸上的分隔是虚的，不是实线）。

### 4.11 面板 `.kami-drop` = 挡板的内侧面立在桌上
深色皮革（亮色方案里是浅色书写面）+ 内嵌一圈黄铜细框 + 四边 3px 的黄铜铰链压条；
`.kami-tabs` 是**文件袋的隔页标签**（选中那张下移 1px、与面板连成一片、顶边一道黄铜）；
皮肤卡片用 `.kami-card` + `.kami-preview`（缩略：一条 14px 高的四折板 + 下面三行纸）。
窄屏（≤768px）保持契约要求的**贴底抽屉**，只把圆角改成上圆。

### 4.12 其它
`.kami-toast` = 便利贴（−1.6° 倾斜 + 3px 底厚 + 落下时从上方 6px 落位）；`.is-bad` 转红笔色。
`.kami-empty` = 虚线留白格。`.kami-chip` = 小纸片（等宽）。`.kami-scroll` = 黄铜轨 + 方块滑块。

## 5. 动效编舞

时间刻度：`--kami-dur-fast .12s / --kami-dur .2s / --kami-dur-slow .34s`，
缓动 `cubic-bezier(.3,.7,.3,1)`（重物的手感：起步快、收尾慢，**不回弹**）。

**A · 入场（.2s）。** 整块从上方 5px 落位（`--kami-enter-y: 5px`，无缩放）——像一块板被放到桌上。
消息楼层会按楼层各跑一次，所以只有一次位移，没有逐项错峰（错峰只给 `dice` 特效）。

**B · 展开（本皮肤的主运动，.34s）。** 三件事同时发生：
1. `::before` 绕上沿 `rotateX(-96deg)`（`.34s` 出场缓动），内侧面从下往上露出来；
2. 板厚投影变软下移（`opacity .9 → .38`，`.34s`）；
3. `.kami-collapse-body` 跑 `kami-trpg-unveil`：`clip-path: inset(0 0 58% 0) → inset(0)` +
   `translateY(-6px) → 0`，`.34s` —— **稿纸是从板后面被抽出来的**，不是淡入的。

**C · 收起（.2s）。** 只有一件事：`::before` 转回来（`opacity` 收尾 .16s 后归零）。
正文由结构层的 `display: none` 立刻收起（**不做高度动画**，见 §10 批评 B）。

**D · 状态切换（.12s）。** 标签抽出、卡扣滑格、滑座移动、卡片按下 —— 都是短促的一次位移，无过冲。

**E · 悬停与聚焦（.12s）。** 卡片被拿起（−2° 内的旋转 + 落影加深）；焦点是 `2px` 黄铜环 +
`5px` 低透明光晕（`box-shadow`），键盘用户在任何底色上都找得到。

**F · 成功（.12s 出现，1.2s 后由前端移除）。** 复制/填入：卡片推进卡槽、按钮转黄铜底并长出一枚勾。

**G · 长文本。** 稿纸的入场只作用在容器上（`clip-path` + `translateY`），**逐段错峰一律不做** ——
两千字的思维链不该边读边动。

**H · 降级。**
- `calm`：时长整体降一档（.08/.14/.2），**去掉所有循环动画**（折缝反光、台灯呼吸），
  滚动错峰（`dice`）减半，翻板改成纯淡出（`transform: none`）。
- `off`：全部 `1ms`、无位移、无旋转、便利贴不歪、翻板直接切换。
- `prefers-reduced-motion: reduce`：同一套 `1ms` + 翻板不转 + 稿纸不用 `clip-path` 入场。

## 8. 响应式与可达性

### 8.1 三档宽度
- **320–430px（手机）**：四折板照旧（百分比周期，不塌），页边 `--kami-margin-w` 34→24px，
  编号公式随之下移（`left: -(margin+11px)`、宽度 `margin-5px`、右对齐），卡片页边 +24→+19px，
  滑杆 112→88px，胶带缩短。横幅 `max-width` 68%→58%；≤360px 再收到 52%、头部左右内边距回到 `--kami-pad-x`。
- **430–768px（平板）**：网格 2 列（`--kami-items-min` 262px 自适应），其余不变。
- **>768px（桌面）**：`--kami-items-min` 决定 2–3 列；面板回到令牌给的 430×580 并可拖动/缩放；
  ≤768px 时面板是契约要求的贴底抽屉。

### 8.2 键盘与焦点
`.kami-root :focus-visible` = 2px 黄铜实环 + 2px 外扩 + 5px 低透明光晕；`.kami-switch-input:focus-visible` 单独给环
（原生 checkbox 被隐藏）。折叠头是 `role="button" tabindex="0"`，前端已处理 Enter/Space。所有可点元素 ≥42px 高。

### 8.3 对比度（对实际合成色计算的 WCAG 比值）
| 组合 | 比值 | 组合 | 比值 |
|---|---|---|---|
| dark 正文 / 纸 | **12.05** | light 正文 / 纸 | **13.46** |
| dark 次文 / 纸 | 7.45 | light 次文 / 纸 | 7.36 |
| dark 最弱文 / 纸 | 5.24 | light 最弱文 / 纸 | 5.22 |
| dark 黄铜 / 纸 | 6.40 | light 黄铜 / 纸 | 5.05 |
| dark 红笔 / 纸 | 4.58 | light 红笔 / 纸 | 5.81 |
| dark 板上的字 / 板 | 14.50 | light 板上的字 / 板 | 10.40 |

正文一律落在比它更暗/更亮的**纸或板**上，不在半透明层上叠字。

### 8.4 状态不只靠颜色
「收起 / 展开」由几何表达（有没有折缝与厚度 / 有没有页边编号与内侧卡槽）；「选中」由形状表达
（索引标签抽出来、卡扣滑到右端、卡片被推进槽）；语义色永远与文字标签同时出现。

### 8.5 降级
- 无 `backdrop-filter`、无外部字体、无位图 → 断网/弱机型下外观不变。
- `:has()` 只用在**一处**（挡板立着时让外壳下沿的厚度条让位）；不支持时最坏结果是下沿多出一条 5px 的深边。
- `@property` 只用于折缝反光的位置；不支持时反光停在 `-60%`（板外），视觉上等于没有这道反光。
- 面板几何完全交给脚本（不覆写 `position/left/top/width/height`），只改外观。

## 9. 主动「不做」的三件事

### ① 不贴任何具象图标或 emoji
没有骰子图、没有剑与盾、没有 🎲🐉📜。全文件只有一处「形状符号」：`.kami-dot` 那颗 **d20**
（六边形 + 内三角，纯几何）。理由：emoji 是「贴上去的跑团感」，而实物挡板上没有图标 ——
它有的是折缝、铆钉、铰链、卡槽、页边和编号。概念落在**结构**上。

### ② 不用任何位图材质与滤镜堆砌
没有噪点贴图、没有木纹/皮革图、没有 `filter: blur/contrast` 冒充材质、没有 `backdrop-filter` 玻璃。
唯一的 `filter` 是主按钮悬停的 `brightness(1.07)`（不在动画帧上）。材质全部由**渐变在正确的几何上**产生：
折板 = 明度块 + 折缝；皮革 = 两条 45° 的 1px 细线；纸 = 3px 周期的纤维；铆钉 = 平铺的径向渐变。
理由：皮肤 CSS 会按楼层复制，一张贴图乘 N 个楼层就是 N 份解码与显存。

### ③ 不做任何「边读边动」的长文本动画，也不做高度动画
逐段淡入、逐行显现、打字机效果一律没有：动画只允许作用在**容器**上（展开那一次）。
折叠收起也不做 `height` 动画 —— 契约的结构层用 `display: none` 收起正文，硬做高度动画会与结构层打架，
并在每一帧重排整页（消息 iframe 的高度由 `body.scrollHeight` 决定）。收起时保留的运动是**挡板转回来**。

## 10. 自我批评与已做的实质修改

### 批评 A：暗色方案的纸「不够白」，第一眼可能被读成「深色面板」
这是**故意的取舍**（长文本可读性优先），但我承认它削弱了「纸」的第一印象。已做的补救：
纸上沿接光 + 下沿 2px 厚度影 + 3px 周期的纤维 + 页边 3px 红笔线，纸/板对比从 1.27 提到约 1.4。
亮色方案是字面的模组纸（`#f7f0dd` 米白 + 蓝黑墨）。**如果用户的原话是「展开后不够像纸」，
第一个该调的就是 `--kami-card-2` 往亮走一档。**

### 批评 B：收起时正文是瞬间消失的
结构层 `display: none` 把正文立刻收掉，只有挡板有回来的动画。我试过反向的 `clip-path`，
但要么与结构层打架，要么让 iframe 高度抖动（预览台用 `body.scrollHeight` 量高度）。
**这是本套皮肤最明显的未完成处**：如果前端愿意在收起时先加一个 `data-kami-closing` 之类的钩子，
这里可以补一段 .2s 的「纸被塞回板后」的反向动作。

### 批评 C：窄屏上横幅标题会被省略号截断
「奈亚子的DM帷幕」8 个字 + 盾徽 + 内边距 ≈ 163px；≤430px 时 `max-width: 58%`（约 200px）刚好放得下，
但 ≥9 个字的标题在 320px 上会截断。现在靠 `text-overflow: ellipsis` 兜住（不会撑破布局），
但**文案 Agent 如果要再改标题，请把长度控制在 9 个汉字以内**。

### 批评 D：亮色方案第一版是错的（整块板保持深色）
第一版里「板」在两种明暗下都是深绛红皮革，结果亮色方案下所有**不在纸上**的字（页眉的两只标签、复制按钮、
页脚、整个面板的参数名）都成了深墨色落在深皮革上，几乎看不见。修复不是加一条覆盖规则，而是**改结构语义**：
板的内侧面在亮色方案里换成浅色书写面（`--kami-inner` 与新增的 `--kami-on-inner` / `--kami-on-inner-dim`），
让「板上的字」跟着板走。挡板朝外的插画面仍然永远是深色。

### 批评 E：板面多层细纹在小数点 DPR 上可能产生摩尔纹
在 1.7x 截图缩放下，深色板面上能看到 13–24px 周期的细密条纹（3px 纤维 + 竖格 + 折缝高光重采样叠加的结果，
放大到 2x 以上基本不可见）。我为此把功能面的竖格从 13px 放宽到 17px、透明度 .05→.025，
并把纸纤维的透明度压到 .022。

### 批评 F：预览台里 boxed text（blockquote）根本没被渲染过
预览台的 iframe 里没有 `window.showdown`，前端走的是内置的简易 markdown 兜底，它**不解析 `>` 引用** ——
所以在预览台里 `> 引用` 会原样显示成一个「>」开头的段落。我因此另建了一个临时探针页
（`<html data-kami-skin="trpg">` + 直接写 `<blockquote>`）验证 boxed text：双线框 + 胶带 + 纸色都成立。
**这条不影响真机**（酒馆页面有 showdown），但「boxed text 的最终观感」只在探针里看过，请以真机为准。

### 批评 G：契约 §3.7 的令牌名与前端实现不一致（已按两边都写处理）
契约表写的是 `--kami-label-think` / `-think-open` / `-options`，而**当前前端**按
`data-kami-label="<slot>"` 拼名：实际读的是 `--kami-label-think-title` / `-think-title-open` / `-options-title`。
我最初只写了契约名，结果预览台里标题一直是「思维链」（前端回退值）。**现在两套名字都声明了**，
并已在预览台真机路径上确认「奈亚子的DM帷幕」与「轮到你行动了」都能显示。
另外三套皮肤目前只写了契约名，**它们的风格性标题会显示回退值** —— 这是平台层该统一的一件事。

### 仍然存在、我不打算在这一版解决的
- 挡板外插画面上没有「整幅插画」：只有多层渐变构成的明暗、画框、横幅与盾徽。纯 CSS 画不出可信的
  「暗色奇幻插画」，我把它做成「裱在画框里的深色板」，而不是假装有画。
- 面板里皮肤缩略图（`.kami-preview`）是「一条板 + 三行纸」的极简缩略，不逐组件还原。

## 11. 与另外三套皮肤的差异声明

| | memo 记事本 | rain 恋雨 | nixie 辉光管 | **trpg DM 帷幕（本套）** |
|---|---|---|---|---|
| 隐喻 | 一张纸 | 一块玻璃 | 一台仪器 | **一件家具（可折叠挡板）** |
| 主色 | 米白纸 | 冷湿灰绿 | 暖暗金属 + 氖橙 | **绛红皮革 + 黄铜 + 羊皮纸** |
| 明暗 | light | dark | dark | **两套都实现，dark 为正典** |
| 折叠的语义 | 纸被折起来 | 起雾 / 擦开 | 通电 / 断电 | **挡板立着 / 被翻开** |
| 展开后的正文 | 纸面正文 | 干的那一面 | 最暗的读数板 | **一页模组文稿（页边 + 编号 + boxed text）** |
| 选项卡片 | 纸卡片 | 玻璃片 | 阴极片 | **递给玩家的选项卡（顶部标签 + 页边编号 + 折角）** |
| 独有 | 裁切线 / 套印 | 起雾与走水 | 起辉扫描 | **四折板结构 + 桌面锯齿投影 + CSS 计数器自动编号** |
| 圆角 | 大 | 上大下小 | 小 | **2–6px（硬卡纸没有圆角）** |
| 位图 / 滤镜 | 无 | 面板用 backdrop-filter | 无 | **无（连 backdrop-filter 都不用）** |

**一句话差异**：另外三套皮肤都在给「一个容器」换材质；这套皮肤先把容器变成**一个有正反两面的物件**，
再让「收起 / 展开」变成这个物件的**翻面动作**。
