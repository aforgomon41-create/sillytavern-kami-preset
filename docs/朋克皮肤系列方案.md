# 朋克皮肤系列方案（第三套皮肤）

> 2026-11-06 用户确认方向：做「朋克」系列，共 9 款。赛博朋克「霓虹」、蒸汽朋克「齿轮」从「世界观」挪进来（世界观剩 13 款），另做 7 款新的。
> 协议见 [前端契约](前端契约.md) 第 5、6 节，制作步骤见 [皮肤制作流程](皮肤制作流程.md)，做法沿用 [世界观皮肤系列方案](世界观皮肤系列方案.md) 第五节（一款一个核心隐喻、招牌动效、环境层）。

## 一、用户定下的事

| 事项 | 结论 |
|---|---|
| 系列名 | 朋克（`punk`） |
| 成员 | 用户点的：赛博、柴油、真空管、蒸汽；我们推荐、用户同意的：原子、太阳、丝绸；用户追加：生物、发条 |
| 挪过来的两款 | 「霓虹」「齿轮」原样挪入（11-02 已按深化标准做过），只改系列归属 |
| 名字 | 两字中文名，或不超过 4 个字母（同世界观） |
| 流程 | 先做平台缺的招牌动效 → 7 款初版 → 整套出预览 → **停下来给用户审阅** → 改 → 实机 |

## 二、区分度

系列内任意两款的「核心隐喻 / 招牌动效 / 环境层」三项不能相同，配色、字体、形状、材质里至少再有两项明显不同。
最容易撞的几对，事先拉开：

| 容易撞的 | 怎么拉开 |
|---|---|
| 柴油 vs 蒸汽 | 蒸汽是黄铜 + 木头 + 齿轮（维多利亚）；柴油是枪灰 + 镀铬 + 宣传红（装饰艺术 Art Deco、阶梯切角、放射线） |
| 真空管 vs 原子 | 真空管是暗室实验台（电木、琥珀灯丝、示波器绿线）；原子是明亮的太空时代展馆（奶油白、薄荷、原子橙、回旋镖曲线） |
| 发条 vs 蒸汽 | 发条是达·芬奇手稿（赭红粉笔线、圆规作图、铁与胡桃木、**银色**机件）；蒸汽是**黄铜**仪表盘 |
| 生物 vs 世界观「深渊」 | 深渊是墨绿与病态荧绿的克苏鲁调查笔记（触手、墨晕、气泡）；骸巢是吉格尔式生物机械（骨、肋、脊椎、湿黑甲壳，肉门、黏液垂落），不用绿色、不用气泡 |
| 丝绸 vs 世界观「江湖」「云笈」 | 江湖是水墨刀光，云笈是修仙玉简；丝绸是竹骨绢面的**机关风筝**（靛蓝 + 朱红 + 生绢，竹节细框、扇形） |
| 太阳 vs 其他 | 全系列唯一以浅色为主、自然系的一款（彩绘玻璃温室） |

### 3. 柴油朋克「铁翼」
- 配色：浅色海报纸 `#ece6da` + 宣传红 `#b3261e`、枪灰墨；深色枪灰 `#1b1d1f` + 装饰艺术金 `#d9b85c`。
- 字体与形状：标题 Limelight（装饰艺术），正文黑体；直角 + 阶梯切角，放射线底纹。
- 材质与装饰：拉丝钢板、镀铬描边、铆钉线；角饰是阶梯形扇面。
- 组件：开关是重型闸刀、进度是燃油表分格、徽章是军徽式盾牌、页签是阶梯形。
- 正文：对白宣传红（深色为金），心理描写枪灰斜体；场景转换是放射扇面。

### 4. 真空管朋克「灯丝」
- 配色：浅色电木奶白 `#efe8dc` + 琥珀 `#a85a14`；深色暗室 `#14110d` + 灯丝琥珀 `#ffb347`，辅色示波器绿。
- 字体与形状：标题 Michroma（仪器面板刻字），正文黑体；大圆角（电木外壳）、刻度盘。
- 材质与装饰：电木、玻璃管、网罩喇叭；角饰是一只电子管剪影，灯丝在完整动效档下会热起来发光。
- 组件：开关是拨动开关 + 指示灯、进度是调谐刻度盘、滑块是旋钮、徽章是数码管读数。
- 正文：对白琥珀，心理描写示波器绿；场景转换是一段正弦波。

### 5. 原子朋克「星芒」
- 配色：浅色奶油 `#fbf4e4` + 原子橙 `#d9532a`、薄荷；深色太空蓝 `#13202e` + 薄荷 `#7fd6c4`。
- 字体与形状：标题 Righteous（Googie 招牌字），正文圆黑；不对称圆角（回旋镖 / 腰果形）、胶囊按钮。
- 材质与装饰：烤漆、镀铬弧线、原子轨道；角饰是四角星芒。
- 组件：开关是火箭控制台按钮、进度是倒计时、徽章是星芒、卡片是展馆展板。
- 正文：对白原子橙（深色为薄荷），心理描写淡蓝；场景转换是三道原子轨道。

### 6. 太阳朋克「向阳」
- 配色：浅色晨光 `#f6f8ee` + 叶绿 `#3f7d3a`、阳光金；深色夜间温室 `#13201a` + 嫩芽绿 `#9fd88a`。
- 字体与形状：标题 Federo（新艺术运动），正文宋体；圆拱窗顶、有机曲线。
- 材质与装饰：彩绘玻璃（铅条分隔的色块）、藤蔓、太阳能板格子；角饰是一片叶子。
- 组件：开关是向日葵转向太阳、进度是植物生长、徽章是叶形、页签是拱窗。
- 正文：对白叶绿，心理描写暖金褐；场景转换是一段藤蔓。

### 7. 丝绸朋克「纸鸢」
- 配色：浅色生绢 `#f5efe2` + 朱红 `#b8322a`、靛蓝；深色靛夜 `#121a26` + 灯笼金 `#e8a33a`。
- 字体与形状：标题志莽行书，正文宋体；竹节细双框（框角有绑结）、扇形。
- 材质与装饰：绢面、竹骨、风筝线；角饰是一只小风筝。
- 组件：开关是风筝线轴、进度是风筝放线、徽章是绢签、页签是扇骨。
- 正文：对白朱红（深色为灯笼金），心理描写靛蓝；场景转换是一根风筝线。

### 8. 生物朋克「骸巢」
> 2026-11-07 用户改方向：「生物朋克我想要的感觉是类似于游戏蔑视、电影异形那种风格，而不是微生物」→ 初版「孢子」（培养皿 / 细胞）整款作废，重做。
- 配色：浅色风干的骨与筋膜（骨白 `#ddd0b5` 表面 + 干血赭 `#7a2a1c`）；深色湿黑甲壳 `#0f0e0d` + 骨色 `#c9b48a`，肉色 `#a8472f` 只在开关打开、进度、对白里透出来。
- 字体与形状：标题 Grenze Gotisch（有机的哥特体），正文黑体；面板顶部拱形、甲片式不对称圆角。
- 材质与装饰：标题栏一排有立体感的肋、顶上一道湿亮高光；卡片左缘一节节脊椎；面板背景右侧贯穿的脊柱 + 左下大肋骨；消息左缘细脊椎；底层四周压暗。角饰是椎骨（会呼吸）与一副肋骨。
- 组件：开关是带肋的软管 + 一节椎骨、进度是软管里的体液、徽章是骨签、按钮是骨质甲片。
- 正文：对白干血红（深色为肉色），心理描写橄榄灰 / 冷铬灰斜体；场景转换是一截带肋软管。
- 动效：招牌 `iris` 肉门（一圈带肋的瓣片拧着旋开、收进骨质门框，门里是深的）；通用 `ink` 体液晕开；环境 `ooze` 黏液从上沿挂出、拉长、坠落。

### 9. 发条朋克「发条」
- 配色：浅色手稿纸 `#ebe4d6` + 赭红粉笔 `#9c4128`；深色胡桃木 `#1a140f` + 铁银 `#c9ccd2`。
- 字体与形状：标题 Almendra（文艺复兴手写），正文宋体；圆规作图的圆与辅助线、镜像手稿注记。
- 材质与装饰：手稿纸、木头、铁质机件；角饰是擒纵轮。
- 组件：开关是发条钥匙、进度是钟面、滑块是摆锤、徽章是手稿编号。
- 正文：对白赭红（深色为铁银），心理描写褐色斜体；场景转换是一道圆规弧线。
