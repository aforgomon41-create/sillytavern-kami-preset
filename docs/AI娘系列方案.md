## 四之二、存在感改版方案（2026-11-03，用户看过 Claude 娘的预览后确认，8 款全部启用）

用户看预览后的意见：「AI 娘的元素没有突出」，要求「充分利用 Codex 画的素材」。

**问题在哪**：现在 17 张图里，真正看得清的只有思维链标题旁 36px 的表情。立绘在面板里只有 26%～34% 不透明、再往左上渐隐，像水印；场景图 12%～16%；Q 版只在手机面板角落和对话框里露一点；道具 30px、在不常见的卡片上；「出错」表情只在搜索没结果时出现。根子是**所有图都叠在文字底下**，一加深就压字，所以只能调淡。

**改版原则**：角色不再当水印，而是**占一块不放字的位置、实心显示**。叠在文字底下的只留氛围（场景），而且只铺在没有正文的边缘。

### 1. 聊天（用得最多，优先）

| 位置 | 用什么图 | 怎么做 |
|---|---|---|
| **回复末尾的「看板娘」行**（新槽位 `msg-sign`，只在最新一条回复） | `chibi` + 状态表情 | 正文与行动选项之后单独一行：左边实心 Q 版小人（电脑 72px / 手机 56px），右边一句风格台词气泡（用风格文案，例如 Grok「选吧，凡人」）。生成中换 `face-think` 并轻轻摇晃，搜索没找到换 `face-oops`。占自己的一行，不压任何字 |
| 思维链 / 搜索资料标题 | `face-*` | 保留现在的头像（已放大到 36px） |
| 消息顶部氛围带 | `scene` | 场景图从「整块 12%」改成「顶部一条 120px 的横幅、约 35%，往下渐隐到 0」：思维链标题那一带能看出是书房 / 海底 / 古堡，正文底下保持干净 |
| 分隔线 `___` | `item-2` | 分隔线中间嵌一个 18px 道具（五线谱、回纹这类矢量分隔线照旧，道具放在线的正中） |
| 行动选项 | `item-1` | 选项标题前的图标换成道具小图 |

### 2. 面板（显示 / 预设 / 引导 / 工具箱）

| 位置 | 用什么图 | 怎么做 |
|---|---|---|
| **电脑：右侧「角色栏」** | `portrait`（高清版） | 面板够宽（≥ 900px）时，皮肤给面板内容区加右内边距，空出约 220px 的一栏，立绘**实心**站在这栏里（只在底边与左边缘做一点羽化），文字不进这一栏。面板拖窄到放不下时退回现在的淡水印 |
| 手机：标题栏探头 | `chibi` | 抽屉标题右侧，Q 版上半身从标题栏下沿探出来（约 64px），不进内容区 |
| 标题前的图标 | `face-done` | 换成 28px 圆形头像，标题读作「Claude 娘 · 显示」这种感觉（标题文字本身不改，只是头像在前） |
| 卡片角标 | `item-1` / `item-2` | 已做：容器卡单双数轮换、选中的选择卡右下角 |
| 加载转圈 | `face-think` | 平台的转圈换成表情头像上下轻晃（矢量转圈作兜底） |
| 空状态 | `chibi` / `face-oops` | 空列表、无结果时出现（平台目前没用到空状态，顺手接上一处：工具箱「没有可用更新」之类） |

### 3. 提示与对话框

| 位置 | 用什么图 | 怎么做 |
|---|---|---|
| 提示条（Toast，新槽位 `toast-face`） | 成功 `face-done` / 出错 `face-oops` / 信息 `face-search` | 提示条左边 32px 表情，带 `data-k-tone` 让皮肤按语气换图 |
| 对话框 | `chibi` + `scene` | Q 版从对话框右下角露出（已有，放大到 110px 并实心化，只在按钮栏左侧留出位置）；场景顶带同消息 |

### 4. 平台要加的东西

- 新装饰槽 `msg-sign`（消息前端最新回复末尾，一行，带 `data-k-face` 状态）与 `toast-face`（提示条，带 `data-k-tone`）；沿用 `state-face` 的做法，默认不显示。
- 「角色栏」不需要新槽位：面板内容区的内边距本来就允许皮肤改；平台只需在面板根上给出宽度档 `data-k-width="wide|narrow"`（面板可拖宽窄，媒体查询看不到面板宽度）。
- 风格文案新增一个槽位 `sign.done`（看板娘台词），每款 2～3 句随机。
- 每处都进特效开关（「看板娘」「角色栏」「提示表情」），可单独关掉。

### 5. 验证

实机电脑 1440 / 手机 390、8 款 × 浅 / 深截图逐张看；`skins-next` 的对比度审计确认角色栏和横幅不压字；全套回归。体积：只多用已有的图（立绘高清版走外链），预设不变大。

## 五、素材体积

8 款 × 3 张，全塞进预设会让预设文件大约增加 3MB。做法（契约 6.6 已支持）：

- **包内只放轻量版**（立绘高 480px、Q 版 200px、场景 640px 宽，WebP），每款约 60KB，8 款约 0.5MB，打包预算相应调高。
- **高清版用外链**：`skin.json` 的 `assets.<名>.url` 指向本仓库文件的 jsDelivr 地址（固定到提交号）；先显示包内轻量版，外链载到再换上，失败就一直用轻量版。皮肤说明里写明用了外链。
- 原始 PNG 不进 git（放 `.cache/ai-chan/raw/`）；处理脚本生成 `src/skins-next/ai-<名>/assets/` 下的 WebP。
