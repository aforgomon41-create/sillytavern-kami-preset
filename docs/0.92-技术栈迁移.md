### 2. 面板不再各自内联组件核心

原来 `core.js`（41KB）被内联进 8 个脚本、`foundation.css`（15KB）8 份，合计约 390KB 纯重复。
现在 `build/kami-doc.mjs` 的 `expandUi` 只发一段**惰性 shim**：

```js
function createKamiUi(doc) {
  var rt = HOST.KamiRuntime;   // 取不到就抛人话错误
  ...
  return rt.createKamiUi(doc);
}
```

> ⚠️ 必须惰性：占位符在脚本里的位置**早于 HOST 定义**，写成 `var x = HOST.KamiRuntime.x` 会在定义时取到 undefined。

**效果**：产物 5.73MB → 5.22MB（省约 550KB）。

## 二、已迁移到 React 的面板

### 🔄 远程更新 v1.6（第一个，2026-10-26）

它的界面只有「更新进度窗口」一处，是最小可行的试点：

- 删掉了 `/* @@KAMI_UI@@ */` 占位 —— **本脚本现在完全不用 core.js**
- 进度窗口改由 React 渲染：`progressNode()` 构造虚拟节点，`reactRoot.render()` 重绘
- **DOM 结构与 `.kami-upd-*` 类名逐字不变** —— `PROG_CSS` 一行没改，皮肤无感
- 关窗口的三条路径（按钮 / 点外面 / document 级兜底）语义一个字没改
- 取不到运行库 → 不显示进度窗口，但**更新照常进行**（保住了 2026-10-05 的老行为）
- `data-kami-update-status` / `data-kami-update-stage` 仍由脚本写在容器上（皮肤与测试在读）

验证：`update-flow`、`update-progress` 两个单测全过；`verify-runtime` 报「已迁移 1 个」。

### 迁移模式（照这个抄）

1. 找出脚本里**自成一块**的界面（弹窗、卡片、列表）
2. 用 `RT.React.createElement` 写成组件，**类名保持原样**
3. 容器沿用原来的 `id` / class，React 只渲染它的子节点
4. 原来 `el.xxx.textContent = ...` 的地方改成 `reactRoot.render(...)`
5. 关闭时 `reactRoot.unmount()` 再摘容器
6. 运行库取不到要有降级（这块界面不显示，功能继续）

### 组件层自测（jsdom）

新增 `test/harness/runtime-ui.mjs`（41 项，已接进构建）：用 **jsdom 起一个真 DOM**、
加载**产物里的真 bundle**，把每个组件渲染一遍，钉住两件事：

- 类名契约：`.kami-btn` / `.kami-card` / `.kami-switch` / `.kami-collapse` …
- Radix 的可访问性角色：`role=switch` / `checkbox` / `radio` / `tab` / `tabpanel` / `dialog` / `progressbar`

> 为什么必须用 jsdom 的 `getInternalVMContext()`：手写全局白名单会漏，
> Radix 一碰 `instanceof HTMLFormElement` 就直接 ReferenceError。
> 创建 JSDOM 时要带 `runScripts: 'outside-only'` 才拿得到它。

**这一步抓到一个真 bug**：运行库导出的 `flushSync` 之前取自 `react-dom/client`
（那里没有这个导出），实际是 `undefined` —— 调用方以为能同步刷新，拿到的是异步渲染。
已改为从 `react-dom` 取。

### 迁移一个面板的步骤

1. 在脚本里取 `HOST.KamiRuntime`（取不到显示「请启用运行库」并退出）
2. 用 `RT.createMountPoint()` 建挂载点，`RT.UI.*` 写界面
3. 原来用 `mk()` / `createKamiUi().xxx()` 的地方换成 `RT.UI.Button` / `RT.UI.TabsRoot` 等
4. 删掉脚本里的 `/* @@KAMI_UI@@ */` 占位（迁移完成后不再需要 shim）
5. 跑 `node build/build.mjs`，再开预览台确认那个面板正常

**建议顺序**：工具箱 → 远程更新 → 引导 → 预设设置 → 皮肤管理（从小到大）。

## 四、注意

- 运行库是普通脚本，用户能在脚本列表里关掉。关掉后所有面板提示「运行库未加载」——

  守卫只能发现「占位没展开」，发现不了「bundle 过期」—— 记得重跑。
