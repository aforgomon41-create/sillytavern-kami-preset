## 维护约定

- **必读只有四份**，新知识往这四份里加，不要再开新的散文档（散文档最容易过期）。
  - 环境/部署/踩坑 → 真机验证备忘
  - 接口/契约/机制 → 皮肤契约
  - 「东西在哪、该复用谁」→ 功能复用
  - 状态/待办/进度 → 交接.md
- 改动 `src/` 之后**不要手改 dist**：跑 `node build/build.mjs`，产物版本号自增。
- 交付给用户时，永远在报告里写明**要下载哪个文件**（他看不到浏览器，只能下载导入手机验证）。
