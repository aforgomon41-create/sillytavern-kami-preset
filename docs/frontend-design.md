## 已确认的用途与风格

用于预设的思维链、行动选项、预设设置、压缩、引导与皮肤管理组件。保留现有结构和操作位置，信息密度适中，新增 GPT、Claude、大肥鱼三套皮肤，每套提供明暗两档。用户已明确回复“按这个方向，先看预览”。

| 皮肤 | 已确认方向 | 字体与层次 | 主要配色 |
|---|---|---|---|
| GPT | 黑白灰、简洁、内容优先 | 系统无衬线，中英文清楚，字号与留白区分层次 | 白/炭黑、灰阶表面，黑白主操作 |

## 预览与布局

- 用同一组“思维链、行动选项、设置控件”内容并排比较三套皮肤，提供明暗切换；只做审阅所需的静态结构，不接真实聊天和保存操作。
- 桌面三列比较；窄屏纵向排列，控件可换行，320px 下不横向溢出。正式面板仍沿用项目既有响应式结构。
- 明确展示默认、选中、禁用、焦点、错误说明等状态；选中态除颜色之外有边线或形状变化，正文对比度至少 4.5:1。
- 装饰放在标题旁或独立留白，不遮正文和操作区；可关闭，减少动效和关闭动效时无循环。图标与文字并存，装饰不承担操作含义。
- 黑暗世界 d10 另做现状与候选角度对比，重点是静止时的立体轮廓和面片可辨认度；掷骰结果仍需清楚，保持无逐帧 JS。用户要求修正展示，未要求更换皮肤配色与页面布局。

### 第十七轮：用户实机测试的意见（2026-10-29）

用户在真实酒馆里测了支线测试包，七条意见，逐条处理：

1. **特效在真实酒馆里不生效（严重）**：碎光判断「元素在不在屏幕内」用的是全局 `innerHeight`——脚本跑在酒馆助手的 0 高 iframe 里，取到的是 0，于是一律判成在屏幕外不画。预览里脚本和页面同一个窗口，测不出来。改为一律用面板所在文档的窗口（`innerHeight`、`getComputedStyle`、`performance`）；滑杆的 `requestAnimationFrame`（隐藏 iframe 里可能不触发）改 `setTimeout`。`display-next.mjs` 加了「打开面板有碎光」，`message-next.mjs` 加了「展开思维链有碎光」。
2. **思维链没生效**、3. **字体颜色没应用上，用酒馆的字体颜色设置**、5. **兼容插件插 DOM / 正文里的 HTML 美化**：消息前端改为 v0.2，内容留在酒馆的 DOM 里，只加外壳。详见[消息前端方案](前端重构-消息前端方案.md)第八节。
4. **消息前端要有开关，放显示面板**：「消息」一组第一行「消息前端」。
6. **所有前端支持 Markdown 与 LaTeX**：正文由酒馆渲染 Markdown；公式走构建期正则 + Temml（MathML）。思维链 / 搜索资料 / 行动选项的 Markdown 组件加了公式、删除线、链接。
7. **反截断按钮不要 emoji**：「反截断 开 / 关」。

另：工作区加了规则（`/workspace/CLAUDE.md`）——验证只在酒馆实机上做，不再用预览页 / 模拟 DOM 下结论。

验收（实机，电脑 1440 / 手机 390）：消息前端 33/33 ×2、显示 15/15 ×2、工具箱 23/23 ×2、预设设置 20/20 ×2、引导 26/26 ×2。
