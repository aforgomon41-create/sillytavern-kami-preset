# 前端设计记录

本项目组件、作用域与性能规则沿用 [皮肤契约](皮肤契约.md)。历史皮肤方案在 `design/proposals/`。本文件记录 2026-10-17 已与用户确认的新一轮设计，新增皮肤正式实现必须等用户审阅预览通过。

2026-10-17，用户审阅第二版后回复“可以动手吧”，已明确批准该布局、丰富装饰方向及骰子候选展示角度，现进入正式实现。保留此后各节的预览验证记录作为依据。

## 已确认的用途与风格

用于预设的思维链、行动选项、预设设置、压缩、引导与皮肤管理组件。保留现有结构和操作位置，信息密度适中，新增 GPT、Claude、大肥鱼三套皮肤，每套提供明暗两档。用户已明确回复“按这个方向，先看预览”。

| 皮肤 | 已确认方向 | 字体与层次 | 主要配色 |
|---|---|---|---|
| GPT | 黑白灰、简洁、内容优先 | 系统无衬线，中英文清楚，字号与留白区分层次 | 白/炭黑、灰阶表面，黑白主操作 |
| Claude | 暖纸、陶土橙、人文阅读感 | 衬线标题，易读正文；中文使用系统字体，不强制下载字体 | 米白、近黑、陶土橙；暗档暖炭灰 |
| 大肥鱼 | DeepSeek 蓝白、清爽圆角、鲸鱼娘装饰 | 系统无衬线，中等密度，蓝色集中在主操作与选中态 | 蓝、白、冷灰；暗档深蓝灰 |

以上是结合用户确认方向和官方资料的适配方案，不宣称是官方主题或与品牌有合作。字体使用系统回退，不打包未经许可的品牌字体。

## 预览与布局

- 用同一组“思维链、行动选项、设置控件”内容并排比较三套皮肤，提供明暗切换；只做审阅所需的静态结构，不接真实聊天和保存操作。
- 桌面三列比较；窄屏纵向排列，控件可换行，320px 下不横向溢出。正式面板仍沿用项目既有响应式结构。
- 明确展示默认、选中、禁用、焦点、错误说明等状态；选中态除颜色之外有边线或形状变化，正文对比度至少 4.5:1。
- 装饰放在标题旁或独立留白，不遮正文和操作区；可关闭，减少动效和关闭动效时无循环。图标与文字并存，装饰不承担操作含义。
- 黑暗世界 d10 另做现状与候选角度对比，重点是静止时的立体轮廓和面片可辨认度；掷骰结果仍需清楚，保持无逐帧 JS。用户要求修正展示，未要求更换皮肤配色与页面布局。

## 当前阶段

### 用户追加方向：官方资料与丰富装饰

用户指出 Claude 风格不够，要求补查官方文档；随后要求 GPT 同样核对。已复核 OpenAI 的公开 [Design Guidelines](https://openai.com/brand/) 与 [ChatGPT UI guidelines](https://developers.openai.com/plugins/concepts/ui-guidelines)。品牌页讲 OpenAI Sans 与标志；界面指南讲系统字体、单色线框图标、克制的色彩和布局。完整 `brand.openai.com` 跳转登录页，未假称读取其内容。皮肤以公开的 ChatGPT 界面规则为主要参考，不强行植入品牌字体。

Claude 的 [官方品牌示例](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md) 确有明确色板和 Poppins/Lora 建议；2026-10-17 实际核对 [Claude 官网](https://claude.com/) 的公开 CSS 后，发现其现行页面使用 `anthropicSans` / `anthropicSerif` / `anthropicMono`，不能把示例字体当作产品官网当前字体。官网暖灰阶、`#d97757` 陶土色、灰阶主按钮与衬线阅读标题已用于第二版预览和正式皮肤；使用本地系统字体回退，未经许可不提取打包品牌字体或标志路径。

用户还明确要求大肥鱼有“很多装饰”，并允许修改皮肤契约与管理脚本。第二版已演示：标题角色挂件、分区小头像、选项边饰、虎鲸开关、滑杆与输入框的小图形、页脚装饰和海洋背景。用户随后纠正动物形态，因此背景与图标采用有背鳍、白眼斑与腹色的蓝白虎鲸，未继续使用初稿的圆头鲸。鲸鱼娘保留指定版本身份。保持蓝白与现有信息密度，装饰量通过分组开关控制，不覆盖文字、禁用状态与焦点。复杂布置已通过第二版审阅，正式皮肤沿用这些位置。

平台扩展采用可选的 `assets` 图片表与 `--kami-asset-*` CSS 变量：只在管理器打包一份图片，同源 iframe 共享 Blob URL，布局与控件外观继续由皮肤 CSS 处理。动态插入的卡片通过 CSS 自动获得装饰，不增加节点观察、定时器或逐帧 JS；停用释放全部资源。旧皮肤没有 assets 字段时保持原有路径。此项基础能力独立于具体布局，按本次授权先实现并验证。

第二版布局与装饰预览位于 `design/previews/brand-skins.html`，骰子对照位于 `wod-dice.html`。已用隔离 Chrome 检查桌面 1440px 明档与窄屏 320px 暗档，五张装饰图正常解码，无页面横向溢出；三组装饰开关、选项切换、滑杆、开关的真实鼠标与键盘操作均通过。该阶段先完成资源管理基础能力；用户随后批准正式实现。

五张预览 WebP 共 189684 字节，位于 `design/assets/deepseek/`，来源与生成要求见该目录 README，均已验证可以由正式资源打包器处理。完整角色参考只留在本地 `design/reference/`。本轮生图使用内置 imagegen，未调用付费 API 或外部模型脚本。

## 正式实现与验证

三套包已完成：`src/skins/gpt/`、`claude/`、`deepseek/`，皮肤总数 21。GPT 使用灰阶轮廓控件；Claude 的消息选项为连续行，阅读区和标题走衬线回退，陶土色只作标记；大肥鱼使用 5 张本地图片及 3 组可独立关闭的装饰，支持背景浓度和标题挂件大小。装饰私有参数为 `--kami-deepseek-ocean-alpha`、`--kami-deepseek-mascot-size`；Claude 的陶土装饰色使用 `--kami-claude-clay`，均非其他皮肤必填令牌。

`test/harness/brand-skins-browser.mjs` 已通过 **107 项**：3 套 × 明暗 × 1440/320px，检查思维链、行动选项和四面板；每种组合覆盖 11 次可见输入及 97 次正文/卡片文字读数，未发现低于 4.5 的文字对比度或外壳/标题操作越界；验证真实鼠标/空格键操作、装饰开关、参数记忆、5 图共享与停用清理。十种 d10 结果均展示 4～5 个可见面，结果面法线朝镜头分量约 0.869；full 正常滚动并停到目标，calm/off 直接到结果。
