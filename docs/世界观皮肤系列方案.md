# 世界观皮肤系列方案（第一套皮肤）

> 2026-11-01 用户确认方向。皮肤按「套」做，第一套按酒馆角色扮演的**世界观**划分，共 15 款，**每款都要完全不一样**。
> 协议见 [前端契约](前端契约.md) 第 5、6 节，制作步骤见 [皮肤制作流程](皮肤制作流程.md)，进度记在 [交接](交接.md) 第〇节。
> 「碎光」继续当中性的默认皮肤，不归入本系列。

## 一、用户定下的事

| 事项 | 结论 |
|---|---|
| 主题 | 用户给的 10 个 + 历史做两款（中国宫廷、西方古典）+ 我们建议追加的 4 个（深渊、锈土、齿轮、暗巷），共 15 款 |
| 名字 | 两字中文名，或不超过 4 个字母 |
| 流程 | 先做基础设施 → 整套出预览 → **停下来给用户审阅**，审完再改、再上实机 |

## 二、怎么保证「完全不一样」

每款在七个方面各有一套做法，任意两款之间至少四项明显不同：

| 方面 | 说明 |
|---|---|
| 色彩 | 浅色与深色两档都要有（契约硬要求） |
| 字体 | 标题用风格字体，正文保证好读；外链字体载不到时退回系统字体 |
| 形状 | 圆角大小、直角、切角、尖拱、不规则毛边 |
| 材质 | 纸、绢、金属、玻璃、屏幕、石材 |
| 装饰 | 角花、边纹、分隔线、徽章样式 |
| 动效 | 打开、关闭、按下、切换页签各是什么动作 |
| 正文排版 | 对白、心理描写、专有名词、场景转换长什么样 |

### 1. 恋爱轻喜剧「糖霜」
- 配色：浅色奶油粉白 `#fff4f2` + 樱桃粉 `#e2557a`，点缀薄荷绿；深色莓果夜 `#2a2130` + 亮粉 `#ff8fb1`。
- 字体与形状：圆体；大圆角，卡片像贴纸（白描边、少女漫画网点底、纸胶带）。
- 装饰与动效：角落小爱心与星星；按下 Q 弹回弹，打开时迸出爱心和星星。
- 正文：对白粉色；心理描写淡紫。

### 2. 西幻冒险「远征」
- 配色：浅色羊皮纸 `#efe3c8` + 蜡封红 `#8a3b1f`，黄铜点缀；深色夜晚橡木酒馆 `#1f1812` + 烛光金 `#d9a441`。
- 字体与形状：标题古典衬线；纸边不规则，墨线双框。
- 装饰与动效：罗盘角花，底纹是地图等高线，徽章做成蜡封；打开像卷轴展开，切换页签像翻页。
- 正文：对白深红墨，心理描写褐色斜体。

### 3. 异世界轻小说「转生」
- 配色：浅色系统蓝 `#2f7cf6` + 白；深色 `#0e1626` + 发光蓝，稀有度金 `#f5b82e`。
- 字体与形状：粗黑体，数字等宽；半透明游戏状态窗，四角括号，标题栏像「【状态】」。
- 装饰与动效：菱形水晶与闪光；窗口弹出时一道光扫过。
- 正文：对白用「」框起来；专有名词做成系统提示框。

### 4. 修仙「云笈」
- 配色：浅色月白 `#f4f6f3` + 玉青 `#3d8c86`、淡金；深色玄青夜空 `#141a1c` + 灵光青 `#8fd6c8`。
- 字体与形状：清刻本风宋体；卡片无硬边、边缘柔光晕开，底是远山云雾渐层。
- 装饰与动效：祥云角饰，徽章做成玉牌；灵气粒子缓缓上升，打开时云雾聚拢。
- 正文：对白青碧，心理描写淡金。

### 5. 武侠「江湖」
- 配色：浅色宣纸 + 浓墨 `#1d1b18` + 朱砂 `#b8322a`；深色墨池 `#15130f` + 米色字。
- 字体与形状：标题毛笔字，正文楷体；直角，边框是粗犷的笔刷痕，徽章做成方形朱印。
- 装饰与动效：场景转换是一道斜刀光；打开时墨晕扩散，按下溅墨。
- 正文：对白浓墨加粗，心理描写淡墨楷体。
- 与碎光的区别：碎光细腻；这款粗犷、高对比、朱砂。

### 6. 赛博朋克「霓虹」
- 配色：深色为主 `#0b0a14` + 品红 `#ff2e88` + 青 `#00e5ff`，关键词黄；浅色是「白天」的混凝土灰 + 荧光色。
- 字体与形状：方块感科技字 + 等宽字；45° 切角，错位描边，扫描线，标题色差。
- 装饰与动效：汉字 / 片假名招牌感、警示条纹；打开时故障闪烁。
- 正文：对白青色，心理描写品红，关键词黄底高亮。

### 7. 军事战术「简报」
- 配色：浅色卡其档案纸 `#e6e2d3` + 橄榄绿 `#4b5d33`、警示橙；深色夜视仪黑绿 `#121611` + 夜视绿。
- 字体与形状：标题模板喷漆字，标签等宽字；直角，页签像档案夹标签，底是坐标网格，分隔线是刻度尺。
- 装饰与动效：「机密」印章、十字准星角标；雷达扫描，打开像抽出文件夹。
- 正文：对白像无线电记录。

### 8. 历史 · 中国宫廷「朱墙」
- 配色：浅色绢黄 + 宫墙朱红 `#9e2a2b`、琉璃黄、青绿彩画色；深色乌木漆 `#1b1210` + 金。
- 字体与形状：标题隶书 / 楷体；对称构图，回纹边框，标题做成竖条题签。
- 装饰与动效：如意角饰、印玺；打开像奏折横向展开。

### 9. 历史 · 西方古典「月桂」
- 配色：浅色大理石白 `#f4f1ea` + 帝国紫红 `#6d2142` + 金箔；深色黑曜石 `#14130f` + 金。
- 字体与形状：标题罗马碑刻体（全大写、宽字距）；直角 + 细金线，立柱式分栏。
- 装饰与动效：月桂叶环、希腊回纹；打开时金线由中间向两端描出。
- 与「朱墙」「远征」的区别：石材与金箔，冷而庄重；不是纸，也不是朱红。

### 10. 黑暗哥特「夜祷」
- 配色：深色为主 `#0f0c0e` + 骨白字 + 血酒红 `#8b1e2d` + 古金；浅色象牙手抄本 + 黑墨 + 朱红标题。
- 字体与形状：标题黑体字母（Fraktur），中文配粗宋；面板顶部尖拱，细铁艺花纹。
- 装饰与动效：正文首字下沉，玫瑰窗、荆棘纹；烛火摇曳的光晕。
- 正文：对白骨白，心理描写暗金斜体。

### 11. 高科技「光栅」
- 配色：浅色洁白 `#f5f7fa` + 精密蓝；深色深空 `#05080d` + 全息青 `#4cc9f0`。
- 字体与形状：极细标题、加大字距，数字等宽；1px 细线，小圆角，毛玻璃，点阵网格。
- 装饰与动效：HUD 角标 ⌜⌟、数据读数；打开时线条逐笔描出。
- 与「霓虹」的区别：干净、冷静、精密；不故障、不脏。

### 12. 克苏鲁 / 诡秘「深渊」
- 配色：深色深海墨绿 `#0c1412` + 病态荧绿 `#6fbf73` + 紫 `#6a4c93`；浅色泛黄调查笔记 + 墨 + 污渍。
- 字体与形状：打字机字 + 手写批注；边框不规则，触须卷纹。
- 装饰与动效：打开时墨水渗开，画面缓慢「呼吸」。
- 备注：预设吉祥物奈亚子就是奈亚拉托提普，与预设本身最对味；也适合恐怖、规则怪谈。

### 13. 末日废土「锈土」
- 配色：沙尘色 + 锈橙 `#b5541c` + 警示黄；深色焦土 `#1c1814`。
- 字体与形状：粗犷喷漆字；铁皮铆钉、胶带修补、磨损边。
- 装饰与动效：灯光不稳地闪、尘土飘。
- 与「简报」的区别：军事整齐规范，废土破旧拼凑。

### 14. 蒸汽朋克「齿轮」
- 配色：黄铜 `#b0803a` + 深色木头 + 奶油纸；深色烟熏黑 + 黄铜。
- 字体与形状：维多利亚襯线；铆接的黄铜边框。
- 装饰与动效：齿轮角饰，进度条做成压力表；齿轮转动、冒蒸汽。

### 15. 悬疑推理「暗巷」
- 配色：黑白灰 + 台灯琥珀 `#d89a3c`（深色）/ 证物红（浅色）。
- 字体与形状：打字机字；百叶窗光影条纹，证物标签。
- 装饰与动效：闪光灯，光从百叶窗扫过。

## 四、需要先补的平台能力（基础设施）

| # | 能力 | 做法 |
|---|---|---|
| 1 | 默认皮肤显式指定 | 不再是「打包顺序第一套」；新皮肤的目录名不会再顶掉碎光 |
| 2 | 系列分组 | 清单加 `series`（系列 id 与名字），显示面板按系列分组列出皮肤 |
| 3 | 通用动效模块 | 在碎光的 `fracture` 之外补一组可调参数的模块，各皮肤组合使用：展开、故障、墨晕、粒子、描线 / 扫描、光晕脉动。全部遵守动效三档与系统「减少动态效果」 |
| 4 | 形状 | 皮肤 CSS 放行 `clip-path` / `mask`（切角、尖拱、毛边），必要时扩充契约 |
| 5 | 程序生成纹理 | 网点、等高线、网格、扫描线、回纹等用 CSS 渐变 / SVG data URI，不占图片预算 |
| 6 | 外链字体 | 中文风格字体走 jsDelivr 上的字体包（大陆能连），载不到退回系统字体 |
| 7 | 整套预览 | 一个预览页把 15 款并排列出，每款看面板与消息正文、浅色与深色 |
