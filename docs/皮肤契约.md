# 卡密预设 · 皮肤契约 v0.3

更新：2026-10-19。本文是当前有效规范；旧版存于 [历史记录](history/皮肤契约-v0.2.md)，不再作为实现依据。新增或修改皮肤同时遵守 [前端设计](frontend-design.md)、[制作流程](皮肤制作流程.md)、[组件库](ui-components.md)。当前目录自动发现全部皮肤，不维护固定数量名单。

## 0. 架构与职责

业务前端使用共享组件；公共基础层管理结构，皮肤覆盖外观。新增通用能力先补共享库，禁止在不同面板复制实现。

| 层级 | 负责 | 不负责 |
|---|---|---|
| 业务前端 | 数据、任务、事件、交互状态和动态数值 | 为某个皮肤另写按钮、模型连接或配色 |
| 共享组件与基础层 | DOM、可访问性、导航、容器几何、滚动、焦点、生命周期 | 皮肤的材质与装饰主题 |
| 皮肤 | 成对配色、字体、间距、圆角、材质、状态反馈和装饰 | 操作逻辑、导航行数、舞台定位、显隐语义、功能文案 |

公共基础 CSS 始终生效；低优先级默认外观可被皮肤覆盖，明确的结构约束必须保留。静态检查只能覆盖可机械判断的规则，不能取代视觉验收。

## 1. 生效、作用域与兜底

皮肤管理将样式和以下属性下发到宿主及消息 iframe 的 html：

| 属性 | 值 |
|---|---|
| data-kami-skin | 皮肤 id；缺失表示管理器未运行 |
| data-kami-scheme | dark / light |
| data-kami-effects | 空格分隔的已开启特效 id |
| data-kami-motion | full / calm / off |
| data-kami-density | compact / cozy / roomy |

- src/ui/foundation.css 始终提供公共结构和默认值。src/skin/base.css 的旧兜底仅在未启用皮肤时生效，由 baseCss() 合并。
- 皮肤普通规则以原样前缀 html[data-kami-skin="<id>"] 开头，再进入 .kami-root。旧版直接 .kami-* / [data-kami-*] 作用域保留兼容；新规则优先带 .kami-root。
- 每个逗号分支和嵌套媒体查询分别检查。禁止选择酒馆自身的 #chat、.mes、body、宿主按钮或第三方插件。
- html 根级规则只允许 --kami-* 声明，不能写背景、字体或布局。
- build/sync-tavern.mjs 仅将准确匹配 .kami-root 的根级默认令牌及明暗/密度/动效条件复制到 html。后代、伪元素、卡片和组件局部映射留在原处；生成块不手改。
- 酒馆全局美化、旧正文包裹层及消息镜像已退役，不能依据历史文档恢复。令牌上提不为酒馆添加外观。
- **层叠顺序**（0.93，宿主页面）：`@layer kami.base`（基础组件 + 令牌默认值）→ `@layer kami.component`（结构兜底）→ 面板几何（**不分层**）→ 皮肤 CSS（**不分层**）。
  未分层的普通声明天然压过分层的，所以皮肤不需要堆特异性或 `!important` 去抢基础层；但几何是平台的事，皮肤不要覆盖面板定位（见 §2 第 5 条）。
  注意 CSS 的反直觉规则：**分层里的 `!important` 压过不分层的 `!important`**。细节与原因见 [前端技术栈](前端技术栈.md) 第六节。

### 1.5 正则前端的源码安全

酒馆替换会展开捕获组，再运行宏替换。进入正则替换文档的共享代码不得意外包含“美元符号后跟数字”或“美元符号后跟小于号”，也不得包含双花括号宏。不要用双写美元符号逃逸；需要美元符号时用字符码生成或函数式 replace。build/verify-frontends.mjs 在构建中按酒馆语义重放检查；普通 JS 语法通过不代表替换安全。

## 2. 皮肤作者硬规则

1. 新界面使用运行库提供的共享组件：React 面板用 `RT.UI`（Radix 组件层），命令式代码与正则前端用 `createKamiUi(document)`（45 项工厂、布局与插槽见组件库文档）。两者的分工见 [前端技术栈](前端技术栈.md)。缺少通用能力先补公共实现。
2. 通用外观按组件/角色编写，不按某个面板 id 打补丁。新皮肤必须同时覆盖内嵌、面板与弹窗。
3. 皮肤不写 JS，不用 @import、@font-face、外部 URL 或未打包相对图片路径。静态 PNG/WebP 走 assets；内联 SVG 可用 data URI。
4. .kami-tabs 始终单行横向滚动；.kami-tab 不收缩、不内部换行。禁止与可换行的 actions/seg 共用布局规则，禁止改为网格/竖列或裁掉横向滚动。等分用 mode:'fit'；末尾控件用 tab-actions 插槽。
5. 内嵌、面板、弹窗分别使用 embedded/panel/dialog。舞台定位、边界夹取、手机贴底抽屉、长弹窗正文滚动由公共层负责。皮肤不得将面板 fixed/inset/transform 套到 dialog，不得挡住关闭/中断操作。
6. 卡片必须区分 container/choice/collapse。反相、凹槽和按下效果只用于选择卡或明确的旧按钮卡；禁止对所有 .kami-card 一把套。
7. 修改底色时同步确认字色、链接、占位、选中、禁用和焦点。accent/accent-fg 成对；局部映射不升到 html。正文对比度至少4.5:1，控件边界/焦点至少3:1；链接有下划线等非颜色提示。
8. 原生 select 同时验收闭合框及展开 option/optgroup 的普通、选中、禁用态。文字与不透明底色成对；仅设 color-scheme 不足以证明展开项可读。必要的控件颜色可在组件作用域内使用 !important，不能借此推翻布局。
9. 选中态不能只靠色相，还应有边线、字重、形状或标记。保留库生成的 aria、disabled、hidden、open、键盘与焦点语义。
10. 先通过320px，再检查390px、桌面及放大字号。网格、长文本与背景必须自适应。消息 iframe 自然撑高；皮肤不使用 vh，不以 fixed 铺满 iframe。
11. 明暗两档都需可读。密度与 full/calm/off 均有效；calm 去掉循环，off 和系统减少动效停止循环/位移。必须核对计算样式，不能只看选择器存在。
12. 装饰不挡字、点击或焦点，覆盖层 pointer-events:none。大面积 blur/backdrop-filter 克制使用，不逐帧动画 filter，不批量滥用 will-change。静态装饰不增加运行循环；切皮肤、重开面板、卸载时不累积节点/事件/资源。

## 3. 令牌与持久化

令牌就是统一的外观变量。完整名称以 src/skin/base.css 为基础；必填集合排除 build/lint-skins.mjs 的 OPTIONAL_TOKENS 及派生值。新增通用令牌先给完整默认值，再逐套补齐；不能只给新皮肤，让其他皮肤取到空值。

基础配色必须放在默认 html[data-kami-skin="<id>"] .kami-root，不能只在某个按钮、选中态或明暗条件里出现。默认值、条件覆盖与局部重映射分开写。

| 分类 | 关键令牌及用途 |
|---|---|
| 文字 | --kami-fg / -fg-dim / -fg-mute；分别用于主文、说明、弱提示 |
| 强调 | --kami-accent / -accent-fg / -accent-soft / -accent-line；强调底和对应文字 |
| 表面 | --kami-bg / -bg-soft / -card / -card-2 / -card-hover；容器与嵌套层 |
| 边界 | --kami-line / -line-strong / -border-w；分隔与控件边界分档 |
| 排版 | --kami-font / -font-title / -font-mono / -fs / -lh / -fw；字体仅用系统栈 |
| 尺寸 | --kami-pad-* / -gap* / -row-h / -r-* / -items-min；密度与网格 |
| 状态 | --kami-warn / -kind-*；语义色不能代替可读文字色 |
| 装饰 | --kami-texture / -glow* / -shadow* / -blur；材质、阴影与辉光 |
| 动效 | --kami-dur* / -ease* / -enter-* / -stagger；须响应关闭与系统减动效 |

### 3.1 配色与局部映射

- 嵌套容器、选择卡、折叠头、模型连接和提示词编辑器分别检查；不能靠继承猜测文字与背景是否配对。
- 换底色后要确认子元素显式读取的令牌，不只是父节点 color。
- 透明背景按实际叠加后的可见颜色验收；getComputedStyle 返回 transparent 时，不能把它直接当成白或黑计算对比度。
- 表面常同时带 .kami-shell/.kami-surface，background 简写会清掉其他背景层；下拉箭头同理。局部补色优先用 background-color 等长写。
- --kami-kind 可作为根级默认值；按 data-kami-kind 的局部值只能留在对应元素。生成器只按“准确根级匹配”上提，不能按“选择器中出现 root”上提。

### 3.6 用户设置

字号缩放 --kami-fs-scale 全局保存，--kami-fs 必须将它乘入。明暗、密度和动效响应当前属性；有意维持相同明暗外观时须记录设计理由并验收两档。

特效与参数保存在 skinSettings[skinId]；切换恢复该皮肤自己的值，首次使用取自身默认。旧平铺设置只迁给当时选中的皮肤，禁止把同名参数跨单位带到另一皮肤。数值按元数据范围裁剪。

管理器按需下发，属性或样式未变不重复写；iframe 换文档在 load 时重发，被移除时清理监听。停用取消待处理队列并移除样式/属性/装饰及其资源。

### 3.7 文案

功能文字归前端：渲染/原文、填入/发送、复制、计数、空态、失败提示等不能被皮肤改写。

风格槽位用 data-kami-label="<slot>"，展开槽用 data-kami-label-open；皮肤提供 --kami-label-<slot>，缺失时回退元素默认文字。槽位用带组件前缀的 kebab-case；不在契约硬编码完整槽位名单。当前表与落地由 design/copy/copy-table.json、apply-copy、lint-copy 管理。

禁止皮肤定义以下功能文案令牌：
--kami-label-empty、-chars、-unit、-demo、-filled、-noinput、-sent、-sendfail（均为完整 --kami-label- 前缀）。

effects/params 的名称、说明、分组和单位归元数据，但须清楚说明作用。代码和文档修改按作者当前的协作约定进行，不再沿用历史“专职文案代理必须写入”的分工。

## 4. DOM、角色与状态

| 稳定属性 | 含义 |
|---|---|
| data-kami-container | embedded / panel / dialog / native；决定容器结构 |
| data-kami-comp | 业务身份：panel、dialog、think、search、options、body、preview、custom、ball |
| data-kami-ui | 组件库写入的准确组件类型 |
| data-kami-card-role | container 普通容器 / choice 选择卡 / collapse 折叠卡 |
| data-kami-tabs-mode | scroll 默认单行滚动 / fit 单行等分 |
| data-kami-slot="tab-actions" | 导航尾部控件区，内容宽度，同一行 |

search 不能冒用 think 身份，dialog 不能冒用 panel。build/css-scope.mjs 为旧皮肤明确映射内部外观，面板根几何不映射到弹窗。新增皮肤按当前身份设计。

### 4.1 容器

| 容器 | 公共结构要求 |
|---|---|
| embedded | 自然撑高，区域内部可有明确的表格/代码横向滚动，整页不意外横向溢出 |
| native | 原生思维链块里的父文档组件：宿主 `details.mes_reasoning_details` 外面再包一层 `.kami-root`，details 只挂 `.kami-shell .kami-surface .kami-collapse`，这样皮肤里 `.kami-root … .kami-shell` 的后代选择器才能命中边框/底色；自然撑高，折叠由宿主 `details.open` 承担，脚本只同步 `data-kami-open`；不铺满视口、不接管宿主编辑/删除/复制按钮 |
| panel | 舞台全视口且不挡背景；本体接收操作；坐标/尺寸受夹取；窄屏贴底 |
| dialog | 支持 showModal 的浏览器中使用原生模态层；根局部定位；长内容滚动正文；头尾和关闭可见；正确焦点恢复 |

不支持 showModal 时现有库只降级为带 open/ARIA 的普通对话框，不能保证背景阻断与完整焦点约束；新功能不得据此宣称兼容浏览器拥有完整模态行为。

面板使用 --kami-panel-x/y/w/h，不能忽略它们另摆一套。旧 data-kami-layout="sheet|floating" 保留兼容；新共享 panel 已由 foundation 按容器与屏宽处理，不要求业务重复实现。

正文外壳在父文档，保留插件就地插入操作；think/options/search 为消息内嵌前端。preview 为皮肤缩略，ball 为状态栏悬浮球。皮肤不能把正文外壳强塞回 iframe。think 另有 `data-kami-container="native"` 的父文档实例（原生思维链块）：它复用同一套 `.kami-*` 骨架与皮肤规则，原生 summary 与编辑/删除/复制按钮保持可用，脚本只补标题、字数与渲染/原文切换。

### 4.3 状态

- 共享 tabs 使用 aria-selected、tabIndex 和 hidden；共享 collapse 使用 details/summary 与 open。
- 旧 .kami-collapse 使用 data-kami-open 与 .kami-collapse-body，旧头部保留 .kami-head.kami-collapse-head 供箭头匹配。旧内容留在 DOM；不能将旧“禁用 hidden”的要求套到新组件。
- 选中用 .is-on / aria-pressed，忙碌用 data-kami-busy，完成反馈用 .is-done；disabled 与 focus-visible 始终可辨认。
- 皮肤只消费状态，不用 CSS 伪造/逆转状态。业务 data-kami-act、-role、-item 等私有委托键不是通用外观接口；不得依赖内部计时器、载荷和初始化标记。
- 新的通用类名、角色或插槽先登记公共 API，再落地并补全默认值/回归，不能只让某一皮肤认识。

### 4.4 导航与工具箱

皮肤管理的页签与快捷下拉同一行，末尾选择器用 tab-actions 插槽而非全宽表单布局。预设多页签保持单行且首尾可达；工具箱为压缩、网络搜索、其他功能，使用 fit 单行模式。

说明用既有可展开说明控件；模态交互用共享 dialog。旧酒馆原生确认路径只临时降低自己面板层级，结束/异常均恢复，不改宿主。没有确认手段时不得假定用户同意。

### 4.5 皮肤管理 API

宿主公开 KamiSkin。skin 读取当前 id，state 返回状态副本；skins() 返回皮肤摘要；previewDoc(id) 返回复用的预览文档，不存在时为 null。open/close/toggle 控制面板；setSkin/setParam/setFlag 通过管理器更新设置，业务不能旁路另存一份。sync/status 用于下发与诊断，shutdown 执行完整清理。

正文前端开关复用 bodyFront/syncBodyFront/setBodyFront，与引导页共用状态。启动及渲染前 syncBodyFront 只读对账；用户操作 setBodyFront 才联动当前预设的正文正则启用位，不能扩大为修改其他正则。角色名样式继续复用 KamiNameWrap，与皮肤参数独立。

## 5. 业务前端边界

think、options、search、body 复用公共组件与皮肤。搜索资料默认折叠，来源链接清晰可点。**2026-10-21 重做**：search 不再照搬 think 的散文骨架，改成「编号事实列表 + 来源芯片表」，事实里的 [n] 与来源表编号同一套；兜底皮肤里有完整设计，另有不限定无皮肤的结构基线保证各皮肤不退化。显示/原文、复制、填入/发送等行为由业务实现，皮肤不隐藏或替换功能文字。原生思维链块沿用 think 身份：`46-思维链.js` 把显式 CoT 写进 `extra.reasoning`，再按同一套骨架装饰宿主块；原生编辑/删除/复制入口必须保留。

皮肤面板、预设设置、引导、工具箱、更新、自定义样式和状态栏都使用同一组件语义。新增面板必须继承公共导航/容器，不以某个旧面板截图为理由复制结构补丁。

## 6. 皮肤包格式

源码目录：src/skins/<id>/skin.json、skin.css，可选 assets/。

~~~json
{
  "id": "example",
  "name": "示例皮肤",
  "button": "示例",
  "scheme": "light",
  "tagline": "简短介绍",
  "effects": [{"id":"grain","label":"纹理","desc":"显示轻量纹理","default":true}],
  "params": [{"id":"glow","label":"辉光","group":"氛围","token":"--kami-glow-size","unit":"px","min":0,"max":24,"step":1,"value":8}],
  "decor": [],
  "assets": {"mascot":"assets/mascot.webp"}
}
~~~

- id 与目录一致，小写字母开头，后续用小写字母/数字/连字符；name/button 非空；scheme 只允许 dark/light。
- effects/params/decor 为数组；各自 id 不重复；effect.default 若给出必须布尔值；特效须在 CSS 中有对应 data-kami-effects 响应。
- 参数 min/max/value 为有限数字，min<max，默认值在范围内；step 若给出必须正数。同一 token 不能被两项参数竞争写入。
- unit 会直接拼成 CSS 值，支持空串、px、rem、em、%、deg、rad、turn、ms、s。×/° 不能当单位；新增单位先扩展公共校验并补测试。
- 源码 skin.json 不含 css。仅构建后的运行时皮肤表附加 CSS/资源，不得倒写源码。
- decor 只接受平台登记模块；assets 按 §8 校验。目录自动参与构建/管理/预览/校验，文案表另需补齐。

## 7. 自动检查与边界

构建接入 lint-skins、skin-contract 负例回归、ui-components 与文案检查，失败即停止。导航规则只有一份 build/skin-contract.mjs，由皮肤 lint 和组件检查共同调用。

| 检查 | 自动拦截 |
|---|---|
| 元数据 | 无效 JSON/类型/id、重复项/token、错误明暗值、无效范围/步长/单位、未知装饰、源码 css 字段 |
| CSS | 准确前缀、每个分支的组件作用域、宿主目标、html 外观声明、基础配色放错层、必填令牌缺失、功能文案覆盖 |
| 导航 | 换行/竖列/网格、裁掉横向滚动、tab 收缩/内部换行；支持嵌套条件与 is/where 分支，排除滚动条伪元素 |
| 资源与能力 | 外部/未打包 url、import/font-face、脚本内容、vh、缺少动效/焦点/字号响应、图片路径/格式/像素/体积 |
| 内容 | 文案表覆盖及落地一致；正则捕获/宏安全由 verify-frontends 检查 |

~~~sh
node build/lint-skins.mjs
node test/harness/skin-contract.mjs
node test/harness/ui-components.mjs
node build/lint-copy.mjs
node build/apply-copy.mjs --check
~~~

静态检查不证明真实对比度、原生选单展开层、叠图可见性、触屏手势或运行开销，也不承诺识别任意伪装的等价 CSS。必须执行 §10，不能把静态 PASS 写成“全部视觉合格”。公共改动要补能复现原故障的回归，禁止只用“元素不出屏幕”代替行数/滚动检查。

## 8. 装饰、资源与清理

交互装饰只声明 decor，由皮肤管理注入/销毁；目前 d20、d10。不得在皮肤里写逻辑或为每张图新增模块。

- 前端保留 .kami-deco 槽，默认收起；模块升级后生成对应 kami-d20*/kami-d10*。不支持时保持隐藏，不露出未升级方块。
- 图形样式不替换几何/随机算法。装饰使用键盘可触发按钮和读屏反馈，滚动及重入由公共模块处理。
- d10 的镜头 --kami-d10-view-x/y 与结果面/滚动分离，静止仍呈现邻面。d20/d10 尺寸由模块观测，不用观测结果反推槽位尺寸，以免形成 ResizeObserver 回环。
- 装饰伪元素不能盖住已升级骰子；减少动效档及卸载时停止动画、监听与定时器。准确几何/属性接口见 src/decor/d20.js / src/decor/d10.js，扩展须同步文档和测试。

### 8.4 静态图片、特色控件与背景

assets 映射资源名到该皮肤 assets/ 下的静态 PNG/WebP。构建检查真实路径、格式、像素和体积，拒绝越界链接及动画图：单图≤256KiB，单套≤768KiB，预设合计≤2MiB；最长边≤4096px，总像素≤4194304。先按实际展示尺寸导出，不能直接塞原始生图大图。

构建只存一份图片。管理器以共享 Blob URL 生成 --kami-asset-<name>，宿主、iframe、预览复用；不将图片字节复制进每楼层 CSS。缺少 Blob 能力时才回退内联，停用撤销 URL。

| 装饰位置 | 稳定挂点 |
|---|---|
| 标题/分区 | .kami-head、.kami-title、.kami-card-head |
| 选项/条目 | .kami-item、.kami-item-main、.kami-badge |
| 按钮/状态 | .kami-btn、.kami-icon-btn、.kami-dot |
| 输入/滑杆/开关 | .kami-field、.kami-range、.kami-switch-track/knob |
| 背景/空态/页脚 | .kami-shell、.kami-drop、.kami-empty、.kami-foot |

使用 background-image:var(--kami-asset-mascot,none) 或伪元素，不替代文字，不移除原生控件。角色、背景、特色控件分别做可关闭特效，复用现有特效状态。大背景选择适合的 contain/cover/分层尺寸和定位；长正文不把完整装饰图强行拉长，正文阅读区留白。无图/关闭装饰仍可完成全部功能。

素材来源、使用条件及生图授权记录在 frontend-design.md；不得把素材授权理解为新布局已获审阅。

## 9. 公共层与动态样式例外

- foundation 的 UA 重置、box-sizing、隐藏、导航、容器几何和焦点属于结构，不受“业务不写外观”限制，皮肤不能推翻。
- 面板坐标/尺寸、进度、滑杆值、球位置、骰子几何和用户参数由脚本写入对应元素/变量；不改整个文档的局部状态。
- tabs 的 hidden、details.open、菜单/树/提示的显隐由组件 API 管理；旧 collapse 的保留 DOM 约束只适用于旧骨架。
- iframe 高度以平台机制为主，启动/内容改变时做必要兜底；不再常驻一套全量扫描/轮询。
- Markdown 复用既有可信引擎，不每楼层内联；文本默认 textContent，富内容回调返回安全 DOM。不要用 innerHTML 塞外部文字。
- 状态球的舞台、拖动与图片缩放由状态栏模块管理，不美化宿主；旧原生确认只调整自己的面板并成对恢复。
- 原生思维链块的宿主重置（`46-思维链.js` 注入、作用域限定 `[data-kami-native-think]`）：summary 的 list-style/margin、`.mes_reasoning_header` 的原生内外边距与底色、`.mes_reasoning` 的原生边框/内边距/底色需要收回，否则会与皮肤的双层壳打架。这些是**结构例外**，不是外观设计；`!important` 只用于压过酒馆与用户自定义 CSS 的 ID 选择器，范围不得扩大到其它组件。
- 原生思维链块的 `.kami-root` 必须是 details 的**父元素**，不能和 details 合并成同一个节点；否则皮肤按 `.kami-root … .kami-shell` 写的边框/底色规则匹配不到（2026-10-20 色块皮肤真机事故）。
- 流式搬运提示（`46-思维链.js` 的 `[data-kami-stream-hint]`）：复用 `.kami-root` + `.kami-chip` 骨架和 `.kami-cot-spin` 转圈，只在显式 CoT 正在从正文流扣走时插在当前消息里；提示文字与转圈不能隐藏，颜色跟随皮肤 token，不写进消息文本，消息落地/生成结束自动收起。

## 10. 验收清单

新皮肤留下结果与截图路径；公共层改动对全部目录发现的皮肤回归。

| 范围 | 必测 |
|---|---|
| 容器 | embedded / panel / dialog；长内容、关闭可见、正文滚动和焦点恢复 |
| 尺寸 | 320、390、桌面；默认与放大字号；网格、长文本、无意外页面横向溢出 |
| 导航 | 皮肤 tabs+下拉同一行；预设首尾项通过触摸/滚轮/键盘可达；工具箱 fit 单行 |
| 配色 | 明暗两档；普通/嵌套/选择/折叠卡；正常/选中/禁用/焦点/忙碌/错误/空态；四类输入及展开 option |
| 装饰 | 长短正文、多宽度、关闭/缺失；不拉伸、不遮字、不挡操作 |
| 动效 | full/calm/off 和系统减少动效，读实际计算样式；卸载无残留 |
| 实机 | 宿主及自定义 CSS 下控件可读；切皮肤、重复开关、iframe 换文档与停用清理 |

node test/harness/server.mjs --port 8794
