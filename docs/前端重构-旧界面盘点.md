# 前端重构 · 旧界面盘点（2026-10-27）

> 给面板重设计用的输入：旧界面**有哪些功能、控件和操作**（不能漏），以及**旧界面的问题**（不能再犯）。
> 来源：本机测试酒馆（SillyTavern 1.18.0 + 酒馆助手 4.11.3）里装的 `kami-v0.93`（main 当前代码），默认皮肤「色块」，1440×1000。
> 截图与原始数据在 [design/rewrite/old-ui/](../design/rewrite/old-ui/)（`inventory.json` 是每页的标题 / 按钮 / 说明，`contrast-baseline.json` 是对比度基线）。
> 复现：`node test/st/capture-old-ui.mjs`、`node test/st/audit-old-ui.mjs`。

## 一、对比度基线（新旧对比）

用新系统同一套算法（按实际叠加后的背景、计入透明度）审计屏幕内可见的文字：

| | 低于 4.5 : 1 | 最差 |
|---|---|---|
| **旧界面**（默认皮肤，3 个面板 15 个页签 + 引导 15 页） | **225 / 909 处（约 25%）** | 1.11 : 1（几乎与底色相同） |
| **新设计系统**（3 套皮肤 × 明暗 × 3 种宽度，含两套故意刁钻的测试皮肤） | **0 / 6138 处** | — |

重灾区就是「未选中的选项卡片」：预设设置的写作指导页 22 处、创作要求 12 处；引导第 7～13 页（逐项选择各类预设条目）累计 152 处；引导的皮肤选择页里，皮肤名写在浅色卡片上（「文明启蒙」「Claude」1.2 : 1）。

## 二、实测发现的交互问题

1. **未选中项靠「降低对比度」表达**，结果是读不出来（见上）。新系统里选中 / 未选中必须用非颜色差异区分（契约第 4 节）。
2. **面板记住打开状态，刷新后直接盖住酒馆的按钮条**（1440×1000 下皮肤面板底栏挡住了 🌟 / 🧰 按钮），只能先关掉面板才能点别的按钮。
3. **焦点不在面板里时按 Esc 关不掉面板。**
4. **预设设置有 9 个页签**，840px 宽的面板里放不下，「运行模式」「关于」要横向滚动才看得到。
5. **引导有 15 步**，其中第 7～13 步是把预设设置的各页签再走一遍。

## 三、各面板的功能清单

### 🎨 皮肤管理（3 个页签）

| 页签 | 内容 |
|---|---|
| 皮肤 | 皮肤卡网格（21 套，每张带实时预览缩略）；正文前端开关（附「请勿在会话中切换」警告）；角色名样式（反引号 / 双下划线 / 无包裹）；行动选项默认展开 / 折叠；明暗（跟随皮肤 / 暗色 / 亮色）；动效（完整 / 克制 / 关闭）；密度 |
| 参数 | 按分组（通用 / 表面 / 动效）的滑杆参数，带单位（× / %）；底部状态行 |
| 特效 | 当前皮肤的特效开关列表（每项带一句说明），例如色块的「噪点 / 顶边亮线 / 方块喘气」 |

> 注意：「角色名样式」「正文前端开关」「行动选项默认展开」其实不是皮肤设置，只是放在了皮肤面板里。重设计时可以考虑挪走。

### 🌟 预设设置（9 个页签）

整体是「运行时解析当前预设 → 按分组展示条目卡片」。每个分组有：标题、条目数、单选 / 多选标记、ⓘ 注释按钮；卡片点击即开关条目。底栏：卡片数 · 条目数 · 锁定数 · 写入次数。

| 页签 | 内容 |
|---|---|
| 🤖 模型 | 模型切换说明；按模型分组（DeepSeek / GLM / Gemini / Kimi）的专属条目卡，带 ⓘ 注释 |
| 🧩 设置变量 | 数值变量卡（推理预算、正文 token 量、插图数量），带 ⓘ；清空变量、标签格式 |
| 📖 创作要求 | 9 组单选：语言文字、剧情推进、叙事视角、创作权限、转述程度、难度设定、叙事焦点、色色选项、杂项要求 |
| 😀 角色塑造 | 角色对白、心理描写、各种防止 |
| 📝 写作指导 | 文风优化、写作文风、NSFW 文风；**自定义文风**（新增 / 保存） |
| 🧪 额外任务 | 头部 / 正文 / 尾部任务（网络搜索、HTML 美化、文生图、摘要、行动选项、角色存档……），带 ⓘ |
| 🧠 推理选项 | 推理工具、增强随机、特殊底部、底部破限、推理格式、卡思维链 |
| 🎛 运行模式 | 剧情游玩 / 对话讨论 |
| ℹ️ 关于 | 版本信息、检查更新、继承旧预设设置（选择旧预设 + 说明） |

### 🧰 工具箱（3 个页签）

| 页签 | 内容 |
|---|---|
| 压缩 | 顶部操作：立即大总结、全部取消隐藏、清除压缩数据；压缩模式（滚动压缩 / 超限压缩，选择卡）；两组参数（起始深度；触发上限、保留最新楼数、每块楼数）；大总结模型（跟随酒馆 / 自定义接口，连接配置）；例外楼层（添加 / 移除）；压缩块列表（刷新）；摘要提示词（模板管理：存为新模板 / 删除；头部 / 任务正文 / 尾部）；关联的「🧱 摘要（小总结）」条目 |
| 网络搜索 | 开启搜索能力；来源（模型自带 / 搜索服务）；选「搜索服务」后：供应商下拉（13 种）、密钥、手动搜索入口与设置（独立模型 / 提示词 / 限额）、自动搜索限额、头部任务内容 |
| 其他功能 | 三张折叠卡：自动标签处理、常驻附加指令、导出纯净正文 |

## 四、给重设计的建议（待用户决定）

- 预设设置的 9 个页签可以按「用户心智」重新分组（例如：写作风格 / 角色与叙事 / 功能任务 / 高级），把「模型」与「运行模式」提到面板头部。
- 引导与预设设置共用同一套页面组件，引导只挑「首次必须决定」的几项（皮肤、模型、语言），其余让用户之后在面板里调。
- 非皮肤设置（角色名样式、正文前端开关、行动选项默认展开）从皮肤面板挪到相应功能处。
- 面板默认不记住「打开」状态，或打开时避开酒馆按钮条。
