## 0. 现场与操作说明

- 真机：http://localhost:11451/ ，SillyTavern 1.18 + 酒馆助手 4.9.5。
- 当前预设始终是 `卡密预设0.9-74`，**没有切换过预设**，也没有开关任何预设条目。
- 每次都用 `browser_session action=start` 新开标签页（没有 borrow）。窗口 `1420x940`，实测 CSS 视口 `1272x699`，就是任务里说的 1280 档。
- 切页只用进度点（click），切皮肤只用第 2 页的皮肤卡（focus + Enter），全程没按过 ✕，没进过第 14 页。
- **收工已把皮肤切回 trpg 并截图确认**（纸面涂鸦 + trpg 卡绿色虚线选中框 + 深色墨块按钮），随后关闭了自己的标签页。

### 一条必须告诉后续验证者的操作纪律（本次踩到）

真机的截图会**落后一帧**，而且不是偶发：切页之后直接截图，拿到的是上一页。
稳定拿到当前帧的办法是「切页 → 滚一下正文（`browser_interact action=wheel`）→ 再截图」。本次 14 张图全部靠这个办法抓到的。
另外 **rain 皮肤下截图基本不可用**：切换皮肤后的第一帧能抓到，之后要么返回同一张过期帧（连续三次截图 sha256 完全相同），要么 `browser_inspect action=screenshot` 直接 30s RPC 超时。同样的操作在 memo / nixie 下正常。

## 4. 三套皮肤共性问题

1. **刊头没有不透明底色，正文滚动时穿帮。** 内容滑到刊头下面，标题「卡密预设 · 新手配置向导 第 N / 14 步」和 14 个进度点直接压在卡片/正文上。模型页还能看到导读文字被刊头切掉一半。
   证据：`共性-刊头滚动穿帮.png`（进度点压在三张皮肤预览卡上）、`memo-p3.png`（导读被截断）。
2. **网格在大屏下大片留白。** 变量页只有两张卡却只用左侧 45%，下方 65–80% 全空；创作权限页三个窄卡只占半行。三套皮肤全一样。
   证据：`memo-p4.png`、`nixie-p4.png`、`rain-p4.png`、`memo-p7.png`、`nixie-p7.png`。
3. **「上一步」在深色皮肤下几乎看不见**（无边框、只有暗灰字），和旁边的墨块主按钮对比失衡。
   证据：`nixie-p3.png`、`nixie-p4.png`、`nixie-p7.png`、`rain-p7.png`。
4. **底部墨块主按钮过宽过重**，占页脚右侧一半以上。三套皮肤都这样。
   证据：`memo-p7.png`、`nixie-p3.png`、`rain-p7.png`。
5. **ⓘ 注释标记在深色皮肤下渲染成空的浅色方块**（memo 正常）。同一个 `.kami-note-mark`，只有浅色皮肤显示得出 ⓘ 字形。
   证据：`nixie-p3.png` / `nixie-p4.png` / `nixie-p7.png` 对比 `memo-p4.png`。
6. **emoji 单色化 + 重影。** 🎮 / 🔊 在纸上和暗底上都渲染成深色单色字形，🔊 还画了两遍（两个喇叭叠着）。
   证据：`memo-p7.png`、`nixie-p7.png`、`rain-p7.png`。
7. **预览小窗首帧空白。** 面板打开后的头一两帧，四张皮肤卡的预览位是纯色块，要等 iframe 的 `load` 事件跑到才出现迷你组件。观感上像"预览坏了"，其实不是。谁验收时看到空洞，请先等一下或滚一下再判断。
   证据：reload 后首帧截图；机制见 `src/scripts/50-引导.js:667-669`。

## 5. 顺手发现的一处死规则（代码层，供后续修，本次没动）

`src/scripts/50-引导.js:499` 写了一条

    #kami-guide-panel .kami-guide-skins > .kami-item.is-on .kami-guide-pv{ border-bottom: … }

但 `renderSkin()` 根本没建 `.kami-guide-pv` 元素——`src/scripts/50-引导.js:659` 建的是 `.kami-guide-plate`，iframe 直接塞进 plate 里。
所以"选中皮肤卡的强调下划线"这条规则从未生效。真机上选中态只有卡片外框和底色在区分（见 `memo-p2.png`）。

## 6. 对照实验：🎨 皮肤管理面板的预览缩略图

**结论：画出来了。** 同一份预览文档（`30-皮肤管理.js` 的 `buildPreviewDoc` / `PREVIEW_MINI`）在皮肤管理面板里用 div 结构渲染，辉光管的迷你组件（标题／渲染·原文／复制／正文样例文字／行动 一个选项）完整显示。
证据：`对照-皮肤面板预览.png`。
→ 说明酒馆环境本身支持这种预览写法，引导那一处没有坏；引导首帧空白只是渲染时机问题（见共性问题 7）。
