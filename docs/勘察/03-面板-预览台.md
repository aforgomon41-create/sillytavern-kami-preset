## 一、memo（记事本）

### 面板

1. **预设设置面板的 tab 行被右边缘硬切，且没有可见的横向滚动条**
   现象：7 个 tab（🤖 模型 / 🧩 设置变量 / 📖 创作要求 / 😀 角色塑造 / 📝 写作指导 / 🧪 额外任务 / 🧠 推理选项）排成一行，到第 4 个「😀 角色塑造」时被面板右边缘直接切掉半个字，界面上看不到滚动条、也没有左右箭头。
   证据：`memo-preset.png`（右边缘「角色塑」被截断）；#diag 读数「tab行: 条数=7 不同行数=1 轨道419/825(可横滚) 面板内溢出=0 页面溢出=0 tab轨=0/825 可视419」。

2. **数字输入框不是黑底黑字，可读**
   现象：设置变量页的 6000 / 1500 / 3000 / 4 / 8 都是「纸白底 + 深墨字」，边框清楚；皮肤面板参数页的字号缩放输入框也是同样的纸白底深字，没有出现黑底配深字。
   证据：`memo-preset-var.png`、`memo-params-expanded.png`。

3. **参数页的折叠组「一行字占一条 420px 的横带」，右侧整片留白**
   现象：通用 / 纸面 / 印记 三组，每组只有左边一个 ▸、组名、右端一个计数小方块（1 / 2 / 2）。组名到计数方块之间约 350px 全是空的横条，行高却接近 60px，看起来像三条被拉长的空条目。
   证据：`memo-params.png`。

4. **特效页开关离文字太远，扫视成本高**
   现象：六行特效（方格底纹 / 裁切线 / 印刷重影 / 翻牌入场 / 纸边洇墨 / 影印颗粒），每行左边是「标题 + 一行说明」，开关挤在右端、只有约 30px 见方。420px 宽的行里，说明文字在左端、开关在右端，中间空出约 300px，要确认「这行开没开」得把眼睛甩到最右边；而且打开态（红色小方块）和关闭态（灰色小方块）只差颜色，形状一样。
   证据：`memo-fx.png`。

5. **皮肤页卡片排布正常，缩略图能看出皮肤差异**
   现象：四张皮肤卡 2 列排开（记事本 / 辉光管 / 恋雨 / 奈亚子的TRPG），当前皮肤右上角挂「使用中」胶囊，卡内是名称 + 一句描述 + 方形缩略图；缩略图里能看到该皮肤自己的纸面/暗色材质。
   证据：`memo-skin.png`；#diag「pv:memo=memo/212x212/rgb(245,240,228)、pv:nixie=nixie/221x221/rgb(25,22,18)、pv:rain=rain/263x263/rgba(16,20,21,0.88)」。

6. **模型页长名字条目卡被撑高，卡片下半截留白**
   现象：「🐋 表示DeepSeek系列模型」组里三张卡 DS/GLM、DS/GLM底部破限、DS/GLM强强；后两张名字换行成 2 行，卡片跟着变高，名字下面到卡片底边留出一大片空。
   证据：`memo-preset.png`；#diag「名字=20字 换行样本 DS/GLM底部破限=2行 DS/GLM强强=2行」。

7. **设置变量页底部两张「空壳卡」**
   现象：「🧩 清空变量」「🧩 标签格式」两张卡并排，卡里除了标题和一个 ⓘ 什么都没有，卡片高度只有上面变量卡的一半左右，看起来像没渲染完。
   证据：`memo-preset-var.png`。

8. **面板整体没有横向溢出**
   现象：抽屉内部和整页都没有被内容撑宽。
   证据：#diag「面板内溢出=0 页面溢出=0」「皮肤面板|drop=419>419」「drop=412,72,420,560」。

### 前端

9. **显式思维链（展开态）结构完整**

10. **行动选项：卡片信息密度合适，但同行卡片等高造成空档**
    现象：6 张卡 3 列 2 行，卡左上角是序号 01..06 + 彩色类型徽章（行动/性格/推进/信息/搞笑/NSFW）+ 标题，右上角一个圆形 ↵，下面 1~2 行正文。第 3 张「正面确认她的心意」正文只有 2 行，卡底却和邻居一样高，卡内下方留白明显。

## 二、nixie（辉光管）

### 面板

1. **预设设置面板的 tab 行同样被右边缘切断**
   现象：和 memo 完全同一处，「😀 角色塑造」被抽屉右边缘切掉半个字，无滚动条、无箭头。
   证据：`nixie-preset.png`；#diag（nixie）「tab行: 条数=7 不同行数=1 轨道419/825(可横滚) 面板内溢出=0 页面溢出=0 tab轨=0/825 可视419」。

2. **数字输入框可读，不是黑底黑字**
   现象：设置变量页的 6000 / 1500 / 3000 / 4 / 8 是「深底 + 亮橙字」，边框一圈浅橙，暗色皮肤下反而比 memo 更醒目；皮肤面板参数页的字号缩放输入框同样是深底橙字。
   证据：`nixie-preset-var.png`、`nixie-params-expanded.png`。

3. **参数页折叠组同样大面积留白，而且暗底上更空**
   现象：通用(1) / 光照(2) / 材质(2) 三行，每行还是「▸ + 组名 + 右端计数」。因为这是暗色皮肤，三行下面那一大片纯黑留白面积更大，面板看起来像只填了三分之一。
   证据：`nixie-params.png`。

4. **特效页开关的「开 / 关」区分偏弱**
   现象：七行特效（市电呼吸 / 起辉动效 / 真空玻璃 / 阴极层叠 / 阴极编号 / 过载溢光 等），开关是斜纹小方块；打开的那行是橙色填充 + 描边，关着的是同形状的灰色斜纹方块。两者形状、大小完全一样，只靠颜色区分，在暗底上并排看容易看错。
   证据：`nixie-fx.png`。

5. **皮肤页卡片的「显示 / 动效 / 密度」三组段控右端不对齐**
   现象：明暗（跟随皮肤 / 暗色 / 亮色）、动效（完整 / 克制 / 关闭）、密度（紧凑 / 舒适 / 宽松）三组段控，选中项是橙框；因为每组选项宽度不同，三个段控组的右边界参差不齐，整块看起来是斜着收尾的。
   证据：`nixie-skin-bottom.png`。

6. **模型页深层条目卡同样被换行撑高**
   现象：DS/GLM底部破限、DS/GLM强强 换行成 2 行，卡片高度被顶开，卡内下方大片空；暗色卡片是虚线边框，边框本身很淡，卡与卡之间的边界不明显。
   证据：`nixie-preset.png`。

7. **皮肤页卡片排布正常**
   现象：四张皮肤卡 2 列，当前皮肤挂「使用中」胶囊，缩略图里记事本是浅纸面、辉光管是暗金属，能一眼分辨。
   证据：`nixie-skin.png`；#diag「pv:nixie=nixie/266x266/rgb(25,22,18)」。

8. **面板本身不横向溢出**
   证据：#diag「面板内溢出=0 页面溢出=0」「皮肤面板|drop=419>419」；网格读数「可见网格[355px→3列 卡113x75 间距8 …]」（条目卡网格在面板里是 3 列，没有挤成一列或溢出）。

### 前端

## 四、跨皮肤共性问题

严格来说只跑完了两套皮肤，rain 未跑，所以下面是「memo 与 nixie 两套都实测到」的共性问题（三套共有这条无法证实，标注清楚）：

1. **预设设置面板的 tab 行被右边缘硬切，且没有任何「还能往右滚」的提示。**
   两套皮肤的读数完全一样：轨道 419px 装 825px 内容、tab 轨初始位置 0/825、可视 419。视觉上都是「😀 角色塑造」被切掉半个字。证据：`memo-preset.png`、`nixie-preset.png`（+ 各自 #diag 的 tab行读数）。

2. **参数页的折叠组在 420px 宽的抽屉里只占左边一小截，右侧整片留白，行高偏大。**
   两套都是一行里「▸ + 组名」靠左、计数小块靠右，中间约 350px 全空。证据：`memo-params.png`、`nixie-params.png`。

3. **特效页的开关是「贴在最右边的小方块」，与左侧说明文字隔了约 300px，且开 / 关只靠颜色区分。**
   证据：`memo-fx.png`、`nixie-fx.png`。

4. **设置变量页底部「🧩 清空变量」「🧩 标签格式」两张卡是空壳：只有标题 + ⓘ，卡身没有内容，高度只有上方变量卡的一半左右。**
   证据：`memo-preset-var.png`、`nixie-preset-var.png`。

5. **数字输入框两套皮肤都没有「黑底黑字」问题。**
   memo 是纸白底 + 深字，nixie 是深底 + 亮橙字，两套都能一眼读清数值。证据：`memo-preset-var.png`、`memo-params-expanded.png`、`nixie-preset-var.png`、`nixie-params-expanded.png`。
