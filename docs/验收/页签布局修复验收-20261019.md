# 页签布局回退修复验收（2026-10-19）

用户在59包中发现：手机上的皮肤快捷选择掉到第二行，预设设置的导航变为多行按钮。此次按用户要求恢复原有单行布局，无新页面或风格设计。

## 共因和修复

1. 公共 foundation 把 `.kami-tabs` 和可换行 `.kami-actions` 合并，新增 `flex-wrap:wrap`；旧皮肤依赖浏览器默认 nowrap，没有重新声明，因此低优先级规则也改变了布局。
2. 页签还继承了普通按钮的边框/最小高度等默认值；快捷 select 又继承表单控件的 `width:100%`，使紧凑导航更易换行。
3. 旧检查只确认不溢出屏幕，没有检查实际行数和横向滚动，换行反而通过了边界检查。

公共层现在独立提供单行滚动轨道与不压缩、不换行的页签项；按钮外观与导航默认值分开。常规按钮组继续允许换行。皮肤管理快捷选择复用 `tab-actions` 插槽，宽度按内容、最多占轨道一半，不再每个面板手写定位。工具箱原有三等分页签显式使用 fit 模式；默认新页签仍为按内容宽度的 scroll 模式。组件运行时升级为1.0.1，缓存按版本切换。没有为21套皮肤逐一叠补丁。
