# 免费搜索 API 调研

2026-10-18，按用户要求由只读 Luna Max 子代理调研，主 Agent 核对官方页面。这里只记录候选，没有新增供应商、注册账户或提交真实密钥。现有13个渠道保持不变。

| 候选 | 官方免费条件 | 对本项目的影响 |
|---|---|---|
| [You.com](https://you.com/product/web-search-api) | 新账户赠100美元，约2万次搜索，不需信用卡 | 一次性赠额。REST优先使用POST，非定期免费额度 |
| [Jina](https://jina.ai/reader/) | 每个新API Key附1000万免费tokens | 未证实周期补充；搜索返回内容较长，仍须提取并限制上下文。免费用途限制按官方条款确认 |
| [Linkup](https://www.linkup.so/pricing) | 页面明确提供4000次免费查询 | 未明确周期与绑卡条件，不称长期免费 |
| [Brave](https://api-dashboard.search.brave.com/documentation/resources/help-feedback) | 每月5美元免费额，约1000次Search；需绑卡，可设预付余额0 | FAQ限制保留API返回的数据。我们的搜索结果会保存进聊天，接入前须取得适用的存储许可，暂不建议直接接入 |

You.com另有每日100次免注册MCP入口，但不是同一REST Key计划；当前未研究或接入这条路径。上述四家预检在本机未取得HTTP响应，浏览器跨域能力未知，也未完成真实搜索；“有API”不能视为已经能够在预设里直连。

官方接口参考：[You.com Search](https://you.com/docs/guides/search)、[You.com认证](https://you.com/docs/using-the-api/authentication)、[Brave快速入门](https://api-dashboard.search.brave.com/documentation/quickstart)、[Linkup快速入门](https://docs.linkup.so/pages/documentation/get-started/quickstart)。

Bing原官方搜索API已退役；SearXNG依赖独立Python服务，不能直接作为预设内脚本运行。按用户“开销太大就算了”的取舍，本轮不捆绑后端，保留现有Bing经SearXNG的入口。依据：[微软退役公告](https://learn.microsoft.com/en-us/lifecycle/announcements/bing-search-api-retirement)、[SearXNG安装](https://docs.searxng.org/admin/installation-searxng.html)。
